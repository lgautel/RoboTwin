# 《小宇和安全小分队》儿童绘本

这是根据 `fbl_g56Ln_3.markdown` 制作的20页中文儿童绘本项目，包含网页阅读版、打印版和本地矢量插画素材。

## 文件结构

```text
fbl_g56Ln_3_picturebook/
├── index.html                 # 网页阅读版，支持翻页和键盘方向键
├── print.html                 # 打印版，浏览器打印即可保存为PDF
├── styles.css                # 网页和打印样式
├── book.js                   # 20页绘本文字、翻页逻辑和图片路径
├── source/
│   └── fbl_g56Ln_3_source.md # 本项目使用的绘本内容说明
└── assets/
    └── pages/
        ├── page-01.svg
        ├── ...
        └── page-20.svg       # 20张本地矢量插画
```

## 浏览

在本文件夹中启动任意静态文件服务器，然后打开 `index.html`。例如：

```bash
python3 -m http.server 8765
```

再访问 `http://localhost:8765/`。

也可以直接双击 `index.html` 打开；若浏览器限制本地文件访问，使用静态文件服务器即可。

## 打印

打开 `print.html`，在浏览器中选择“打印”，目标选择“保存为PDF”。打印样式已设置分页，每个绘本页面独立成页。

## 内容安全说明

- 飞机表示从安全距离观察。
- 高铁表示沿安全路线离开，前往安全站。
- 预警雷达表示发现危险后提醒找大人。
- 导弹只通过带盾牌的预警图标表现，不包含发射、瞄准、爆炸或攻击。
- 绘本反复强调：说“停”、走安全线、报告大人、陪伙伴。

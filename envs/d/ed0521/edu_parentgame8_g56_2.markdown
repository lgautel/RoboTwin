# 6–8 岁社交、领导、学科与反欺凌载具亲子游戏指南

> 调研与撰写日期：2026-10-23  
> 适用对象：喜欢飞机、战斗机、战舰、汽车、赛车、火车、消防，以及航天、港口、公交、邮政、气象和城市服务等模拟游戏的 6–8 岁儿童。  
> 核心目标：把已有兴趣转成合作社交、邀请式领导、语文、数学、英语、物理/STEM，以及识别不友善/欺凌候选、安全退出、持续求助和旁观支持的具体学习机会。  
> 使用边界：普通家庭游戏不诊断或治疗 ADHD，不替代课堂系统教学、真实同伴实践、专业家长训练、学校欺凌防控或安全处置；儿童不负责认定法律或校规意义上的欺凌。游戏表现也不证明领导身份、人格、同伴接纳、学科成绩、现实自保能力或远迁移已经改变。

## 0. 先看结论

### 0.1 十六条核心结论

1. **领导不是发号施令。**本指南中的领导行为是邀请、倾听、复述、分工、保护异议、支持求助、检查影响、共享功劳和承担修复。
2. **一局只有一个主目标。**社交、语文、数学、英语和物理可以同时出现，但一次只观察一个，其他只是副目标。
3. **先关系、再挑战。**孩子不愿共同玩时，回到儿童主导连接，不用“培养领导力”压过拒绝权。
4. **按当前能力选档，不按生日硬切。**八岁儿童疲劳时可用六岁档；六岁儿童熟悉任务时也可主持。
5. **加难不靠更久、更多题、更响、更快或更强碰撞。**优先角色反转、信息差、策略比较、换情境和撤一种提示。
6. **合作不是把几个人放在一起。**有效合作需要共同目标、角色互赖、个人责任、促进性互动和短复盘。
7. **真实社交迁移只能在真实同伴中观察。**和父母配合顺利，不代表在学校被接纳、有朋友或被群体承认为领导。
8. **学科游戏需要明确教学。**材料本身不会自动教会数轴、叙事、英语语音或物理变量控制；新知识先示范，再练习和反馈。
9. **语文不是只认字，数学不是只口算。**本指南还练叙事结构、来源归属、数量关系、等量、时间区间、测量和数据。
10. **英语每次少而深。**围绕少量词、句框或沟通修复策略反复听说读写；不把背台词、口音或一次开口当成能力。
11. **物理结论必须限定条件。**只说“在这辆车、这套材料和当前设置中……”，不用玩具直觉宣布普遍定律。
12. **错误应产生信息。**不暗中破坏作品、不故意制造失败；错误后检查第一处偏差、得到反馈并局部修正。
13. **ADHD 支架先改环境和成人动作。**材料减量、终点可见、一句一动作、允许站立和每次只撤一种提示，优先于奖惩加码。
14. **安全和关系高于游戏完整。**儿童说停、真实危险、持续羞耻或恐惧、成人开始接管或游戏挤压睡眠时立即停止或降档。
15. **不必证明“对方有坏心”才保护自己。**儿童只需看可见行为、伤害、力量差、重复或再发风险和能否安全退出；正式认定与调查属于成人、学校和有关机构。
16. **勇敢不是打回去或独自扛住。**安全时可简短说停；不安全时跳过说停、尽快离开、持续告诉可信成人，并在不增加自身风险时陪伙伴求助。

| 类型 | 主要价值 | 成人做什么 | 不做什么 |
|---|---|---|---|
| 儿童主导连接 | 关系、共同注意、兴趣表达 | 模仿、描述、复述、守安全 | 偷放考题、连续纠正 |

## 1. 本指南怎样推导

### 1.1 四份既有指南提供的底座

本指南继承但不要求读者预先阅读：

- [`edu_parent_g56_1.markdown`](./edu_parent_g56_1.markdown)：关系、学习能动性、元认知、价值、社会交往和优势识别；
- [`edu_parentadhd_gp56_1.markdown`](./edu_parentadhd_gp56_1.markdown)：前因调整、指令、强化、共同调节、家校与专业边界；
- [`edu_parentgame_g56_1.markdown`](./edu_parentgame_g56_1.markdown)：六岁载具游戏统一协议和安全；
- [`edu_parentgame8_g56_1.markdown`](./edu_parentgame8_g56_1.markdown)：6–8 岁三档、20 个新循环、迁移和反重复审计。

两份游戏指南已有 40 个核心循环。本指南不再换皮重复塔台等待、路线配送、紧急安置、位置记忆、修理厂对话、红绿灯、碰撞修复、道岔改线、消防报告与撤离、痕迹侦探、单变量坡道/风/船体、资源采购、公平分配、广播删选、策展、交接或安全漫画，而补充**邀请式授权、保护异议、调解、带教、拉动协作、独立对账、算法调试、来源署名、规则试行、信息最少披露、跨团队接口和独立验收**等结构。

### 1.2 社交与领导证据改变了什么

[现代学校 SEL 元分析](https://doi.org/10.1111/cdev.13968)纳入 424 项研究、575,361 名 K–12 学生，SEL 技能、同伴关系和亲社会行为平均效应较小且研究高度异质。它支持完整学校项目平均可能有效，不证明一次家庭游戏或某一句主持话术有效。

[6–7 岁合作—创造游戏项目](https://doi.org/10.1027/1015-5759.12.2.141)报告任务内合作、帮助和教师评“亲社会领导行为”改善，但只有 8 个班，教师兼实施者和评分者，且无长期追踪；不能把家庭游戏中的主持表现解释为领导身份。[幼儿同伴协作综述](https://doi.org/10.1002/rev3.3484)与[合作学习综述](https://doi.org/10.14221/ajte.2016v41n3.3)提示，共同目标、正向互赖、个人责任、角色分工、显性社交技能和小组复盘比“只是一起玩”更关键，但证据主要来自学校。

[假装游戏与社会能力元分析](https://doi.org/10.1007/s10648-024-09884-z)对 3–8 岁只发现很小关联，且多数研究为横断面；角色扮演是练习媒介，不是社交能力的必然原因。[Fast Track 同伴接纳研究](https://doi.org/10.1080/15374416.2022.2051523)则提醒：真实同伴接纳需要真实同伴、教师和家庭生态共同作用。

由此得到三条设计纪律：

1. 把“领导力”拆成可观察行为，不打领导人格总分；
2. 每次主持都伴随倾听、邀请跳过、异议通道和责任检查；
3. 家庭练习后，只在真实同伴活动中低调观察，不要求儿童表演领导。

### 1.3 语文、数学与英语证据

**语文。**[叙事干预系统综述](https://pubs.asha.org/doi/10.1044/2021_LSHSS-20-00160)纳入 40 项学前与小学研究，支持明确故事结构、视觉/语言提示、复述与创编机会；不能推出随便编故事就能提高阅读。[中文阅读干预元分析](https://doi.org/10.1007/s10648-024-09915-9)显示语音、字形和语素训练均可能有效，但家长实施子组较弱且不显著。中文不能照搬英语逐字母解码：拼音是语音支架，汉字还涉及语素意义、字形结构和语境。

**数学。**[家庭数学干预元分析](https://doi.org/10.3102/00346543231156182)纳入 25 项、3,697 名约 1.6–8.5 岁儿童，总体效应约 `g=.26`；样本平均年龄偏小，方案异质。[线性数字棋盘元分析](https://doi.org/10.3102/00346543251383552)对学前至二年级数学结果约 `g=.21`。[IES K–6 数学指南](https://ies.ed.gov/ncee/wwc/Docs/PracticeGuide/WWC2021006-Math-PG.pdf)支持数轴和应用题结构，但主要面向课堂与数学困难儿童。设计上使用实物、数轴、等量、区间和数据记录，不宣称所有游戏提高数学成绩。

**英语。**[IES K–8 英语学习者指南](https://ies.ed.gov/ncee/wwc/Docs/PracticeGuide/english_learners_pg_040114.pdf)支持少量词汇跨数日深教，并结合听说读写、图片、例反例与结构化交流；其语境是英语环境中的课堂，不是中国家庭 EFL。[小学 EFL 语音教学综述](https://www.frontiersin.org/journals/education/articles/10.3389/feduc.2017.00015/full)对语音意识和假词解码较支持，但真实词阅读与理解不稳定。本文每局只用少量词或一个句框，并把“请重复、请指出、你的意思是……”等沟通修复视为有效目标，不用口音和流利表演评分。

### 1.4 物理与 STEM 证据

[NGSS 科学与工程实践](https://www.nextgenscience.org/sites/default/files/Appendix%20F%20%20Science%20and%20Engineering%20Practices%20in%20the%20NGSS%20-%20FINAL%20060513.pdf)把 K–2 定位为简单公平测试、观察测量和比较预测，3–5 才逐步明确变量控制、重复试验和模型修订。标准规定发展目标，不是家庭游戏疗效证据。

[发现学习元分析](https://doi.org/10.1037/a0021017)显示无辅助发现总体弱于明确教学，而带脚手架、反馈、范例和解释提示的增强发现较好；[探究指导元分析](https://doi.org/10.3102/0034654315627366)也支持指导。7–10 岁变量控制研究表明，仅追问不够，明确教“只改一个变量”更可靠（[Chen 与 Klahr](https://doi.org/10.1111/1467-8624.00081)）。

因此，本指南的 STEM 游戏必须：

```text
成人先示范一个公平/不公平例子
→ 儿童预测
→ 明确改什么、看什么、保持什么
→ 操作或运行模型
→ 保留所有结果
→ 用“在当前条件下”形成结论
→ 根据证据改模型或规则
```

不得从玩具直接教授牛顿定律、密度公式、转矩、升力理论或电学操作；这些游戏只作定性先备和探究方法练习。

### 1.5 反欺凌证据改变了什么

中国法定与学校治理语境首先把责任放在成人和系统。《[未成年人学校保护规定](http://www.moe.gov.cn/jyb_xxgk/xxgk/zhengce/guizhang/202112/t20211206_584982.html)》要求教职工及时制止侵犯身体、侮辱人格、强拿毁坏财物、恶意排斥及网络诽谤/传播隐私等行为，学校接报后调查，并由欺凌治理组织认定和处置；《[防治中小学生欺凌和暴力指导手册](http://www.moe.gov.cn/jyb_sjzl/ziliao/A06/201803/P020230302379013322085.pdf)》覆盖识别、预防、处置、善后和家校合作；教育部 2024 年[专项行动“十项要求”](http://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/202405/t20240531_1133303.html)要求学校建立治理组织、公布报告渠道并落实首问负责。家庭游戏不能把这些职责转交儿童。

国际研究同样支持多层级而非“只训练受影响儿童”。[Campbell 系统综述与元分析](https://doi.org/10.1002/cl2.1143)综合 100 项学校反欺凌评估，平均而言实施欺凌约减少 18%–19%、受害约减少 15%–16%，但研究异质性高；这支持持续、多组件学校方案，不能拆出某个家庭游戏的疗效。[KiVa 对小学一至三年级的随机试验](https://doi.org/10.1037/a0030417)属于整校项目，核心含改变同伴规范、教师和学校响应，不等于在家排练一句“说停”。[WHO 学校暴力预防手册](https://iris.who.int/server/api/core/bitstreams/9971db81-2451-4a8c-9511-84ad9d196a4a/content)和 [UNESCO 全教育系统方法](https://www.unesco.org/en/articles/what-you-need-know-about-school-violence-and-bullying)也把课程、教师培训、安全环境、报告转介、家庭参与和监测放在同一体系。

[CDC 的操作定义](https://www.cdc.gov/youth-violence/about/about-bullying.html)与 [StopBullying.gov](https://www.stopbullying.gov/bullying/what-is-bullying)通常强调不受欢迎的攻击行为、现实或感知的权力不平衡，以及已经重复或很可能重复。中国制度定义还强调学生之间蓄意或恶意通过肢体、语言及网络等方式造成身体、财产或精神损害。本文不用儿童裁定哪一定义成立，而采用更安全的双层语言：

- **儿童层：**“这让我/他受伤、害怕、被控制或很难退出，需要停止并告诉大人。”
- **成人层：**记录具体事实，核对权力差、重复或再发风险、影响和多方信息，由学校/有关机构认定并处置。

因此得到六条设计纪律：

1. 先处理安全，再分类；一次严重伤害不等待“重复”；
2. 安全时可短句说停，不安全时直接离开，不因跳过说停扣分；
3. 第一个成人未处理时继续告诉下一个可信成人，求助不是告状；
4. 旁观者不笑、不围观、不点赞、不转发，优先叫成人、陪同离开和事后接纳；
5. 网络证据由成人协助保存、屏蔽和举报，儿童不卧底、不套话取证；
6. 不让儿童独自调解、当面对质、理解伤害者、强迫和解或以反击证明勇敢。

### 1.6 证据标签

| 标签 | 含义 | 本文怎样使用 |
|---|---|---|
| 【综述/元分析】 | 多项研究综合 | 支持平均方向和边界 |
| 【随机/实验】 | RCT、准实验或实验任务 | 只外推到相近年龄、实施和结局 |
| 【相关】 | 横断或纵向关联 | 不写成因果 |
| 【官方指南/标准】 | 课程、儿科、消防或安全标准 | 规定内容与边界，不冒充游戏疗效 |
| 【实施设计】 | 由证据和家庭目标推导 | 低风险候选，需本家庭观察 |

## 2. 把抽象目标变成可观察行为

### 2.1 社交与邀请式领导

| 抽象词 | 本指南观察什么 | 不用什么冒充 |
|---|---|---|
| 领导 | 邀请、复述、分工、查遗漏、承担修复、分享署名 | 声音最大、决定最多 |
| 合作 | 共同目标、互赖角色、各自责任、相互帮助 | 全程不争执 |
| 包容 | 主动邀请且允许跳过，保护少数意见 | 强迫每人发言 |
| 反馈 | 先征得同意，描述事实与影响，采纳权归执行者 | 批评人格、要求照改 |
| 调解 | 分开事实/影响/请求，逐方核对摘要 | 判谁是坏人 |
| 求助 | 说明状态并选择帮助类型，保留任务所有权 | 成人全部接管 |
| 责任 | 承认具体影响、实际补救、说明下次动作 | 强迫道歉 |

### 2.2 学科目标分轨

| 学科 | 可在游戏里直接观察 | 需要另行教学/测量 |
|---|---|---|
| 语文 | 故事结构、来源署名、因果句、口头概括 | 系统识字、拼音、阅读流利与作文 |
| 数学 | 一一计数、数的分合、等量、区间、简单数据 | 稳定运算、应用题迁移、课程掌握 |
| 英语 | 少量词汇、指令理解、句框、澄清策略 | 自由口语、真实词阅读、理解与写作 |
| 物理/STEM | 公平测试、模型链、接口标准、测量与复测 | 正式物理理论、学校实验与远迁移 |

一次游戏不同时评分“主持+英语+数学+物理”。例如“赛车圈数双裁判”的主目标是处理记录分歧，计数只是副目标；若本周主练计数，就另开数学局。

### 2.3 冲突、不友善与欺凌候选

| 情形 | 给 6–8 岁儿童看的线索 | 成人怎样路由 | 不能怎样处理 |
|---|---|---|---|
| 玩笑或打闹 | 双方都主动参加；强弱会轮换；说停就停；结束后仍愿意玩 | 守住自愿、力度和停止权 | “他在笑”就自动判定没事 |
| 普通冲突 | 双方力量大致相当；都能说话、退出并影响结果 | 冷静且双方自愿后协商或调解 | 把所有冲突都叫霸凌 |
| 一次不友善/伤害 | 一次抢夺、嘲笑、推撞、破坏或排斥也会造成伤害 | 先停止、照顾受影响者、记录并按严重性处理 | 因“只发生一次”而忽略 |
| 关系破裂 | 朋友背约、疏远或伤害；不一定存在力量差 | 先问儿童是否想修复，也允许结束关系 | 强迫继续做朋友或立即原谅 |
| 欺凌候选 | 有伤害，力量明显不对等，且重复或很可能再发生；也可能利用人数、地位、秘密或网络传播 | 保护儿童、记录模式、通知学校并改监督和群体条件 | 让受影响儿童单独协商、调解或更友善 |
| 协同排斥 | 多人反复要求绝交、故意孤立或用地位让某人很难参加 | 区分私人选择与有组织伤害，由成人调查群体条件 | 规定每个私人活动都必须邀请所有人 |
| 网络欺凌候选 | 威胁、冒充、群聊羞辱、传播隐私；内容可被反复查看或转发 | 成人保存必要证据、屏蔽、举报并联系学校/平台 | 让儿童继续聊天套取口供 |
| 操控/不安全联系 | 礼物换秘密、催促转私聊、索要资料/照片、威胁或要求见面 | 立即停止联系并告诉可信成人；由成人处理 | 要儿童证明对方是不是坏人 |

“意图”常看不见，也可能被否认。儿童无需先证明“故意”或说准“霸凌”一词才有资格离开和求助。判断顺序固定为：

```text
现在安全吗
→ 有什么可见行为和影响
→ 能否自由说停/离开
→ 是否有力量差、重复或再发风险
→ 需要哪位成人现在介入
```

### 2.4 策略性勇敢与四条保护路径

| 路径 | 适用条件 | 最小合格动作 | 不是目标 |
|---|---|---|---|
| 简短说停 | 没有即时危险，离成人或安全区域近 | “停下”“我不喜欢”“这不可以”中的一句 | 辩赢、解释很久、让对方承认 |
| 直接离开 | 说停可能增加风险、对方不停止或儿童僵住 | 不争辩，走向成人/开放区域 | 留下证明不怕 |
| 持续告诉 | 任何伤害、恐惧、控制、重复或不安全秘密 | 告诉一位可信成人；未处理就告诉下一位 | 一次被忽略后沉默 |
| 旁观支持 | 不增加自身风险 | 不起哄/不转发，叫成人、结伴离开、事后陪伴 | 身体介入、单挑或公开审判 |

成人应先示范：“你不用独自解决。告诉我是对的。我们一起让下一步更安全。”若儿童没说停、没离开或当时跟着笑，不能据此责怪；僵住、讨好、沉默和跟随都可能是压力下反应，保护责任仍属于成人。

## 3. 三档选择：能力档，不是年龄标签

### 3.1 选档问题

1. 儿童能否在一张图或一个手势后开始？
2. 能否保留 2–3 条可见信息？
3. 出错后能否在一句提示下回任务？
4. 能否复述一个他人想法或说一个理由？
5. 当天是否饥、累、痛、兴奋或刚有冲突？

第 1–3 项多数困难或当天状态差，用 **6 岁起步**；能完成完整循环，用 **7 岁进阶**；能解释策略且愿意撤一种提示，用 **8 岁挑战**。连续两局需成人接管就降档；连续三次轻松且儿童主动要求变化，才加一个变量。

### 3.2 三档契约

| 维度 | 6 岁起步 | 7 岁进阶 | 8 岁挑战 |
|---|---|---|---|
| 信息 | 2 个选项、1 个变化 | 完整默认循环 | 信息差、策略比较或 1 个新约束 |
| 角色 | 成人示范，儿童选一步 | 儿童执行一个角色 | 儿童主持、带教、审核或角色反转 |
| 支架 | 全图示、共同启动 | 关键步骤可见 | 儿童同意后撤一种 |
| 表达 | 指、摆、短句均可 | 说一个理由或复述 | 说明适用边界或处理异议 |
| 复盘 | 指一个有用动作 | “我发现……下次……” | 解释何时适用/不适用 |

禁止以增加文字、算题量、英语台词、游戏时长、速度、噪声、失败代价或碰撞力度来加难。

## 4. 一局游戏的统一协议

### 4.1 开局 30 秒

- 身体和情绪是否适合开始？
- 这局是连接、共同挑战还是迁移检查？
- 唯一主目标是什么？
- 儿童需要先学哪个知识或看哪个示范？
- 材料是否安全、够少、够清楚？
- 自然终点在哪里？
- 暂停、简化、换角色和退出怎样表达？

### 4.2 三阶段

**A. 连接，3–5 分钟。**儿童选材料和角色；成人模仿、描述、复述，少提问、少教学。  
**B. 共同挑战，5–10 分钟。**成人明说一个目标，示范必要知识；儿童可接受、简化或拒绝；一次一变量。  
**C. 收尾，1–3 分钟。**提前预告，走到自然终点；最多问“哪一步有用/下次改哪一步/这个方法还可在哪试”中的一个。疲劳时只整理。

### 4.3 提示阶梯

```text
等待
→ 环境线索
→ 手势/指图
→ 一个关键词
→ 二选一
→ 示范一步
→ 共同完成
```

同样完成率下提示下降可以是进步。每次只撤一种提示；撤后失败就恢复，不惩罚。

### 4.4 合作局最低结构

1. 有全队共同目标，不以个人赢者结束；
2. 每人有不可替代但负担适当的输入；
3. 角色可轮换，拒绝某角色不等于拒绝合作；
4. 行动前有复述或确认门；
5. 异议和求助不会扣分；
6. 结束时共享署名，最多复盘一个过程动作。

没有兄弟姐妹或同伴时，可由父母、祖辈或两个玩偶承担角色；这只练流程，不算真实同伴迁移。

## 5. ADHD 叠加层

### 5.1 八项通用支架

1. 桌面只留当前材料；
2. 用 3–5 格板显示步骤和终点；
3. 靠近后一句一动作，等待约 5–10 秒；
4. 先允许摆、指、移动，再要求解释；
5. 每人每轮只持一个任务或发言物；
6. 具体反馈行为：“你复述后才执行”，不说“真乖、真聪明”；
7. 转换前预告，保留自然收尾和“下次盒”；
8. 每次只撤一种支架。

### 5.2 竞争或讨论过载的降档

```text
去排名和个人输赢
→ 改共同任务
→ 减少角色/信息
→ 每人只说一句或摆一张卡
→ 回 6 岁起步
→ 只做儿童主导连接
→ 改日
```

高唤醒时成人先降低音量、语速和词数，移开危险物，描述事实并给两个真实选项；恢复后才讨论规则和修复。不要故意让孩子输来“练挫折”。

### 5.3 不能由游戏替代

- 多场景 ADHD 与共存问题评估；
- 完整 PTBM/BPT、PCIT 或课堂行为支持；
- 睡眠、听视力、语言、学习、焦虑和欺凌排查；
- 教师可执行的家校协作；
- 按指南进行的药物评估与监测。

若困难持续跨家庭和学校并影响安全、学习、同伴或家庭功能，或高质量支持约 8 周仍无有意义改善，应寻求合格专业评估，而不是增加游戏量。

## 6. 安全边界

### 6.1 战斗、赛车和城市服务题材

- 战斗机与战舰不瞄准人、动物和脸；可改成考察、补给、协商、护航与工程；
- 赛车使用轻软车辆、低速桌面轨道和软缓冲，不把撞击声当奖励；
- 医院、消防和电网只使用虚构物流与纸卡，不使用真实患者信息、药物、消防设备、插座、电线或开关；
- 儿童可以拒演“坏人”、伤亡、被困或灾害情节。

### 6.2 物理/STEM 材料

- 不使用散装强磁铁、磁力珠、可脱落小磁体、纽扣电池、裸露风扇叶片、激光、玻璃、尖锐金属、热熔胶和重砝码；
- 风只用纸扇或有完整防护罩且远离水的设备；低亮度手电不照眼，不聚焦阳光；
- 声音保持低音量、不贴耳；杯线电话若使用，只用短绳、坐姿、绝不绕颈；
- 轨道低于眼睛，运动方向清空；工程测试不用高处、破坏性加载和人体承重；
- 水盆活动由成人持续专注监督，结束立即倒空并擦干。

官方入口：[国家市场监管总局磁铁玩具提示](https://www.samr.gov.cn/zlfzj/qxcpzh/xcjy/art/2024/art_51e8d9b19da54702970ef9f5ca6537b2.html)、[CPSC 纽扣电池中心](https://www.cpsc.gov/Safety-Education/Safety-Education-Centers/Button-Cell-Coin-Battery-Information-Center)、[FDA 激光玩具安全](https://www.fda.gov/consumers/consumer-updates/laser-toys-how-keep-kids-safe)、[NIDCD 噪声安全](https://www.nidcd.nih.gov/health/how-loud-too-loud)。

### 6.3 消防真实规则

消防站游戏只处理开放日、模型整理和团队承载量。真实火警中儿童按家庭预案撤离或避险待救、求助和报告，不搜救、不灭火、不返回取物、不盲目穿烟。预定路线安全时立即撤离；通道被烟封或门明显发热时，不盲目开门，按成人事先制定并演练的本地预案避险和等待专业救援。桌面游戏不能替代真实设备维护和适龄演练。

### 6.4 反欺凌题材的模拟边界

- 全部使用虚构玩偶和低强度情境卡，不使用真实同学姓名、照片、班级群截图或孩子的既往事件作“题库”；
- 不真实推搡、堵门、抢夺、辱骂、起绰号、围观起哄或传播秘密；动作只由图标、定格位置和纸卡表示；
- 成人优先扮演提出不友善要求的虚构角色；儿童可只观察、指卡、让玩偶代演或拒绝任何角色；
- 不要求受影响角色说服对方、听对方解释、当面对质、立即原谅或共同复盘；欺凌候选不是儿童调解题；
- 说停只在安全时练；任何“直接离开”“找成人”“跳过这一局”都算完整成功；
- 不把“识别正确率”变成抓坏人竞赛，不故意设置逼真威胁来测试勇气；
- 网络局只用纸制界面，不登录真实账号、不搜索真实内容、不让儿童继续接触以“取证”。

以下任一出现就立即停止游戏：儿童说停、僵住、哭泣、明显退缩、异常兴奋地要求升级羞辱/暴力，或开始讲述真实伤害、威胁、身体接触、私密影像和被要求保守的秘密。

### 6.5 真实披露后的成人动作与升级

若儿童在游戏中说出真实经历，成人不继续教学或测试：

```text
停下游戏并确保眼前安全
→ 安静听儿童自由叙述，不连续追问
→ “谢谢你告诉我；这不是你的错”
→ 不承诺绝对保密，只说明会找能保护他的人
→ 记录儿童原话、时间地点和已知事实
→ 启动学校/当地保护、医疗或紧急程序
→ 约定何时向儿童反馈下一步
```

**当天联系学校并要求保护/跟进：**反复或很可能再发生、存在人数/体格/地位等力量差、推打或威胁、财物损坏、协同排斥、谣言/网络传播、儿童害怕返校，或第一位教职工未采取行动。家长描述日期、地点、可见行为、重复/力量差信息、功能影响、已尝试措施和希望的监督/复查，不替学校先下最终结论。

**立即使用所在地紧急、公安、医疗或未成年人保护通道：**武器、严重伤害或明确暴力威胁；性接触、索要/传播私密影像、勒索、抢劫、跟踪、仇恨暴力；网络诱约见面、住址暴露或即时人身危险；自伤、自杀言语或行为。

**考虑儿科/心理专业支持：**持续拒学、头痛腹痛、睡眠或进食改变、噩梦、退缩、成绩骤降、明显焦虑抑郁或自伤；实施伤害的儿童持续失控、残酷、携带武器，或可能也正遭受虐待。游戏剂量不能替代评估、学校环境改变和专业干预。

## 8. 航空航天：邀请、异议、边界、带教与英语

### 游戏 1｜空港任务板：邀请式分工

**主目标/副目标与明确非目标：**主目标是完成“邀请—听偏好—授权—回查”；副目标是清楚求助。非目标是命令服从、速度、全做完或用“谁最能干”评领导。

**材料与先备：**三项和平任务卡、偏好卡、接受/换岗/求助卡和“待选—进行—完成”任务板。成人先示范邀请可被拒绝。

**角色与儿童所有权：**儿童任协调员，选共同目标、邀请对象并授权做法；成人任队员，可接受、协商或拒绝。成人仍负责安全。

**8–15 分钟默认玩法：**

1. 共同选“迎接航班”等目标；
2. 儿童问每人偏好；
3. 用“你愿意……吗”逐项邀请；
4. 队员接受或换岗，儿童复述确认；
5. 各自执行；卡住者选提示、示范或搭手；
6. 回查遗漏并共享署名。

**直接话术：**

> “你愿意负责摆登机牌吗？不愿意可以换。”  
> “我听见你想做引导员，对吗？”  
> “这项怎么做由你决定；需要哪种帮助？”

**三档玩法：**

- **6 岁起步：**两任务、二选一，成人示范邀请。
- **7 岁进阶：**三任务，儿童完成邀请、授权和一次回查。
- **8 岁挑战：**加入一项无人认领任务，由儿童重组、亲自承担或缩小目标，不强派。

**ADHD 支架：**只展示当前栏；每人一张进行卡；完成即移栏；一句一邀请，可站着送卡。

**安全：**不用弹射件、真行李带和真实证件；走动区清空；不把“队长”变成服从权。

**设计理由与证据边界：**偏好可见、可拒绝和明确授权形成真实互赖；这是合作学习原则转化的【实施设计】，不证明现实领导身份或同伴接纳。

**观察指标：**三次机会中，完成“邀请+听完回应+确认授权”的次数与提示等级。

**近迁移桥：**收餐具时邀请家人自选一项，并保留换岗权。

**停止/降档：**出现命令、嘲笑拒绝、抢做或争权即暂停；降为成人示范一次邀请，儿童只选任务。

**与既有 40 局去重：**核心是按偏好邀请和授权，不是共同编任务、搭机场、资源采购或路线规划。

### 游戏 2｜发射前反对席

**主目标/副目标与明确非目标：**主目标是主持人主动邀请异议、准确复述后再决定；副目标是以事实说明顾虑。非目标是压服、辩赢、盲目勇敢或模拟真实航天安全。

**材料与先备：**纸火箭、发射台垫、“赞成/有顾虑/需核查”卡、两张虚构事实卡和“试行/延后/取消”卡。成人先说明反对方案不等于反对人。

**角色与儿童所有权：**儿童任任务主持，决定发言次序和虚构方案；成人任工程员，提出预设、可处理的顾虑。真实安全由成人否决。

**8–15 分钟默认玩法：**

1. 选“发射气象球”等和平任务；
2. 主持人邀请支持理由，再明确邀请反对席；
3. 工程员摆一张事实卡说明顾虑；
4. 儿童复述，工程员确认或修正；
5. 儿童选择纸面核查、修改或延后；
6. 说明决定回应了什么、仍未知什么，并把异议者写入贡献栏。

**直接话术：**

> “谁看到我们可能漏掉的事？”  
> “我先复述：你担心的是……对吗？”  
> “谢谢你让计划更完整；我们的决定是……”

**三档玩法：**

- **6 岁起步：**成人给一条顾虑，儿童从两个处理办法中选。
- **7 岁进阶：**儿童复述顾虑并选择处理办法。
- **8 岁挑战：**比较两条冲突顾虑，说明暂未解决项，不延长辩论。

**ADHD 支架：**三个席位固定；一次一张事实卡；发言物限制一句；复述句框可见。

**安全：**火箭只摆不弹射；不用倒计时、火焰、压力容器、电池或失败灾难。

**设计理由与证据边界：**在决定前保护异议通道，把领导从控制改为信息整合；一局不能证明心理安全、批判思维或现实工程能力。

**观察指标：**异议后能否在行动前准确复述，并作出有对应理由的处理。

**近迁移桥：**家庭周末方案确定前，固定问一次“有没有顾虑”，不强求少数同意。

**停止/降档：**若变成人格批评、逼人站队或引起灾难焦虑，立即停止；降为把顾虑卡分“已回应/待核查”。

**与既有 40 局去重：**核心是制度化保护异议，不是痕迹核查、资源取舍、公平分配或需要听证。

### 游戏 3｜编队暂停权

**主目标/副目标与明确非目标：**主目标是任何成员提出暂停后，负责人立即停、听完并协商重启；副目标是描述可见影响。非目标是快速反应、服从信号、艺术编队或奖励频繁喊停。

**材料与先备：**三架软飞机、慢行轨迹垫、每人一张暂停卡、“我看到/我需要/可重启”三格条。暂停无需先证明危险，也不扣分。

**角色与儿童所有权：**儿童先任负责人；成人任队员并提出预设的小顾虑。下一轮换角；提出暂停者决定自己是否准备重启。

**8–15 分钟默认玩法：**

1. 负责人邀请成员选择位置；
2. 全员确认慢行与间距；
3. 移动一小段，成人因“太近”亮卡；
4. 全部原地停，负责人说“我听”；
5. 提出者按三格条说明，负责人复述并邀请改法；
6. 提出者确认后重启，感谢其信息。

**直接话术：**

> “任何人都能暂停，包括你。”  
> “我先停，不急着解释；你看到了什么？”  
> “拉开距离后，你准备好重启了吗？”

**三档玩法：**

- **6 岁起步：**只需说“停”并指出问题。
- **7 岁进阶：**用三格条完成停—说—改—确认。
- **8 岁挑战：**处理两个不同需要，或由儿童作成员检验成人是否尊重暂停。

**ADHD 支架：**只走一段；暂停卡常在手边；地垫画停机点；先摆后说；重启后即收尾。

**安全：**飞机贴垫慢移，不投掷、不追逐、不靠脸；真实身体不适无需解释即可退出。

**设计理由与证据边界：**把暂停权交给所有角色，并要求确认后重启，可练程序内发声与响应；不能推出真实群体表达或抑制控制改善。

**观察指标：**负责人是否立即停、复述准确、获得确认后才重启。

**近迁移桥：**合作积木时沿用同一卡，只处理“太挤/要倒”等即时问题。

**停止/降档：**暂停被嘲笑、忽略、用来控制人，或移动兴奋升级即停；降为静态摆位示范。

**与既有 40 局去重：**核心是成员授权与负责人响应，不是塔台等待、红绿灯切换或航空展审美改版。

### 游戏 4｜飞行学校新队员带教

**主目标/副目标与明确非目标：**主目标是先问学习者需要，再示范一步、观察尝试并按需反馈；副目标是主动选帮助。非目标是航空知识、连续命令、替做或优越感展示。

**材料与先备：**飞机、机库垫、一项“沿线滑行后停位”的简单任务，“看我做/提醒一句/一起做”帮助卡和四格带教板。成人不装笨或反复故意犯错。

**角色与儿童所有权：**儿童任教练，决定示范方式；成人任新队员，可提问、试做、拒绝反馈。安全范围内，学习者保留做法，教练不抢飞机。

**8–15 分钟默认玩法：**

1. 教练问“你想学哪一步”；
2. 新队员选帮助卡；
3. 儿童只示范一个动作并说关键点；
4. 成人复述后试做，儿童先观察；
5. 儿童征得同意后描述一个事实，再问是否要建议；
6. 成人再试或结束，双方说出各自贡献。

**直接话术：**

> “你想先看、听一句，还是一起做？”  
> “我先看你试，不抢过来。”  
> “我看到飞机越过停线；想听一个办法吗？”

**三档玩法：**

- **6 岁起步：**教一个动作，成人立即模仿。
- **7 岁进阶：**完成问—示范—试做—反馈。
- **8 岁挑战：**根据新手回应调整教法，或换角比较哪种帮助更合适。

**ADHD 支架：**每次只教一步；帮助卡代替长问答；教练手放自己停机点；默认只再试一次。

**安全：**只做低速桌面动作；不用真实设备、跑跳或蒙眼；学习者拒绝被评价时停止反馈。

**设计理由与证据边界：**示范、练习和及时具体反馈比无支架摸索更有依据；一次带教不证明教学能力、耐心或真实领导。

**观察指标：**成人试做前是否完成“询问帮助偏好+单步示范”，且未接管材料。

**近迁移桥：**请儿童教家人一个熟悉收纳步骤，仍先问帮助偏好。

**停止/降档：**嘲笑、假装无能、连环纠错、抢做或烦躁即停；降为儿童示范、成人照做一次。

**与既有 40 局去重：**核心是了解新手需要并调整支架，不是修理问答、交接日志、广播或角色互换。

### 游戏 5｜International Lost & Found：机场英语失物招领

**主目标/副目标与明确非目标：**主目标是用少量英语完成描述—核对—确认；副目标是听不清时请求重复。非目标是背长对话、纠口音、测词汇量，或处理真实失物与身份信息。

**材料与先备：**三张物品卡 `bag/hat/toy`、两张颜色卡、柜台和号码牌。只教 `I lost my ___.`、`Is this yours?`、`Yes/No` 和 `Again, please.`；成人先配图慢说。

**角色与儿童所有权：**儿童选旅客或柜员、物品和是否先指图；柜员只看候选物，旅客持答案卡，形成安全信息差。每轮可换角或改中文。

**8–15 分钟默认玩法：**

1. 看图听说三个词；
2. 旅客说或拼卡 `I lost my bag.`；
3. 柜员拿候选物问 `Is this yours?`；
4. 旅客答 `Yes, it is.` 或 `No, it isn't.`；
5. 听不清可说 `Again, please.`；
6. 找到后交号码牌并换角，最多三轮。

**直接话术：**

> “You can point and say: `I lost my toy.`”  
> “`Is this yours?`”  
> “没听清也完成了沟通：`Again, please.`”

**三档玩法：**

- **6 岁起步：**一物两候选，可指图补句。
- **7 岁进阶：**三物并轮换角色。
- **8 岁挑战：**只新增一个颜色词框 `It is red/blue.` 处理同类物，不再加句型。

**ADHD 支架：**词卡常驻；一次只摆两件；句框按顺序排列；可站着递牌；两轮后预告最后一轮。

**安全：**全用虚构卡；不用姓名、电话、证件、航班和真实遗失物；不用可吞咽小件。

**设计理由与证据边界：**小词集、图像、重复听说和信息差支持英语服务沟通；家庭短局不能证明自由口语、阅读、口音或成绩改善。

**观察指标：**三轮中，在何种提示下完成一次描述和一次核对；请求重复记为成功策略。

**近迁移桥：**隔天用书桌物品只复用同一句框，不扩词表。

**停止/降档：**出现羞耻、拒说、连续纠音或靠猜时停止；降为成人说、儿童指物，用中文收尾。

**与既有 40 局去重：**核心是英语信息差与核对修复，不是丢失货物路线、广播删选、修理对话或位置记忆。

## 9. 港口舰队：调解、少数意见、时间、反馈与求助

### 游戏 6｜港口调解台

**主目标/副目标与明确非目标：**主目标是调解者完成“听双方—核对摘要—支持下一步”；副目标是区分事实、影响与请求。非目标是判坏人、逼道歉、强求和好，或处理欺凌与安全事件。

**材料与先备：**两艘船、共享泊位、中性分歧卡、“事实/影响/请求”、暂停和暂不协议卡。

**角色与儿童所有权：**船员拥有自己的说法、请求和接受权；调解者只管轮次与摘要，不替双方决定。成人守安全边界。

**8–15 分钟默认玩法：**

1. 读“同时想用泊位”等中性分歧；
2. 甲船只摆一张事实卡；
3. 调解者复述，甲确认或纠正；
4. 乙船按同样流程表达；
5. 双方各补一项影响与请求；
6. 调解者邀请各提一个下一步；
7. 选择试行、修改或暂不协议；不协议就安全分开。

**直接话术：**

> “我先确认：你看到的是___，对吗？”  
> “调解不是判谁坏，而是让两边被准确听见。”  
> “可以不同意，也可以先安全分开。”

**三档玩法：**

- **6 岁起步：**用图卡和两个成人给定方案。
- **7 岁进阶：**儿童复述双方各一句。
- **8 岁挑战：**主持全程，标出一致项、未解决项和临时方案。

**ADHD 支架：**桌面只留当前角色卡；发言物标轮次；一句一问；可指卡。

**安全：**不用真实冲突、羞辱或秘密；威胁、欺凌和身体边界问题由成人直接处理，不让儿童调解。

**设计理由与证据边界：**外置三类信息降低组织负担，逐方核对减少误解；一局不能证明现实冲突能力。

**观察指标：**双方摘要被确认的比例；调解者越权下结论的次数。

**近迁移桥：**两人争同一画材时，只迁移“各说事实—复述—提请求”。

**停止/降档：**出现人身攻击、翻旧账或高唤醒即停；降为成人示范一方的一次复述。

**与既有 40 局去重：**不同于延误协商和出行听证，本局练第三方调解程序；也不评资源分配原则。

### 游戏 7｜舰队少数意见保险栓

**主目标/副目标与明确非目标：**主目标是在集体决定前保护未获多数支持的意见；副目标是复述理由并设置保障。非目标是少数必然正确、多数必然让步、强迫表态或无限否决。

**材料与先备：**三艘和平任务船、两个可行方案、同意/犹豫/反对/跳过卡、纸制保险栓和“已回应”板。

**角色与儿童所有权：**队长邀请、复述和检查遗漏，不能独占决定；船员拥有意见和跳过权。成人设真实安全边界。

**8–15 分钟默认玩法：**

1. 公布共同任务和两个可行方案；
2. 每人静默放表态卡；
3. 出现犹豫或反对就放保险栓；
4. 队长邀请说明，也允许跳过；
5. 队长复述，由原发言者核对；
6. 全队选择小测试、加保障或记录未知；
7. 决定采用、修改、并行试行或延期，并记录少数意见如何处理。

**直接话术：**

> “不同意见不是不合作，是新信息。”  
> “我先复述，不急着反驳。”  
> “领导负责让意见进来，不负责让所有人服从。”

**三档玩法：**

- **6 岁起步：**两人两方案，成人复述。
- **7 岁进阶：**儿童主持一次保险栓。
- **8 岁挑战：**区分偏好与安全担忧，并说明采纳或不采纳的理由。

**ADHD 支架：**先静默表态；每人一句；担忧只写一项；决定后翻完成牌。

**安全：**只用纸卡；不模拟攻击、投降或危险航行，不以真实隐私为异议材料。

**设计理由与证据边界：**先表态再讨论可减少跟随压力，复述门让异议可见；家庭局不证明真实群体心理安全。

**观察指标：**决定前，非多数意见是否得到准确复述并留下处理结果。

**近迁移桥：**家庭选共同活动时先问：“还有谁犹豫或想跳过？”

**停止/降档：**出现嘲笑、围攻或逼问理由即停；降为玩偶提异议、成人示范保护。

**与既有 40 局去重：**公平议会讨论分配，出行听证追踪需要；本局是静默表态—少数暂停—回应留痕。

### 游戏 8｜港口泊位时间拼图

**主目标/副目标与明确非目标：**主目标是把作业时长放入允许时间区间；副目标是辨认开始点、结束点、持续量和重叠。非目标是钟表竞赛、背乘法或找唯一最优表。

**材料与先备：**按 5 分钟分格的 0–30 分钟时间线、两个泊位、船舶窗口卡、时长块、起止标记和可选缓冲块。成人先示范“10 分钟”占两个格，不是一个点。

**角色与儿童所有权：**调度员提出排法；船长提供不可随意改变的窗口；港务员只查重叠与安全，不替儿童优化。

**8–15 分钟默认玩法：**

1. 翻第一艘船的窗口与时长；
2. 儿童放起点、整块时长和终点；
3. 加入第二艘船；
4. 检查越界或同泊位重叠；
5. 只移动一艘或增加一个泊位；
6. 再检查并读出“从___到___，共___分钟”；
7. 对比另一可行排法或结束。

**直接话术：**

> “九点是时间点，九点到九点十分才是区间。”  
> “先看整块能否装进窗口。”  
> “重叠说明排法要改，不说明全部算错。”

**三档玩法：**

- **6 岁起步：**用无钟面的彩色格和两船。
- **7 岁进阶：**读整点、半点或 5 分钟刻度。
- **8 岁挑战：**加第三船或缓冲块，解释两种可行排法。

**ADHD 支架：**时长用整块表示；一次只翻一船；当前窗口加框；每排一船立即查。

**安全：**不用真实赶船、倒计时或迟到惩罚；卡片足够大，真实港口安排不交儿童。

**设计理由与证据边界：**数轴和实物区间配合示范，可支持当前任务理解；不能据一局推断钟表、应用题或时间管理。

**观察指标：**能否独立放入完整区间，并发现越界或重叠。

**近迁移桥：**把“搭建 10 分钟、收纳 5 分钟”放入 20 分钟家庭活动线。

**停止/降档：**连续猜格、钟表焦虑或成人催快时停；降为两个彩色区间匹配。

**与既有 40 局去重：**旧时刻游戏练事件先后，停车场练空间容量；本局专练时间点、持续量和区间包含。

### 游戏 9｜联合航行反馈请求

**主目标/副目标与明确非目标：**主目标是在反馈前取得同意，由接收者决定类型、时机和是否采纳；副目标是以事实描述影响。非目标是借领导纠正别人、评价人格或强迫照改。

**材料与先备：**海图、两艘船和可修改航线；“现在/稍后/不听”“只听观察/可问问题/可给建议”“采纳/修改/暂不用”卡。

**角色与儿童所有权：**设计者拥有作品和修改权；观察员拥有反馈内容，但未经同意不输出。成人只直接处理真实安全。

**8–15 分钟默认玩法：**

1. 设计者说明想实现的目标；
2. 按草案航行一次；
3. 设计者主动请求某类反馈，或观察员先询问；
4. 获同意后只说一个观察及影响；
5. 再问是否需要建议；
6. 设计者选择采纳、修改或暂不用；
7. 试行一次后换角。

**直接话术：**

> “你现在愿意听一个观察吗？”  
> “我看见船在蓝线停住；这让交接中断。”  
> “谢谢，我只改这一处；其他保留。”

**三档玩法：**

- **6 岁起步：**只选“现在/不听”，成人示范事实句。
- **7 岁进阶：**选择反馈类型并决定采纳。
- **8 岁挑战：**提出精准反馈请求，比较修改前后并说明边界。

**ADHD 支架：**每轮一条反馈；类型卡可见；允许“稍后”；反馈后立即操作，不开长会。

**安全：**涉及人身、欺凌和现实危险时成人直接制止，不等待同意；本局只用于低风险作品。

**设计理由与证据边界：**同意门与采纳卡保护自主，事实—影响减少人格批评；一局不证明现实反馈素养。

**观察指标：**未经同意的反馈次数；事实和建议是否分开；接收者是否真可拒绝。

**近迁移桥：**看积木或画作前问：“想听观察、问题、建议，还是暂不听？”

**停止/降档：**讽刺、连发建议、假同意或拒绝受罚即停；降为只练询问同意。

**与既有 40 局去重：**通信站练消息确认，编队创作含作品反馈；本局核心是反馈前同意、类型选择和采纳权。

### 游戏 10｜船队求助灯

**主目标/副目标与明确非目标：**主目标是说明卡点、选择帮助剂量，并在帮助后取回任务；副目标是区分提醒、线索、示范和共同做。非目标是坚持到崩溃、证明完全独立或让成人接管。

**材料与先备：**两三步和平补给任务、纸制求助灯、“听我说/提醒目标/给线索/示范一步/一起做一步”卡、船长牌和归还牌。

**角色与儿童所有权：**任务船长拥有目标、材料和最终动作；支援船只给被请求的一小份帮助，随后归还船长牌。成人保留安全处置权。

**8–15 分钟默认玩法：**

1. 儿童从两个短任务中选一个；
2. 成人示范：“给我一个线索，不替我摆”；
3. 儿童开始，卡住时可亮灯、暂停或继续；
4. 支援者复述卡点与所选帮助；
5. 只给约定剂量；
6. 放回归还牌，由船长决定下一步；
7. 到自然节点后换角，指出哪种帮助刚好。

**直接话术：**

> “你要线索、看一步，还是一起做一步？”  
> “你选线索，我只提醒目标。”  
> “船长牌还给你；下一步仍由你决定。”

**三档玩法：**

- **6 岁起步：**从两种帮助中指选。
- **7 岁进阶：**说“我卡在___，请___”。
- **8 岁挑战：**先说已尝试办法，请求最小帮助并判断是否升级。

**ADHD 支架：**求助卡常驻；任务不超三步；成人等待后再问；一次一剂，完成即归还。

**安全：**不用真实故障、电器或水上活动；涉及火、电、吞咽和交通危险时成人立即处理。

**设计理由与证据边界：**外置帮助类型减少表达负担，明确归还防止包办；不能证明独立性、ADHD 改善或现实求助迁移。

**观察指标：**能否选匹配帮助；支援者越量次数；帮助后儿童是否重新决定下一步。

**近迁移桥：**作业或收纳卡住时问：“要听目标、要线索，还是一起做第一步？”

**停止/降档：**成人连续代做、求助被嘲笑或持续挫败即停；降为共同完成一步后结束。

**与既有 40 局去重：**核心是选择帮助剂量—限量支持—归还所有权，不是报告、修理对话或一般委托。

## 10. 汽车赛车：工作协调、证据核验与可靠执行

### 游戏 11｜维修站拉动看板

**主目标/副目标与明确非目标：**主目标是在维修位空出后自主拉取任务，并用邀请或求助协调；副目标是看懂“待修—维修中—完成”状态。非目标是练服从派单、速度、修车知识或真实维修。

**材料与先备：**三栏纸看板、3 张轻故障工单、一个“维修中”框、姓名夹、“提醒/示范一步/一起做”帮助卡、软车和大号纸零件；成人先示范“进行中只能一张”。

**角色与儿童所有权：**儿童是维修员，拥有选单、节奏和帮助类型；成人是看板员，只报告空位并守安全，不能点名派单或接管。

**8–15 分钟默认玩法：**

1. 把工单放“待修”，共同确认一次只修一辆；
2. 空位出现，儿童自选一单移入“维修中”，也可暂不拉；
3. 按卡做一个象征动作；卡住时选帮助卡；
4. 自检后移到“完成”，看板员只描述状态；
5. 儿童邀请下一位选择，不替对方决定；
6. 完成 2–3 单即关站，交换角色复盘一次。

**直接话术：**

> “维修位空了，你想拉哪张，也可以先不拉。”  
> “你要提醒、示范一步，还是一起做？”  
> “邀请不是命令，对方可以换单。”

**三档玩法：**

- **6 岁起步：**两单和全图示。
- **7 岁进阶：**独立走完整三栏。
- **8 岁挑战：**主持空位、邀请和同单冲突协商，只撤一种提示。

**ADHD 支架：**桌面只留当前车；三栏常显、完成即翻面；一句一动作；可站着送卡；两单后结束。

**安全：**只做纸面维修；不用真工具、电池、磁铁或可吞咽件，不滚车撞人。

**设计理由与证据边界：**拉动和在制品上限把任务所有权外显，属低风险实施设计；表现不证明自主管理、领导力或 ADHD 改善。

**观察指标：**3 次空位中，自主拉取或明确暂缓几次；求助是否保留选择权；记录提示等级。

**近迁移桥：**整理桌面时设一个“进行中”位，做完再自选下一件。

**停止/降档：**出现抢单、派单争执、成人催快或车辆冲撞即停；降为一张工单共同完成。

**与既有 40 局去重：**旧修理厂练问题—回应—确认；本局核心是空位—拉取—限量—求助的工作所有权，不练对话脚本、路线或故障推理。

### 游戏 12｜赛车圈数双裁判

**主目标/副目标与明确非目标：**主目标是两份记录不一致时，用可见证据核对而非凭身份定输赢；副目标是一一计数圈牌和看见缺口。非目标是比速度、名次、时间、均速或心算，也不鼓励撞击。

**材料与先备：**胶带短环道、轻软车、终点停车格、3–4 枚大圈牌、A/B 两条计数板、“一致/待核验”卡和软边界；成人先摆一例 A=3、B=2 的记录。

**角色与儿童所有权：**儿童自选司机或裁判，可质疑任何记录；两名裁判各管自己的板，不能偷改对方答案。成人只守低速和核对流程。

**8–15 分钟默认玩法：**

1. 先核对示例：两板逐格对齐，只说“这里差一格”；
2. 约定本局 3 圈、每圈过线即停车，不计时；
3. 司机慢推一圈并把一枚圈牌放入证据区；
4. A/B 裁判各移动一格，再放行下一圈；
5. 结束后把两板与圈牌逐一配对；
6. 一致就共同确认；不一致则标“待核验”，找第一处缺口，不猜谁错；
7. 换角再做一局或直接收车。

**直接话术：**

> “我们核对记录，不评谁更聪明。”  
> “看得见的圈牌有几枚？哪一板有空格？”  
> “证据不够就写待核验，不靠大人拍板。”

**三档玩法：**

- **6 岁起步：**两圈，成人协助配对。
- **7 岁进阶：**三至四圈并独立双记。
- **8 岁挑战：**主持分歧核对，说明何时只能保留未知，不增加速度。

**ADHD 支架：**每圈停车形成小终点；圈牌不遮挡；司机与裁判轮换；最多四圈；不用口头记忆追数。

**安全：**地面或低桌慢推，清空行进方向；软边界只防意外，不作撞击目标；不追车、不抛车。

**设计理由与证据边界：**独立记录和一一配对让分歧可修复；只支持当前任务内核对，不能推出数学成绩、公正人格或真实赛事裁判能力。

**观察指标：**两次记录比较中，儿童能否先配对再指出一致、缺一或未知，并记录所需提示。

**近迁移桥：**数洗好的袜子时两人各摆一列，有差异就逐双配对。

**停止/降档：**开始抢跑、撞车、争输赢或用“作弊”指责人时停；降为静态两列圈牌找缺口。

**与既有 40 局去重：**不同于坡道单变量、红绿灯切换和碰撞修复；本局核心是双记录—证据对账—保留未知。

### 游戏 13｜智能车传送带算法诊所

**主目标/副目标与明确非目标：**主目标是沿纸卡顺序追踪执行，在第一处不符合目标的位置停下，只改一张卡再复测；副目标是说清“输入—动作—结果”。非目标是用电脑或真实传送设备、测编程语法、速度或算法天赋。

**材料与先备：**四格纸传送带、纸车、包裹卡、起点/目标格、图示指令卡“拿起、前进一步、放下、停止”、诊断夹和版本框；成人先演示按卡执行，不替程序补意图。

**角色与儿童所有权：**儿童是算法医生，拥有排卡、修改和保留版本的权利；成人是执行器，只逐卡行动，不偷偷纠错。

**8–15 分钟默认玩法：**

1. 选一个包裹和目标格；
2. 儿童排 3–5 张指令并指出预期结果；
3. 成人从左到右逐张执行，完成一张翻一张；
4. 首次偏离目标时夹住该处并停止；
5. 儿童移动、替换或补一张卡，其余保持；
6. 从起点复测，比较版本一和版本二；
7. 成功或两次修补后结束，说“我改了___，结果___”。

**直接话术：**

> “执行器只照卡走，不猜你的意思。”  
> “先找第一处不同，不必全推倒。”  
> “一次只改一张，才看得出它有没有用。”

**三档玩法：**

- **6 岁起步：**用三张成人备选卡。
- **7 岁进阶：**独立排四至五张并修一次。
- **8 岁挑战：**用第二个包裹作测试，解释规则何时适用，不加电子装置。

**ADHD 支架：**只露当前卡和下一卡；已执行即翻面；诊断夹固定注意点；可站着移动车；两轮即收尾。

**安全：**只用纸卡和轻软模型；不用电机、插座、磁铁或自动传送带；车不驶向人和桌边。

**设计理由与证据边界：**可见序列与局部修补降低记忆负担；纸面调试不证明计算思维、执行功能或智能车知识。

**观察指标：**最多两次故障中，能否指出第一处偏差并只改一张卡；记录独立/提示/共同完成。

**近迁移桥：**用“拿杯—接水—放桌”三图检查漏掉的第一步。

**停止/降档：**反复推倒全套、成人代改、儿童因“出错”羞耻或车被加速时停；降为成人排两卡、儿童找顺序。

**与既有 40 局去重：**旧多站配送重路线顺序，货运编组重分类；本局独有“执行—定位首个偏差—单卡补丁—复测”的算法循环。

### 游戏 14｜Pit-stop English Coach：维修站英语教练

**主目标/副目标与明确非目标：**主目标是在图示和可请求支架下听懂并执行唯一指令 `Put the wheel in the blue tray.`；副目标是教练等待、按学习者选择提供帮助。非目标是加第二条指令、测背诵、口音、流利度或修车知识。

**材料与先备：**大轮子卡、蓝托盘、带图句条、听—做—检查三卡和中文“再说一次/指给我看/暂停”卡；成人先示范唯一句义。

**角色与儿童所有权：**儿童选机械师或教练；机械师可请求重复、看图、只用动作回应和停止；教练不能纠音、抢放或换词。

**8–15 分钟默认玩法：**

1. 一起看轮子、托盘和句条，成人读一句并示范；
2. 复位，教练只说：`Put the wheel in the blue tray.`;
3. 机械师可选中文帮助卡，教练按选择重说或指图；
4. 机械师把轮子放入托盘；教练只核对意思；
5. 交换角色，仍用相同句子；
6. 做 2–4 轮，以动作成功或主动暂停收尾。

**直接话术：**

> “今天英语只有这一句。”  
> “没听懂可选再说一次或指图。”  
> “动作表达正确意思就完成，不用模仿口音。”

**三档玩法：**

- **6 岁起步：**保留全图并可立即跟做。
- **7 岁进阶：**先听后自选是否看图。
- **8 岁挑战：**由儿童当教练，等待对方选支架并检查自己有没有多说，句子不变。

**ADHD 支架：**材料只留一轮一盘；三步卡常显；每句后等待 5–10 秒；可站着送轮卡；四轮封顶。

**安全：**只用大号纸卡和轻托盘，不用真轮胎、千斤顶、工具或可吞咽零件；不模拟高速进站。

**设计理由与证据边界：**同一句在听、动作、角色反转中重复，降低新词负荷；家庭 EFL 表现不能证明一般英语理解、发音或课堂迁移。

**观察指标：**3 次机会中，儿童在何种支架下完成动作或主动求助；不记录口音和复述长度。

**近迁移桥：**隔天换维修站背景，仍用同一轮子、蓝托盘和同一句指令。

**停止/降档：**出现逼读、连环纠音、偷换英文、沉默被评价或儿童说停时结束；降为成人说句子并共同做一次。

**与既有 40 局去重：**旧修理厂练中文问题—回应—确认；本局只练单一英语祈使句的理解、支架请求和教练等待，不是失物描述或自由对话。

### 游戏 15｜零件库存诚实官

**主目标/副目标与明确非目标：**主目标是独立核对库存，如实报告“够、缺、多或未知”，不为迎合订单改记录；副目标是用一一对应数可见存量和缺口。非目标是练心算或金钱、抓“小偷”、评诚实人格或处理真实贵重库存。

**材料与先备：**3–6 格零件订单卡、大号纸零件、逐格核对垫、“够/缺/多/未知”卡、报告夹；成人公开准备数量不符的一例，不藏件设陷阱。

**角色与儿童所有权：**儿童是库存诚实官，拥有独立摆放、复点和选“未知”的权利；成人是申请员，不能暗示“必须够”或改记录。

**8–15 分钟默认玩法：**

1. 翻一张订单，诚实官先指所需轮廓；
2. 库存逐件放上轮廓，一格一件；
3. 数已填格、空格或剩余件，只看眼前数量；
4. 选择“够、缺、多或未知”；缺口直接数空格，不做脱离材料的算式；
5. 必要时沿格复点，把状态夹到报告上；
6. 申请员据报告改订单或等待，不要求改答案；
7. 换角再核一单，2–3 单关库。

**直接话术：**

> “订单要五个，不代表盒里有五个。”  
> “空格就是看得见的缺口。”  
> “看不清可报未知；诚实不是猜数。”

**三档玩法：**

- **6 岁起步：**用三至四格，只判够/缺。
- **7 岁进阶：**加入多和一次复点。
- **8 岁挑战：**比较两份独立记录，用核对垫处理分歧，仍不口算。

**ADHD 支架：**一次一单；零件排成行；手指逐格移动；状态卡加图形；三单封顶。

**安全：**只用大号纸件，不用磁珠、螺丝、电池、尖锐或真实汽车零件；不藏件、不投掷。

**设计理由与证据边界：**一一对应外置存量和缺口，“未知”减少迎合；表现不证明数学掌握、道德品质或现实库存能力。

**观察指标：**3 单中，儿童独立/提示后正确标状态几次；数量不符时是否保留记录并报告可见缺口。

**近迁移桥：**收画笔时对照笔槽，报告“已放几支、还空几格”。

**停止/降档：**出现藏件抓错、指责撒谎、催报想要的数或计数挫败时停；降为三格一一配对。

**与既有 40 局去重：**旧资源采购重取舍，停车场重空间容量，货运编组重分类；本局是独立对账—报告缺口—保留未知。

## 11. 火车、公交与邮政：来源、分合、规则试行与英语澄清

### 游戏 16｜列车故事接力调度

**主目标/副目标与明确非目标：**主目标是每次接续前标明“沿用谁的设定/我新增什么”，区分共同来源与个人创编；副目标是因果连接、倾听和交接。非目标是背原句、排固定先后、比故事精彩、测识字作文或记忆。

**材料与先备：**3–4 张无文字场景卡、角色卡、列车三节“已有—新增—署名”槽，姓名/图标章、“不确定来源”卡、终点站卡。成人先示范“蓝桥是卡上已有；会唱歌是我新编”。

**角色与儿童所有权：**儿童先选调度员或创作者；创作者拥有自己新增内容，可改、删或不授权成人续写；调度员只复述和标来源，不替作者润色。轮换一次。

**8–15 分钟默认玩法：**

1. 看一张起点卡，调度员签收已有设定；
2. 创作者加一个事件并放署名章；
3. 下一人先复述“卡上/某人说过”，再新增一段；
4. 来源忘记就放“不确定”，不猜；
5. 三次交接后共同命名，到终点即收。

**直接话术：**

> “这一点从哪里来？”  
> “我沿用你的___，我新编___。”  
> “忘了来源可以标不确定；创编不是把别人的话算成自己的。”

**三档玩法：**

- **6 岁起步：**两人两段和图章。
- **7 岁进阶：**三次接力，每次说来源与新增。
- **8 岁挑战：**加入两位作者的兼容设定，由儿童主持署名争议，可撤一句提示。

**ADHD 支架：**桌面只留当前卡；三槽外置；每轮只加一件事；可站着送章；最后一站可见。

**安全：**只演日常旅行，不设脱轨、失踪、被困；不用真实姓名、学校、住址，儿童可拒绝任何剧情。

**设计理由与证据边界：**把来源标签嵌入创编，避免“复述”和“原创”混为一谈；一局不能证明写作、记忆、诚信或总体语文提升。

**观察指标：**3 次合格接续中，先标来源再新增的次数及最低提示级别。

**近迁移桥：**共编绘本时用“原图给的/你说的/我新增的”三类贴签。

**停止/降档：**出现抢署名、擅改他人内容、归属争执持续或儿童说停，立即降为两张卡一轮。

**与既有 40 局去重：**不是旧“时刻与故事排序”的时间排序，也不是“广播编辑”的信息删选；核心是创编所有权与来源链交接。

### 游戏 17｜站台新闻署名台

**主目标/副目标与明确非目标：**主目标是分开“稿件作者”和“信息来源”，给虚构站台新闻准确署名、标来源；副目标是概括、提问和共享功劳。非目标是判断真人说谎、追求新闻腔、写字量、识字速度或记住全部细节。

**材料与先备：**纯虚构站台图、目击/角色转述/待核实三类来源卡，“标题—来源—署名”新闻卡、故事角、修正贴。成人先示范：“小熊说伞丢了”中，小熊是来源，写卡的人是作者；想象细节应进故事角并署创编者。

**角色与儿童所有权：**儿童选记者、消息提供者或编辑；提供者拥有原意并可纠正引用，记者拥有表述但不能添加未标明事实，编辑只查来源链、不擅改稿。每轮换角。

**8–15 分钟默认玩法：**

1. 抽一幅事件图；
2. 提供者给一条所见或角色转述；
3. 记者复述并将来源卡入槽；
4. 写、画或口述一句消息，另放作者章；
5. 提供者核对原意；
6. 不确定项贴“待核实”，创编项移故事角；
7. 发布两张即收台。

**直接话术：**

> “谁写的，不等于消息来自谁。”  
> “这是你看见、听谁说，还是新编？”  
> “来源不清先待核实，不补得像真的。”

**三档玩法：**

- **6 岁起步：**二选一来源图并分开放作者章。
- **7 岁进阶：**完成来源、署名、核对。
- **8 岁挑战：**处理两种来源表述不同的消息，保留差异并写明各自来源，不裁判谁坏。

**ADHD 支架：**一次一图一事实；三槽固定；允许贴图代写；发布数可见；每轮只问一个来源问题。

**安全：**不用真实同学、照片、校名、事故或隐私，不把成品公开上传，不编指控和谣言。

**设计理由与证据边界：**署名与来源分槽，让归属成为可见动作；不能由一局推断阅读、诚信、媒体素养或现实辨伪能力。

**观察指标：**两张稿中，作者与来源均分开标明且新增内容未冒充事实的张数。

**近迁移桥：**介绍家庭作品时说“谁做的、信息/想法从哪里来”，未知就留空待问。

**停止/降档：**出现真人影射、嘲笑、抢功、逼供式追问或儿童不愿被署名时立即收台。

**与既有 40 局去重：**不是“站台广播编辑”的必要信息删选，也不是“广告真假侦探”的证据裁决；核心是作者—来源—引用的归属链。

### 游戏 18｜邮票凑额合作柜台

**主目标/副目标与明确非目标：**主目标是把一个目标总额分成两部分，再合并核验，发现同一总额可有不同分法；副目标是轮流贡献和请求核对。非目标是心算速度、找零、乘法、真实邮资、稀缺分配或谁贡献更多。

**材料与先备：**大号虚构邮票卡（1、2、3、5）、6–10 的目标封套、数框/数轴、“部分 A—部分 B—整体”垫、核验章。成人预查每个目标至少有两种组合；不用真实邮票、地址和可吞咽小片。

**角色与儿童所有权：**儿童选配票员或核验员；配票员决定一种分法，核验员只能按数框重数、指出差额，不能抢卡代摆。双方各有一盒票卡并轮换。

**8–15 分钟默认玩法：**

1. 抽一个目标放入整体格；
2. 两人各从自己的盒中贡献一部分；
3. 先分别数部分，再合到数框核验；
4. 不足或超出只改一边；准确后盖章；
5. 保持总额，换其中一部分找第二种分法；
6. 最多完成三封。

**直接话术：**

> “整体要___，你这部分___，还需要多少？”  
> “两部分变了，整体还能一样吗？”  
> “核验员只报告差多少，办法归配票员。”

**三档玩法：**

- **6 岁起步：**总额 6 以内，两种可见组合。
- **7 岁进阶：**总额 10 以内，找两种分法。
- **8 岁挑战：**可到 20，加入一种票值暂缺或三部分合成，并说明什么变、什么不变。

**ADHD 支架：**只摆当前封套和两盒票卡；数框外置；一人一次一张；完成格清楚；可站立送票，不限时。

**安全：**卡片足够大且无尖角，不舔“邮票”、不交换真实钱物，不写个人地址；掉地立即停步捡取。

**设计理由与证据边界：**实物分开—合并呈现部分整体关系，但不能证明稳定运算、应用题迁移、合作品格或数学成绩提高。

**观察指标：**3 次合格机会中，能形成目标总额并说、指或摆出两部分的次数与提示级别。

**近迁移桥：**用积木把 8 分成两盒，再换一种分法，保留同一部分—整体垫。

**停止/降档：**转为抢票、比快、嘲笑算错、成人代摆或材料入口时，降为成人示范一个 5 以内分合。

**与既有 40 局去重：**不是“机队采购”的资源取舍，也不是“补给议会”的公平分配；没有稀缺决策，核心是总量不变下的数的分合。

### 游戏 19｜公交公约试行员

**主目标/副目标与明确非目标：**主目标是把一条共玩公约当作可修订方案，用试行情境的影响决定保留或改一处；副目标是邀请异议、说条件。非目标是服从测试、制定真实公交法规、评好乘客、处罚违规者或训练现实乘车安全。

**材料与先备：**静止玩具公交、乘客偶、2–3 张低风险公约卡（如“发言物到手再说”“想暂停可举卡”）、两个边界情境、“有效/有困难/信息不足”板、异议卡、修订贴。成人预备一条需在边界情境中修改的规则。

**角色与儿童所有权：**儿童选试行主持或乘客；主持人说明、邀请反馈和记结果，无权压下异议；乘客有暂停、跳过和反对权；成人只守安全底线，不把偏好称作法规。

**8–15 分钟默认玩法：**

1. 共同选一条并说试行范围；
2. 用玩偶演普通情境，受影响角色放结果卡；
3. 再演边界情境；
4. 主持人先复述异议，再依据两张结果保留、加“如果/除非”或改一个词；
5. 用一个情境复测，贴“本局暂行”，到站结束。

**直接话术：**

> “这是试行，不是永远正确。”  
> “谁受到影响？异议补了什么信息？”  
> “我们只改一处，再看结果。”

**三档玩法：**

- **6 岁起步：**从两条公约选一条，演一景并选结果。
- **7 岁进阶：**试两景、改一处。
- **8 岁挑战：**主持少数意见，写出适用条件，并比较原版与修订版，不增加惩罚。

**ADHD 支架：**一次一规则；“选—试—听—改”四格板；玩偶代言；每人一句；终点可见，兴奋时改静态摆卡。

**安全：**只在桌面或地面静止模拟，不到真实车辆、站台或道路试验；不奔跑急停，成人安全决定优先。

**设计理由与证据边界：**按影响反馈修订规则，练程序而非盲从；一局不能证明公民意识、现实守规、领导力或同伴接纳。

**观察指标：**儿童最终决定前是否引用至少一张试行结果，并准确复述一个异议。

**近迁移桥：**家庭共用桌试行一条低风险规则一天，约定复盘点和成人安全边界。

**停止/降档：**规则被用于控制、羞辱、排斥或惩罚真人，争论升级或儿童说停，立即取消“主持权”。

**与既有 40 局去重：**不是“护航规则切换”或“红黄绿灯”的信号转换，也不是安全漫画；核心是公开规则—影响取样—有限修订—复测。

### 游戏 20｜International Post Office：国际邮局英语澄清台

**主目标/副目标与明确非目标：**主目标是英语没听懂或指代不清时，主动选择澄清方式并确认意思后再行动；副目标是少量邮局词汇和轮流。非目标是测口音、纠音、背长对话、词汇量、语法完整、反应速度或装作听懂。

**材料与先备：**空纸包裹、虚构地点/物品图、两张相似目的地卡，四张双语图示句框：`Please say it again.`、`Please point.`、`What does ___ mean?`、`Do you mean ___?`，确认章和停止卡。成人只用自然清楚英语，不模仿任何口音；混淆来自卡片信息差。

**角色与儿童所有权：**儿童先选 clerk 或 customer；说话者拥有原意，可重复、指图或换说法；听者拥有“不懂”、选中文支架和暂停权，不必猜。成人不得替儿童回答或以发音决定是否通关。

**8–15 分钟默认玩法：**

1. 先教两句并示范对应情境；
2. 抽一张“没听到/不知道词/两个地点像”信息差卡；
3. 顾客给短消息；
4. 职员指出自己哪处不懂，选一句澄清；
5. 顾客按请求修复；
6. 职员用 `Do you mean…?` 或指图确认，得到确认才分拣；
7. 2–3 轮后换角。

**直接话术：**

> “Not understanding is okay.”  
> “Which part is unclear?”  
> “Please point.”  
> “Do you mean the blue station?”

不因使用中文辅助扣分。

**三档玩法：**

- **6 岁起步：**两句框、两图二选一，可全程指。
- **7 岁进阶：**按三类“不懂”选择合适句框并确认。
- **8 岁挑战：**自组针对性问题或换说法，并说明为何有效，不延长台词。

**ADHD 支架：**一次一包裹一障碍；句框常显；先指再说；三格“说不懂—澄清—确认”；轮次和终点可见。

**安全：**不用真实姓名、地址、证件、邮资或包裹，不含秘密/违禁品剧情，不以国家和口音做笑料。

**设计理由与证据边界：**把“不懂”变成可操作的沟通修复，而非发音评判；不能据此推断英语水平、自信、听力障碍或现实跨文化能力。

**观察指标：**合格不清消息中，行动前完成“指出不懂—提出澄清—确认意思”的次数/机会及提示级别。

**近迁移桥：**家庭英语活动中遇到含糊手工指令，保留同一句框请求重复、指示或释义。

**停止/降档：**出现口音模仿、羞耻、连续三次仍不懂、成人连环纠错或儿童说停，立即改中文加图片或结束。

**与既有 40 局去重：**不是“海图密码站”的公开代码解码，也不是“修理厂”的一般问答；核心是按不懂类型选择英语澄清策略，不测口音。

## 12. 城市服务：主持、信息节制、概念辨析、模型与承载量

### 游戏 21｜城市服务圆桌：安静声音主持人

**主目标/副目标与明确非目标：**主目标是用近距离可听清的安静声音邀请、复述并保护异议；副目标是形成一项试行建议。非目标是比音量、强迫发言、评“领导气质”或决定真实城市事务。

**材料与先备：**虚构的公园、图书馆、公交站需要卡；议程条、发言物、跳过卡、异议卡和三级音量图。成人预备两个均可行方案。

**角色与儿童所有权：**儿童主持流程，不拥有他人的意见或最终答案；各代表拥有自己的需要、跳过权和更正权。成人守时间与安全边界。

**8–15 分钟默认玩法：**

1. 每名代表放一张需要卡；
2. 主持人用安静声音逐一邀请，也接受指卡或跳过；
3. 每听一项先复述，原代表确认后才记录；
4. 主持人邀请一次不同意见；
5. 全组选择一个可逆方案，标明未解决项；
6. 试摆一分钟，再保留或改一处。

**直接话术：**

> “我先确认：你需要的是___，对吗？”  
> “可以说、指卡或跳过。”  
> “声音安静不等于意见要退让。”

**三档玩法：**

- **6 岁起步：**用两代表、两方案。
- **7 岁进阶：**主持完整“邀请—复述—异议—总结”。
- **8 岁挑战：**处理一次打断或沉默，并说明主持权不等于决定权。

**ADHD 支架：**议程逐格翻面；每轮一人一句；允许站立主持；成人不用“再大声点”连催。

**安全：**不模拟投诉围攻、治安或应急会议；不评论儿童嗓音、口音和性格。

**设计理由与证据边界：**流程权与内容权分开，可减少抢话；一局表现不证明现实领导力或同伴接纳。

**观察指标：**总结前是否准确复述至少两项意见，并邀请一次异议或跳过。

**近迁移桥：**家庭讨论周末小活动时沿用同一轮盘。

**停止/降档：**出现嘲笑声音、强迫表态、主持人包办或儿童说停即降为双人复述。

**与既有 40 局去重：**核心是低音量主持、发言可及性与异议保护，不是听证取舍、共同设计或资源分配。

### 游戏 22｜医院物流隐私护航

**主目标/副目标与明确非目标：**主目标是只传递完成虚构物流所需的最少信息；副目标是闭环交接。非目标是记病历、猜身份、学习诊疗或把保密责任交给儿童。

**材料与先备：**纸制床单、空文件盒、绘画纸等供应卡；虚构部门代码；“目的地—物品—数量/轻放”标签槽；封套、删除贴、确认卡及无关资料卡。不得填写家庭、儿童、患者或工作人员真实信息。

**角色与儿童所有权：**请求员拥有需求；隐私护航员只删无关字段；配送员只看最终标签；接收员确认。成人预审全部虚构内容并承担现实隐私责任。

**8–15 分钟默认玩法：**

1. 请求员生成一张供应需求；
2. 全组判断配送者完成任务必须知道什么；
3. 护航员删去姓名、爱好、原因故事等无关虚构资料；
4. 将最少必要标签装入封套；
5. 配送员仅按标签送到部门盒，不规划复杂路线；
6. 接收员复述物品与目的地；信息不足时只补缺项；
7. 交换角色一轮。

**直接话术：**

> “完成任务必须知道哪几项？”  
> “好奇不等于有必要知道。”  
> “少给信息，但不能少到需要猜。”

**三档玩法：**

- **6 岁起步：**从完整/多余两标签中选择。
- **7 岁进阶：**独立删一项并完成确认。
- **8 岁挑战：**为请求员、配送员设计不同可见字段并说明理由。

**ADHD 支架：**每轮一个封套；三槽固定；搬卡代替长说；只纠正一个字段。

**安全：**不用真实患者、药物、病情、医院单据或信息；不进入真实医院执行。

**设计理由与证据边界：**按角色限制信息可呈现“最少必要”；游戏不是法律、医疗或信息安全培训。

**观察指标：**最终标签是否足够完成交接且不含预设无关字段。

**近迁移桥：**请家人取普通物品时只说物品、位置和必要特征。

**停止/降档：**开始询问真实隐私、故意偷看或因删信息争执时，改用纯图形货物。

**与既有 40 局去重：**核心是分角色的信息可见范围，不是多站配送、广播压缩或代码解码。

### 游戏 23｜医院推车等号维修师

**主目标/副目标与明确非目标：**主目标是理解等号表示两边的值相等；副目标是区分数学等量与推车的物理平稳。非目标是口算竞速、真实医院搬运、称重或教授转矩公式。

**材料与先备：**等号垫、同单位计数片、真假算式卡、数字卡；不滚动的纸板推车轮廓、左中右位置格、带质量图标的大号泡沫块及“等量/平稳”分类牌。

**角色与儿童所有权：**儿童是等号维修师，决定如何修算式；成人是装载安全员，提供物理模型事实并阻止把两种“平衡”混为一谈。

**8–15 分钟默认玩法：**

1. 用计数片验证 `5=3+2`，说“两边值相等”；
2. 修复 `5=4+2`，可改任一边但须重新核验；
3. 将“算式维修”和“装载维修”分到两区；
4. 看一张数量相等但全放一侧的装载图：数学可相等，推车仍可能不稳；
5. 看一张件数不同但质量、位置安排后可平稳的模型图；
6. 儿童完成一句区别说明并换角出题。

**直接话术：**

> “等号不是‘答案来了’，是两边值相等。”  
> “数量相等，不保证推车平稳。”  
> “物理平稳要看质量和位置，不能靠等号证明。”

**三档玩法：**

- **6 岁起步：**配对实物等量。
- **7 岁进阶：**修一个假算式并分类。
- **8 岁挑战：**自行设计“数学真但装载不稳”的反例。

**ADHD 支架：**两块工作垫分色；一次一张卡；允许摆片后再解释；结束格可见。

**安全：**不用真实推车、患者、药物或重物；不骑坐、推跑或做人体验。

**设计理由与证据边界：**并列反例可阻止“等号就是秤平”的误解；纸卡模型不证明真实结构稳定性。

**观察指标：**能否正确修一式，并说出数量等量与物理平稳的不同依据。

**近迁移桥：**分点心时谈等量；整理书包时另谈重量位置。

**停止/降档：**材料被投掷、儿童混乱加重或成人开始讲超龄公式时降为等量配对。

**与既有 40 局去重：**不是公平分配或船体单变量试验，而是比较两套不可互换的“平衡”概念。

### 游戏 24｜气象联席影响图

**主目标/副目标与明确非目标：**主目标是把一个假设天气条件画成可修订的跨服务影响模型；副目标是标注未知与需核实处。非目标是做真实预报、发布预警、决定停课、交通或任何应急行动。

**材料与先备：**醒目的“模型，不是预报”牌；“假设短时小雨/较热的一天”等温和情境卡；公园、公交、图书馆、清洁组节点；“可能影响、还需核实、反馈回来”箭头和事实/假设贴。

**角色与儿童所有权：**气象角色只读假设输入；各服务代表拥有本节点信息；儿童协调员经代表确认后连线，无权替团队下结论。成人负责现实天气信息。

**8–15 分钟默认玩法：**

1. 选一张假设卡并盖“非预报”章；
2. 各代表放一个直接影响或“未知”；
3. 协调员连接“天气条件→服务变化”；
4. 再加一层跨团队影响，每条箭头说清“可能因为”；
5. 给未经核实的连接贴问号；
6. 只改变一个假设，如持续时间，删改受影响箭头；
7. 指出模型中一个仍不知道的地方。

**直接话术：**

> “这是如果……可能……的模型，不是明天的预报。”  
> “这条箭头是谁确认的？”  
> “模型可以改；未知不能用猜测填满。”

**三档玩法：**

- **6 岁起步：**完成两节点单链。
- **7 岁进阶：**画一条跨团队链并标未知。
- **8 岁挑战：**改变一个前提，主持全图局部更新。

**ADHD 支架：**节点不超过四个；箭头逐张出现；可站着连图；每轮只扩一层。

**安全：**不用当前恶劣天气、灾害音效或真实应急方案；现实行动听成人及当地权威信息。

**设计理由与证据边界：**影响图呈现假设、因果方向和不确定性，但相关连线不等于已证实因果，更不是预报。

**观察指标：**是否形成一条有条件词的影响链，并在前提改变后修正至少一处。

**近迁移桥：**家庭活动用“如果下雨，哪些准备可能变化”作低风险计划。

**停止/降档：**儿童把图当真实警报、持续担忧或有人要求据此作现实决定时立即结束。

**与既有 40 局去重：**核心是跨团队影响模型及假设更新，不是气象单变量试飞、路线改线或多方听证。

### 游戏 25｜消防站精力调度圈

**主目标/副目标与明确非目标：**主目标是主持承载量检查，并按成员自报状态缩小、轮换或延期任务；副目标是求助和共享功劳。非目标是调度火警、决定救援优先级、测试耐力或判断 ADHD、懒惰和责任心。

**材料与先备：**仅含开放日低风险事务的任务卡，如摆纸徽章、整理模型图、迎接玩具访客；“可做/轻任务/休息/不说明”状态卡、任务槽、搭档牌、下轮盒和结束牌。

**角色与儿童所有权：**每人拥有自己的状态、改变与不解释权；儿童主持人拥有询问和汇总流程，不能替别人定精力。成人负责总负荷、安全和结束。

**8–15 分钟默认玩法：**

1. 摆出两三项非应急任务；
2. 每人选择状态卡，可盖住原因；
3. 主持人逐一邀请，允许跳过，只复述可承担量；
4. 按当前承载量配单人、搭档或下轮任务；无人承担也可留空；
5. 做一小轮后再次检查，任何人可换轻任务或休息；
6. 未完成项进下轮盒，不追责；
7. 总结谁提醒了负荷、谁请求了帮助，共享署名。

**直接话术：**

> “你最了解自己现在能承担多少。”  
> “可以休息，不必证明理由。”  
> “任务要适配团队，不让人硬撑去适配任务。”

**三档玩法：**

- **6 岁起步：**只选“做/休息”。
- **7 岁进阶：**主持一次检查并安排搭档。
- **8 岁挑战：**面对中途状态变化重排任务，说明延期为何不是失败。

**ADHD 支架：**任务最多三项；状态卡始终可见；先动手再短复盘；转换前翻结束牌；不用倒计时。

**安全：**不用真实消防设备、警报、应急情节或撤离决策；不模拟疲劳上岗。

**设计理由与证据边界：**自报承载量与可逆排班支持同意和求助，但状态卡不是体能、疾病或工作能力测评。

**观察指标：**主持人是否询问所有成员，并让最终安排尊重一次休息、减量或换岗请求。

**近迁移桥：**家庭整理前各报可承担量，把剩余事项留到下轮。

**停止/降档：**出现羞辱休息、强迫解释、比较谁能干或儿童被迫完成全局时停止。

**与既有 40 局去重：**核心是可变化的个人承载量与同意式重排，不是补给分配、交接日志或消防应急优先级。

## 13. 工程航天：接口、系统、物理类比、因果语言与独立验收

### 游戏 26｜月球基地接口合同

**主目标/副目标与明确非目标：**主目标是在分开建造前共同约定、复述并遵守接口标准，接合失败时据合同修订；副目标是标准语言和跨组确认。非目标是造得最大、学习真实航天工程，或由协调员替别人改件。

**材料与先备：**纸板月面、两个纸盒模块、大号纸片/积木连接件；“开口宽度、连接形状、朝向、交付信号”合同卡，只选 2–3 项；通过、待修卡。成人先排除磁铁、电池、尖角和小件。

**角色与儿童所有权：**儿童选接口员或模块工程师；工程师拥有本模块方案和修复权，接口员只核对合同、不能动手重做。单人时用两个玩偶代表团队；成人只管材料安全。

**8–15 分钟默认玩法：**

1. 两组先签合同并互相复述；
2. 各自搭模块，中途不偷改标准；
3. 交付前说“按___接口，已准备”；
4. 只按清单接合；
5. 不合时标出“合同含糊/制作未符合”，不怪人；
6. 原作者选修件，或双方同意改合同；
7. 复测一次并给各角色署名。

**直接话术：**

> “先对标准，不猜对方心里。”  
> “我只报告接口哪里不合，怎么修仍由你决定。”

**三档玩法：**

- **6 岁起步：**只核对形状、朝向两项。
- **7 岁进阶：**独立建两件并完成一次修订。
- **8 岁挑战：**加入“两个都合格却互不兼容”的样件，由儿童主持改写标准并说适用范围。

**ADHD 支架：**合同固定中央，一人一次只拿一张卡；步骤用“签—建—交—测—修”五格，失败只修一处。

**安全：**只搭桌面纸模，不承重、不攀爬，不模拟舱压或生命保障。

**设计理由与证据边界：**接口把合作从“互相帮忙”变成可核验约定；纸模成功不证明真实工程、空间能力或团队领导力。

**观察指标：**三次核对中，按合同指出符合/不符并把修复权还给原作者的次数。

**近迁移桥：**两人分别做拼图边框与内页，先约定尺寸和交付信号再合并。

**停止/降档：**抢改他人模块、临时加标准、争功或反复拆毁时，降为核对两个现成接口。

**与既有 40 局去重：**核心是跨团队接口合同与独立集成，不是编码通信、交接日志、单变量试验或自由搭建。

### 游戏 27｜城市电网连锁图

**主目标/副目标与明确非目标：**主目标是只沿纸卡上已确认的依赖箭头追踪变化，分清直接影响、间接影响和不受影响；副目标是系统说明与核查异议。非目标是操作真实电网、决定先保谁、制造停电恐惧或学习正式电路。

**材料与先备：**城市底图；发电、分配、路灯、车站时钟、图书馆灯箱等纯纸卡；输入/输出图标、箭头、维护卡、直接/间接/无影响标记和一张虚构备用卡。关系均由成人预审为本局规则，不冒充真实电网图。

**角色与儿童所有权：**节点代表只说明本卡需要什么、提供什么；制图员拥有箭头布局；核查员可要求指出依据，但不能替代表发言。成人守住现实安全边界。

**8–15 分钟默认玩法：**

1. 摆 4–6 个节点，各代表读输入/输出；
2. 两端确认后才连箭头；
3. 抽“某节点维护”卡；
4. 从该点每次只走一条已画箭头，依次放直接、间接标记；
5. 没有箭头的支路放“目前无证据受影响”；
6. 加入一张备用纸卡，重画一处依赖再运行；
7. 比较改图前后，不讨论真实调度。

**直接话术：**

> “箭头没画，就先不能跳过去。”  
> “这是纸卡系统的结果，不是现实城市预测。”

**三档玩法：**

- **6 岁起步：**用三节点单链。
- **7 岁进阶：**加一个分支并区分三类影响。
- **8 岁挑战：**找出一条多画或漏画的依赖，主持修图并说明结论只适用于当前卡组。

**ADHD 支架：**一次只揭一张节点卡；用手指沿箭头移动影响标记；三类结果区固定，最多追两层。

**安全：**全程纸卡；不接触插座、电线、开关、电表或配电设施，也不把家庭断电交儿童处理。

**设计理由与证据边界：**连锁图把系统依赖外置，也限制无依据的灾难化跳跃；它不是电学模型、风险评估或应急训练。

**观察指标：**三次合格分支中，沿箭头逐层标记且未越过未知连接的次数。

**近迁移桥：**用“材料—步骤—成品—展台”卡画手工活动依赖，检查少一项影响到哪里。

**停止/降档：**儿童想检查真实电气、持续担心停电、给节点或人贴罪名时，降为三张普通流程卡。

**与既有 40 局去重：**核心是纸卡系统依赖与影响边界，不是路线改道、资源优先级、隐患检查或故障修理。

### 游戏 28｜火车声波接力剧场

**主目标/副目标与明确非目标：**主目标是借低音量身体—纸卡模型表达“源头动作引起相邻部分依次响应，最后到达接收端”，并说出模型局限；副目标是轮流与顺序协作。非目标是比嗓门、传秘密话、测听力，或教授频率、压强等正式物理。

**材料与先备：**纸火车头、3–5 张相邻“车厢/空气区”卡，每张有“靠近—回位”两个位置；源头、接收、模型不是实物卡和音量停止牌。成人先约定只用一次轻柔指敲纸盒作开场信号。

**角色与儿童所有权：**源头演员只发一次低声信号；每位车厢演员只移动自己的卡；接收员只报告末端是否到达；指挥员不能替别人动。成人拥有音量否决权。

**8–15 分钟默认玩法：**

1. 演员排成相邻站位；
2. 源头轻敲一次；
3. 第一位做“靠近—回位”，下一位看到邻位动作后再做，依次到接收端；
4. 接收员举“到达”；
5. 抽“剧场断点”卡，让一站暂不响应，观察这套模型停止；
6. 恢复该站再演；
7. 共同指出：纸卡接力只表示局部影响依次传开，不表示真实空气有同样断点或整块跑动，也不测传播速度。

**直接话术：**

> “不用更响，模型靠顺序看清。”  
> “哪一段动了、哪一段还没动？”

**三档玩法：**

- **6 岁起步：**三段并由成人指序。
- **7 岁进阶：**四段独立接力并复述源—邻近—接收。
- **8 岁挑战：**比较连续/断开两版，指出模型能说明什么、不能说明什么。

**ADHD 支架：**每人只有一张卡和一个动作；地面箭头标轮次，先静默排练，完整两轮即结束。

**安全：**声音保持谈话以下，不贴耳、不喊叫、不敲金属，不用长绳或让耳朵贴桌面。

**设计理由与证据边界：**可见的局部接力提供定性先备；这是类比剧场，不足以推出真实声波结构、介质规律或听觉结论。

**观察指标：**两轮中按相邻顺序完成且能指出一项模型局限的轮数。

**近迁移桥：**改用排队举牌，保留“每人只响应相邻一站”的可见动作链。

**停止/降档：**音量上升、反复制造声响、抢动别人卡或儿童捂耳时，立即静音，改成人翻三张顺序图。

**与既有 40 局去重：**核心是低音量局部传播模型，不是密码通信、广播编辑、故事排序或听觉记忆。

### 游戏 29｜气象记者“因为—所以”校对台

**主目标/副目标与明确非目标：**主目标是判断“因为—所以”是否有足以支持且范围匹配的因果依据；不足时改成先后、同时或未知表述；副目标是语言编辑。非目标是预测真实天气、把相关当因果或学习正式气象机制。

**材料与先备：**观察卡、来源卡、句子卡；“有支持/只见先后或同时/仍未知”三栏；改写词“随后、同时、可能、目前不知道”。成人预备例句，如“预报说下雨，所以预报让雨发生”与虚构扇风模型句。

**角色与儿童所有权：**记者拥有原句和最后措辞；证据编辑只判依据范围；来源员只报告卡上信息。编辑不得夺笔改稿，记者可要求说明。

**8–15 分钟默认玩法：**

1. 记者抽观察、来源和稿件各一张；
2. 编辑圈出“因为”“所以”两端；
3. 核对来源是否真的操纵或排除了别的解释；
4. 放入三栏；
5. 依据不足时由记者改为“随后看见___”或“可能因为___，仍需核查”；
6. 来源员复述新句没有多说什么；
7. 完成三句，以一条合格改稿播报。

**直接话术：**

> “先后发生，不自动等于前者造成后者。”  
> “把句子缩小，不等于失败。”

**三档玩法：**

- **6 岁起步：**在“有支持/不知道”中二选一。
- **7 岁进阶：**分三栏并改写一句。
- **8 岁挑战：**处理同一事实的两个因果解释，保留未知并说还缺什么证据。

**ADHD 支架：**一次只放一组卡；把因、果两端用箭头框出；可先摆栏再口述，三句封顶。

**安全：**只用虚构纸卡；真实雷暴、预警和出行决定由成人按官方信息处理，不带儿童外出验证。

**设计理由与证据边界：**显性校对能练因果语言边界，但一句合格不证明因果推理、写作或气象知识已迁移。

**观察指标：**三次机会中，依据不足时主动保留未知或改成非因果句的次数。

**近迁移桥：**校对生活句：“我穿红袜后赢了，所以红袜让我赢”，改成事实与未知。

**停止/降档：**成人设陷阱嘲笑、争论真实灾害责任、儿童因天气持续焦虑时，降为给两句贴“事实/猜想”。

**与既有 40 局去重：**核心是因果连接词及范围校对，不是广告真假判定、来源署名、广播删减或证据侦探。

### 游戏 30｜工程验收不揽功委员会

**主目标/副目标与明确非目标：**主目标是按事先公开标准独立验收，把“通过/返修/未知”交给证据，并在结项时共享功劳；副目标是反馈分工。非目标是评谁聪明、边做边改标准、验收员代修或主持人独占成果。

**材料与先备：**纸板等安全大件；一个桌面小工程，如让轻玩具车通过纸门；2–3 张可观察标准卡、清单、通过/返修/未知章和贡献卡。标准开工前固定。

**角色与儿童所有权：**需求员只定标准；建造员拥有方案和返修权；未参与建造的验收员只测试、记录，不边测边教；记录员保存证据。人数不足由玩偶任需求员，同一作品不互换建造与验收身份。

**8–15 分钟默认玩法：**

1. 需求员公布标准；
2. 建造员完成并提交；
3. 验收员逐项按清单测试，不增加“我还想要”；
4. 只记可见结果；
5. 不合格时说一条标准差距并退回；
6. 建造员决定修法，只复测该项；
7. 结项板分别写“标准、建造、核验、修复”，共同署名，验收员不把通过说成自己的作品。

**直接话术：**

> “验收权不是改造权。”  
> “通过靠证据；功劳属于所有贡献者。”

**三档玩法：**

- **6 岁起步：**两项图示标准并看一次示范。
- **7 岁进阶：**独立验收、返修一项。
- **8 岁挑战：**遇标准含糊时暂停判定，由全体澄清后复测。

**ADHD 支架：**标准始终可见；一次只测一项；章代替长评语；返修一处，复测即结束。

**安全：**只验桌面轻物，不做人体承重、攀爬或破坏性加载，不用刀具、热胶、玻璃和真实设施。

**设计理由与证据边界：**角色独立减少自评与临场偏袒，共享署名抑制揽功；一局通过不证明耐久、工程能力或现实公正。

**观察指标：**按预设标准测试、不给新标准且把修复权交还建造员的项目数/合格机会。

**近迁移桥：**手工作品展前，由未参与者按两项预定摆放标准检查，贡献者共同署名。

**停止/降档：**验收变羞辱、临时加码、验收员抢修或只写自己名字时，暂停并核对一件现成样品。

**与既有 40 局去重：**核心是独立验收、返修权和共享功劳，不是接口集成、交接日志、单变量试验或作品策展。

## 14. 识别与命名：愿意、重复、力量差、玩笑与排挤

### 游戏 31｜双方愿意信号台

**主目标/副目标与明确非目标：**主目标是在共同玩耍开始及规则改变时，核对双方是否明确愿意，并尊重“等等、不参加、停止”；副目标是表达与更新边界。非目标是凭笑脸猜同意、逼问理由、训练顺从或判定谁在欺凌。

**材料与先备：**两个虚构玩偶、愿意/等等/不参加/不清楚卡、停止卡和两张低强度合作任务卡。成人先示范：沉默、僵住和含糊回应都不等于愿意。

**角色与儿童所有权：**儿童任信号员，选择情境、替玩偶放卡并决定是否启动；成人读卡和守安全，不纠正儿童感受或替玩偶答应。

**8–15 分钟默认玩法：**

1. 成人用玩偶发出一次邀请；
2. 儿童为另一玩偶选择回应卡；
3. 只有双方明确“愿意”才启动纸卡任务；
4. 抽取“换角色、加一人或改规则”卡；
5. 信号员重新核对双方意愿；
6. 任一方出示停止卡，动作立即结束；若停止被忽略，直接把场景送入“成人保护”盒。

**直接话术：**

> “你愿意一起玩吗？等等和不参加都可以。”  
> “条件变了，要重新问；停下不需要先解释。”

**三档玩法：**

- **6 岁起步：**在愿意/不参加两卡中选择。
- **7 岁进阶：**加入等等与不清楚，并在变化后重问。
- **8 岁挑战：**分辨“先前同意”不代表“现在仍同意”，说明何时必须复核。

**ADHD 支架：**每轮只留两张回应卡；邀请—回应—行动三格可见；允许只指卡；两次核对即收台。

**安全：**只用虚构玩偶和纸卡，不模仿推搡、嘲弄或真实同学事件；不让儿童调解或独自对峙。任何一次严重伤害都直接交成人保护，不等待重复或完成本局。

**设计理由与证据边界：**明确同意和可撤回信号把“愿意”变成可观察程序；桌面选择不证明儿童能在压力现场表达，也不能正式认定霸凌或推测动机。

**观察指标：**在合格机会中，行动前取得明确回应、条件改变后复核、停止后不再推进的次数。

**近迁移桥：**开始亲子追逐、搭建或轮流游戏前，只试一次“邀请—回应—可退出”。

**停止/降档：**出现逼答、取笑拒绝、把停止卡当控制工具或儿童退缩时结束；降为成人演示一次“不参加也被接受”。

**与既有 70 局及 FBL 去重：**核心是“启动前双方明确愿意—条件变化再同意”，不是既有编队暂停、邀请式分工、规则切换，也不是 FBL 的事后识别与安全四步法。

### 游戏 32｜重复模式雷达

**主目标/副目标与明确非目标：**主目标是按可见事实区分“一次、出现模式、可能再发生、资料不足”，并把相应信息交成人核查；副目标是时间排序和保留未知。非目标是等够次数才求助、猜测故意、给玩偶或真人贴“霸凌者”标签。

**材料与先备：**虚构玩偶、四张低强度事件卡、日期条、对象/行为/地点/渠道标签、一次/模式/可能再发/未知卡及成人保护盒。成人先示范相似不等于相同。

**角色与儿童所有权：**儿童任雷达记录员，可重排事件、标未知或跳过；成人只提供卡面事实，并负责决定现实保护措施。

**8–15 分钟默认玩法：**

1. 读第一张事件卡，只记录谁受到什么可见影响；
2. 第二张卡出现后，逐项比较对象、行为、地点和渠道；
3. 相连事实放入同一时间条，不相连就分开；
4. 为现有资料选择“一次、模式或未知”；
5. 抽取一张“明确预告下次继续、群聊仍在传播”等再发线索，更新判断；
6. 遇严重伤害卡立即绕过雷达，送入成人保护盒；
7. 用一句事实报告收尾，不作正式认定。

**直接话术：**

> “我们记录发生了什么，不猜为什么。”  
> “重复会增加警报；严重的一次也要马上找大人。”

**三档玩法：**

- **6 岁起步：**比较两张卡是否指向同一玩偶。
- **7 岁进阶：**沿三次事件找相连与不相连线索。
- **8 岁挑战：**加入传播未结束或明确威胁等再发风险，并允许结论为未知。

**ADHD 支架：**一次只翻一张卡；标签不超过四类；用连线代替复述；完成三次比较即结束。

**安全：**情境全部虚构且低强度，不重演真实伤害；儿童不负责取证、调解或独自对峙。一次严重伤害、威胁或即时危险不等待重复，由成人立即处理。

**设计理由与证据边界：**时间条可外置“模式”概念，未知卡抑制过度判断；正确分类不证明现实识别或安全处置能力，也不能正式认定霸凌。

**观察指标：**在合格事件组中，儿童正确分开事实与未知、识别相连事件并选择成人核查的次数。

**近迁移桥：**读虚构故事时，只问一次：“这是单次、已有模式，还是资料不够？”

**停止/降档：**儿童联想到真实经历、反复追问坏心或因次数焦虑时停；降为两张无伤害日常卡找相同点。

**与既有 70 局及 FBL 去重：**本局核心是事件条对齐、模式证据与再发风险更新，不是雷达位置记忆、痕迹侦探或双裁判对账；FBL 只用明确剧情提示求助，本局不复演其人物、情节或四步口诀。

### 游戏 33｜力量差检查台

**主目标/副目标与明确非目标：**主目标是从人数、体格或年龄、地位与资源、秘密信息、网络扩散及退出通道等可见条件检查力量差；副目标是说明未知并转交成人。非目标是给儿童排强弱、责怪没反抗、计算总分或正式认定霸凌。

**材料与先备：**虚构玩偶、六类力量条件卡、能否说停/离开/取回物品/找到成人卡、事实/未知标记和成人核查夹。成人先示范：单一卡片不是自动结论，多种条件也不能由儿童裁决。

**角色与儿童所有权：**儿童任检查员，选择检查顺序、放事实或未知；成人读情境、承接求助并保留最终调查责任。

**8–15 分钟默认玩法：**

1. 摆出一张虚构互动卡；
2. 只从卡面找双方人数、资源和位置等事实；
3. 检查受影响玩偶能否安全说停、离开、取回物品和接近成人；
4. 每个障碍旁放对应力量条件卡；
5. 资料不足就标未知，不补写动机；
6. 若差异让一方很难退出或影响结果，送入成人核查夹；
7. 严重伤害卡直接进入保护程序。

**直接话术：**

> “力量差不只看谁个子大，还看谁能控制人、信息和出口。”  
> “很难自己解决时，应增加成人保护，不是要求更勇敢。”

**三档玩法：**

- **6 岁起步：**只比较人数和能否离开。
- **7 岁进阶：**加入地位、物品和秘密信息。
- **8 岁挑战：**分析多种小差异怎样叠加，并指出仍未知的部分。

**ADHD 支架：**每轮只查两类条件；用出口箭头和成人图标代替长问答；允许站立摆卡；一张情境完成即收台。

**安全：**仅用玩偶和纸卡，不称真人“强者、弱者”；不让儿童调解、证明能力或独自对峙。一次严重伤害不等待重复或力量差核对完毕，立即由成人保护。

**设计理由与证据边界：**多维检查避免把力量差缩成体格，也把“能否安全退出”置于中心；游戏表现不能推断真人关系、动机或完成正式认定。

**观察指标：**儿童能依据卡面指出至少一个力量来源、一个退出条件，并在资料不足时标未知的次数。

**近迁移桥：**共读虚构故事时，用“谁更能影响结果、谁更难离开”替代“谁更厉害”。

**停止/降档：**出现身体比较羞耻、责怪玩偶不反击或争论谁最强时停；降为只检查“出口是否畅通”。

**与既有 70 局及 FBL 去重：**核心是多维影响力与退出障碍审计，不是公平分配、资源采购、风险评审或异议保障；FBL 只提示“一个人难解决”，未进行条件分层与未知标记。

### 游戏 34｜玩笑刹车测试

**主目标/副目标与明确非目标：**主目标是在玩笑中出现“停、不喜欢、后退、沉默或僵住”等刹车信号时立即停止，并由受影响一方决定是否结束；副目标是检查影响和提出低压力修复。非目标是判断谁没幽默感、用笑声证明愿意、逼道歉或认定霸凌。

**材料与先备：**虚构玩偶、三张无羞辱的滑稽情境卡、停/后退/不喜欢/不清楚卡，以及立即停、减弱、忽略、争辩回应卡。成人先示范“笑过也能改主意”。

**角色与儿童所有权：**儿童任刹车测试员，负责选择信号和检验回应；玩偶拥有停止、离开和不重启权。成人不要求受影响玩偶解释或原谅。

**8–15 分钟默认玩法：**

1. 摆出双方起初愿意的虚构玩笑；
2. 儿童为任一玩偶放一张刹车信号；
3. 从回应卡中选出“立即停并留空间”；
4. 另一玩偶只问一次“需要结束还是换玩法”；
5. 受影响玩偶选择结束、换玩法或暂不回答；
6. 比较忽略、争辩与停车回应会造成什么可见影响；
7. 若刹车被持续忽略，直接转成人介入。

**直接话术：**

> “有人按刹车，玩笑就停；刚才笑了也可以现在不玩。”  
> “我先停。你不用证明自己真的不舒服。”

**三档玩法：**

- **6 岁起步：**看到停止卡就让玩偶静止。
- **7 岁进阶：**识别语言和身体两类刹车信号。
- **8 岁挑战：**比较停止、检查影响与修复邀请，说明重启权属于谁。

**ADHD 支架：**只保留一个情境和三张回应卡；刹车卡放中央；成人一句一动作；完成一次停车即算完整一局。

**安全：**不真实起绰号、嘲弄、碰撞或试探忍耐，只操作虚构玩偶和纸卡；不让儿童调解或独自对峙。任何一次严重伤害均直接由成人处理，不等待第二次或“测试刹车”。

**设计理由与证据边界：**本局观察的是边界出现后的回应，而非猜玩笑者意图；桌面会停车不证明现实中能说停，也不能据此正式认定或排除霸凌。

**观察指标：**在合格机会中，儿童选择立即停止、不争辩，并把结束或重启决定交还受影响玩偶的次数。

**近迁移桥：**下次双方自愿的追逐或逗趣开始前，约定一个真实停止词，并由成人先示范立即停。

**停止/降档：**儿童开始复制伤人台词、笑声升级、忽略停止卡或出现真实披露时结束；降为成人翻卡、儿童只做停车动作。

**与既有 70 局及 FBL 去重：**核心是“刹车信号—立即停—影响检查—重启权”，不同于游戏 31 的启动前同意、编队暂停的任务重启，也不复演 FBL 的抢夺排斥和求助口诀。

### 游戏 35｜私人选择与协同排挤分诊台

**主目标/副目标与明确非目标：**主目标是依据可见条件，把情境分流为“私人选择仍需体谅、资料不足由成人了解、协同排挤风险需成人保护”；副目标是区分感到难过与权利受侵害。非目标是规定所有私人活动必须邀请所有人、猜恶意或由儿童正式认定霸凌。

**材料与先备：**虚构玩偶、私人约玩/共享活动/多人施压/反复阻挡等纸卡，私人选择、成人了解、立即保护三个信封及未知卡。成人先说明：一次未被邀请可能令人难过，但与号召全体排斥不是同一结构。

**角色与儿童所有权：**儿童任分诊员，可选信封、标未知或要求补一条事实；成人负责调查、监督和保护，不让儿童去质问或撮合。

**8–15 分钟默认玩法：**

1. 读一张虚构情境卡；
2. 标出活动是私人安排还是共同开放场景；
3. 查找是否有人号召他人绝交、以友谊相逼、反复封锁参与或借群体地位施压；
4. 区分一人的选择与多人协调行动；
5. 将卡放入相应信封，并说出一条可见依据；
6. 翻开补充事实后允许改投，不因更新扣分；
7. 严重威胁、伤害或无法安全退出时直接进入立即保护。

**直接话术：**

> “一次私人不邀请，不自动等于欺凌；难过仍值得被照顾。”  
> “如果有人组织大家持续排斥或惩罚接近他的人，需要大人调查和保护。”

**三档玩法：**

- **6 岁起步：**区分“一人自己选”和“多人一起施压”。
- **7 岁进阶：**加入私人场景、共享场景及重复线索。
- **8 岁挑战：**面对信息不全先标未知，再依据新增事实改分诊路线。

**ADHD 支架：**每轮只看一张卡和两个问题；三只信封颜色固定；允许直接投递；完成两张情境即结束。

**安全：**全部使用虚构玩偶和纸卡，不代入真实同学、群聊或生日名单；不强迫邀请、和解、儿童调解或独自对峙。一次严重伤害不等待排挤重复，由成人立即启动保护。

**设计理由与证据边界：**分诊同时保护私人交往选择与儿童免受群体操控的权利；卡片选择只练事实路由，不能推断动机、完成学校调查或正式认定霸凌。

**观察指标：**儿童能指出私人/共享场景、单人/协同行动和重复或施压线索，并选择相应成人路线的次数。

**近迁移桥：**共读故事时只问：“这是个人选择，还是有人在组织别人一起排斥？还缺什么事实？”

**停止/降档：**出现真实点名、要求列出谁没邀请自己、强迫所有人加入或儿童明显难过时停；降为比较两张差异明确的虚构卡。

**与既有 70 局及 FBL 去重：**核心是私人交往权与协同排挤的分诊、补证和改路由，不是邀请式分工、少数意见保护或调解；FBL 呈现明确重复排斥并练安全行动，本局专门处理边界情形且不复述其情节。

## 15. 边界、退出与操控信号：先安全，不猜坏心

### 游戏 36｜安全说停选择器

**主目标/副目标与明确非目标：**主目标是先看现场安全，再选择“短句说停”或“跳过说停、直接离开”；副目标是允许不确定时采用更安全路径。非目标是对峙、反击、说服对方、证明勇敢或准确预测危险。

**材料与先备：**软载具玩偶、低强度虚构情境卡、“可选说停/直接离开”双轨板、可信成人站。成人先说明：说停不是必经步骤；被围、堵路、威胁、追随或拿不准时都可直接离开。

**角色与儿童所有权：**儿童任安全领航员，决定是否说、说哪句及去哪个成人站；成人只出示线索和接应，不扮演逼近者。真实安全判断与处置归成人。

**8–15 分钟默认玩法：**

1. 儿童先选一个可信成人站；
2. 成人翻一张情境卡及可见线索；
3. 儿童判断“现在说话会不会增加风险”，不确定也可选离开；
4. 若选说停，只说“停下”“这不可以”或“我不要”一句，也可临时改为不说；
5. 说完立即移动，不等待对方回答、道歉或同意；
6. 若选直接离开，玩偶不发言，立即到成人站；完成两三轮即结束。

**直接话术：**

> “安全时，说停只是一个可选动作。”  
> “不安全或拿不准，不用解释，直接走。”  
> “你的任务是保护自己，不是让对方承认错误。”

**三档玩法：**

- **6 岁起步：**成人说明安全状态，儿童只在两条轨道中指选。
- **7 岁进阶：**儿童依据一项可见线索选择，并移动到成人站。
- **8 岁挑战：**比较同一事件在“成人就在旁边”和“出口被挡”时为何选择不同。

**ADHD 支架：**每轮一张卡、两个选项；先移动再说明；短句印在卡上；三轮封顶。

**安全：**不真实堵路、追逐、威胁或夺物；儿童任何时候都可跳过。若提及真实经历，立即停止教学并按披露流程处理。

**设计理由与证据边界：**条件分流可避免把“必须先说停”变成儿童责任；这是低风险【实施设计】，一局选择正确不证明现实危险判断或自保能力。

**观察指标：**在“不安全/不确定”机会中，能否不争辩而选择直接离开；成人是否同样肯定两种合格路径。

**近迁移桥：**看绘本或动画时暂停一次，只问：“安全说一句，还是现在就离开？”

**停止/降档：**儿童僵住、害怕、把任务理解成必须面对对方，或成人追问“为什么不敢说”时停止；降为成人演示两条路径。

**与既有 70 局及 FBL 去重：**不同于游戏 3 的暂停—协商—重启同意，也不复演 FBL 固定四步口诀；本局只练行动前的安全分流，且直接离开可独立算完整成功。

### 游戏 37｜快速离场靠岸站

**主目标/副目标与明确非目标：**主目标是遇到持续压力时减少决定和停留，直接到可用的可信成人或开放监督区；副目标是原路线不可用时切换靠岸站。非目标是竞速、寻找最短路、拿回物品、完整报告或回头证明自己不怕。

**材料与先备：**桌面场景图、玩偶、两三个由成人核实的“靠岸站”、开放/暂不可用卡和“东西先留下”卡。成人先说明哪些现实成人及地点可求助。

**角色与儿童所有权：**儿童任船长，拥有立即离开、选择靠岸站和放弃未完成物品的权利；成人只放压力卡和接应，不追玩偶、不堵路线。

**8–15 分钟默认玩法：**

1. 在图上指出两个可用靠岸站；
2. 成人在起点放一张“继续纠缠、要求留下或不让拿回玩具”的低强度卡；
3. 儿童放下“现在离开”牌，不回应、不抢回；
4. 指定一个开放站，把玩偶沿清楚路线一次移到站内；
5. 若途中出现“暂不可用”，立即改去第二站，不返回起点；
6. 到站只说“请和我待在一起，我需要帮助”，成人确认接管；最多三轮。

**直接话术：**

> “不用把话说完，先靠岸。”  
> “物品可以暂时留下，安全比拿回来重要。”  
> “这条路不通就换站，不回去解释。”

**三档玩法：**

- **6 岁起步：**一条直线、一个成人站，儿童只移动玩偶。
- **7 岁进阶：**两个站中选择，并处理一次路线不可用。
- **8 岁挑战：**比较“最近但无人值守”和“稍远但有可信成人”，说明为何选后者。

**ADHD 支架：**路线不超过三段；靠岸站用大图；压力出现后只给一句提示；到站立即完成，不追加盘问。

**安全：**全程桌面静态移动，不跑、不躲藏、不练挣脱；现实中不得为玩具、书包或取证返回，也不让儿童独自寻找成人。

**设计理由与证据边界：**把离场压缩为“放下—选站—到达”，可减少压力下的语言和工作记忆负担；不能据此推断现实路线安全或危机应对已掌握。

**观察指标：**能否在压力卡出现后不继续互动，直接抵达可用站；路线变化时是否不返回起点。

**近迁移桥：**在熟悉场所由成人指出两个真实求助点，只做口头指认，不制造突袭演练。

**停止/降档：**儿童开始竞速、搜救物品、担心离开会受罚或场景唤起真实恐惧时停止；降为给玩偶指出靠岸站。

**与既有 70 局及 FBL 去重：**不同于旧游戏 18 的消防停—看—走路线，也不重复 FBL 的安全线表演；本局专练社会压力下缩短停留、舍下物品和切换有人接应的站点。

### 游戏 38｜秘密压力闸门

**主目标/副目标与明确非目标：**主目标是识别“瞒着可信成人、礼物换保密、威胁后果、催转私聊或索要资料/照片”等可见压力，并停止互动、交给成人；副目标是准确指出触发词。非目标是判断对方是否坏、套话取证、守住秘密或独自处理。

**材料与先备：**纸制手机/对话卡、四类压力图标、“不继续—离开/放下设备—交成人”闸门板和可信成人卡。成人先说明：儿童无需区分“好人坏人”，任何不舒服的秘密都可告诉成人。

**角色与儿童所有权：**儿童任闸门员，拥有不回复、退出和选择告诉谁的权利；成人任接报员并负责保存必要信息、屏蔽、举报和后续保护。发送者只由纸卡表示。

**8–15 分钟默认玩法：**

1. 成人翻一张卡，如“送你礼物，但别告诉家长”；
2. 儿童圈出看得见的压力词或要求；
3. 把卡送进闸门，不猜动机；
4. 线下卡选择结束谈话并离开；网络卡选择停止回复、放下设备；
5. 将原卡交给一位可信成人，不继续聊天验证；
6. 成人回应“谢谢你告诉我，我来处理”；完成三类卡即结束。

**直接话术：**

> “我不用猜你是不是坏人。”  
> “你要求保密、威胁或转私聊，我不继续。”  
> “我现在把这件事交给可信成人。”

**三档玩法：**

- **6 岁起步：**成人读卡，儿童找“保密/威胁”图标并交成人。
- **7 岁进阶：**分辨秘密、礼物、威胁或私聊压力，完成三步闸门。
- **8 岁挑战：**处理礼物与威胁同时出现的卡，仍只报告可见要求，不分析人格。

**ADHD 支架：**一次一卡；压力词高亮；三步板固定；允许只指不说；每类最多一例。

**安全：**不用真实账号、图片、姓名和既往经历，不让儿童回复或截图取证。出现真实秘密、性接触、私密影像、诱约或威胁时立即停止并启动保护程序。

**设计理由与证据边界：**以可见压力作触发点，比要求儿童识别恶意更可执行；家庭纸卡不能证明网络素养或现实中一定能退出。

**观察指标：**能否指出具体压力要求，并在不追问动机、不继续互动的情况下交给成人。

**近迁移桥：**观看虚构广告或游戏弹窗时，只找“保密、转平台、送礼换资料”等压力，不点击链接。

**停止/降档：**儿童明显恐惧、开始自责、成人追问细节或把它变成真假秘密考试时停止；降为成人示范一张卡。

**与既有 70 局及 FBL 去重：**不同于游戏 22 的最少必要信息、英语澄清或广告真假判断；也不复演 FBL 的一般报告剧情，核心是四类操控压力的即时闸门与成人接管。

### 游戏 39｜身体与物品边界关卡

**主目标/副目标与明确非目标：**主目标是分别识别身体接触与个人物品请求，并使用同意、拒绝、离开或交成人的合适路径；副目标是知道同意可以改变。非目标是强迫分享、抢回物品、解释拒绝理由、忍受接触或用反击守边界。

**材料与先备：**身体轮廓卡、物品垫，“愿意/不愿意/现在不/离开/找成人”卡，以及低强度请求卡，如拥抱、拉手、借模型、打开书包。成人先示范：没有回答不等于同意。

**角色与儿童所有权：**儿童任关卡主人，拥有自己身体和游戏物品的选择权，可随时改答案；成人只用卡提出请求并立即尊重回应。儿童不扮演越界者。

**8–15 分钟默认玩法：**

1. 抽一张请求卡，先放入“身体”或“物品”区域；
2. 儿童选择愿意、不愿意或现在不，指卡也有效；
3. 成人立即复述并撤回请求，不劝说；
4. 儿童可翻转答案，体验同意能够改变；
5. 加入“对方未停/未经允许已拿走”的压力卡；
6. 若安全，可说一句“停下/请放回”；若不安全或未停止，直接离开找成人，物品不靠争抢取回；
7. 成人恢复边界并结束，不要求双方和解。

**直接话术：**

> “你的身体由你表达愿不愿意。”  
> “拒绝不需要长理由，也不能用礼物换同意。”  
> “东西被拿走不必抢回来，先找成人处理。”

**三档玩法：**

- **6 岁起步：**身体、物品各一张卡，只练指选。
- **7 岁进阶：**加入“先同意、后来改变”，成人立即停止。
- **8 岁挑战：**比较身体请求与借物请求的共同点和不同处，并选择安全路径。

**ADHD 支架：**桌面只留一个区域；答案卡常驻；成人一句一请求；动作仅限放卡和移玩偶。

**安全：**不真实拥抱、拉扯、搜包或抢夺，不模拟私密部位接触；必要照护与紧急避险由成人透明、适度地负责，不能借游戏取消儿童表达权。

**设计理由与证据边界：**把身体同意与物品所有权分开，可避免用“要分享”覆盖身体边界；一局表现不证明现实防护能力，也不把保护责任转给儿童。

**观察指标：**能否正确分区并作出真实选择；成人是否第一次回应就停止劝说；越界后是否避免争抢。

**近迁移桥：**家庭借玩具或表达拥抱前先问一次，并把“不愿意/现在不”当作完整答案。

**停止/降档：**儿童退缩、僵住、成人开玩笑挑战拒绝，或出现真实身体接触披露时立即停止；降为玩偶替儿童指卡。

**与既有 70 局及 FBL 去重：**不同于游戏 3 的团队暂停、游戏 9 的作品反馈同意或碰撞后修复；也不重复 FBL 的“还玩具并道歉”，本局同时区分身体自主与物品所有权，且不要求对质。

### 游戏 40｜不猜恶意的可见信号台

**主目标/副目标与明确非目标：**主目标是用“我看到什么—我不知道什么—我现在做什么”报告可见信号并采取保护行动；副目标是描述影响、重复或力量差。非目标是猜坏心、裁定欺凌、证明撒谎、说服对方或给真人贴标签。

**材料与先备：**三层信号台“看到/不知道/行动”、低强度虚构卡、重复/人数/堵路等可见线索片和离开、停止联系、找成人卡。成人先示范把“他故意整我”改成具体行为。

**角色与儿童所有权：**儿童任信号员，决定报告哪些可见事实及采用哪条保护路径；成人任接报员，负责调查、认定和处置。卡中人物不由儿童扮演。

**8–15 分钟默认玩法：**

1. 翻一张卡，如“同一玩偶两次拿走模型，第二次挡住出口”；
2. 儿童把动作、次数和影响放入“看到”层；
3. 把“是不是故意、以后会不会再做”等放入“不知道”层；
4. 不等待动机答案，按当前安全选择短句说停、直接离开、停止联系或找成人；
5. 向接报员说一条事实和一条影响；
6. 成人复述：“你不必证明恶意，我会处理”；完成两三张卡即结束。

**直接话术：**

> “我看到他拿走两次，还挡住了路。”  
> “我不知道他怎么想，也不用先猜。”  
> “这已经让我难以离开，我现在去找成人。”

**三档玩法：**

- **6 岁起步：**成人给出两句话，儿童选哪句是看得见的事实。
- **7 岁进阶：**完成“看到—不知道—行动”三层。
- **8 岁挑战：**把带标签的报告改写成事实、影响和未知，并保留成人调查空间。

**ADHD 支架：**一次只处理一张卡；三层从上到下翻牌；可先摆后说；不追问多个“为什么”。

**安全：**不用真实同学、聊天记录或家庭冲突；不把信号台变成侦查、审讯或抓坏人游戏。真实披露出现时立即停止分类。

**设计理由与证据边界：**意图通常不可直接观察，而保护无需等待恶意被证明；三层语言可减少猜测，但不能凭一局判断报告准确性、欺凌性质或现实迁移。

**观察指标：**报告中可见事实与动机猜测能否分开；即使动机未知，是否仍能选择离开或交成人。

**近迁移桥：**阅读故事时把一句“他就是坏”改成一条可见行为、一项未知和一个安全动作。

**停止/降档：**成人逼问“他为什么这样”、儿童开始审判人物或因类似经历明显不安时停止；降为只把两句话分入“看见/猜测”。

**与既有 70 局及 FBL 去重：**不同于痕迹侦探、广告真假、因果校对及游戏 31–35 的情形分类；也不同于 FBL 的完整安全剧情，本局只建设事实—未知—保护行动的报告台。

## 16. 告诉、持续求助与证据交接：儿童报告，成人承接

### 游戏 41｜可信成人联络图

**主目标/副目标与明确非目标：**主目标是为不同地点选择一名可到达的可信成人及一名备选；副目标是练习接近成人的第一句话。非目标是评判谁“绝对可信”、报告完整事件或选择帮助剂量。

**材料与先备：**家庭、学校、活动场所图；照护者、教师、值班人员等职务卡；路线、暂时不在、备选卡。成人先解释：可信成人会认真听并采取保护行动。

**角色与儿童所有权：**儿童任联络规划员，可排除任何让自己不愿接近的角色且不必解释；成人核实真实岗位和可达性，不替儿童决定舒适度。

**8–15 分钟默认玩法：**

1. 抽一个虚构地点；
2. 儿童放置第一位成人卡；
3. 用路线卡表示怎样找到他；
4. 翻出“暂时不在”卡；
5. 改接第二位成人；
6. 用一句开场话完成联络。

**直接话术：**

> “我有件让我不安全的事，需要你听我说。”  
> “如果这位成人不在，你下一站去哪里？”

**三档玩法：**

- **6 岁起步：**两个成人二选一，沿单一路线送求助卡。
- **7 岁进阶：**为两个地点各配第一位成人和备选。
- **8 岁挑战：**加入岗位更换或通道关闭，更新地图并说明可达依据。

**ADHD 支架：**一次只摆一个地点；用颜色连接地点—成人；允许只指卡或带玩偶走路线。

**安全：**不用真实账号、电话或住址；不要求儿童披露真实经历。现实名单须由成人核实并定期更新。

**设计理由与证据边界：**把“找大人”具体化为地点、通道和备选，是【实施设计】；完成纸图不证明儿童现实中一定能求助或成人一定可靠。

**观察指标：**三个情境中能否指出第一位成人、备选及一条可行接近路线。

**近迁移桥：**成人陪儿童实地辨认学校公布的求助岗位，不现场测试披露。

**停止/降档：**儿童害怕某角色、地图引出真实披露或路线不确定时停止；成人先处理安全。

**与既有 70 局及 FBL 去重：**核心是“可达成人—备选通道”，不是游戏 10 的帮助剂量、消防五要素报告或 FBL 中已知教师旁的一次成功求助。

### 游戏 42｜事实报告拼图

**主目标/副目标与明确非目标：**主目标是把一条可见或可听见的事实与一项当前需要拼成报告；副目标是用“我不知道”区分事实、猜测和未知。非目标是证明动机、认定欺凌、复原全部经过或提供最少必要字段。

**材料与先备：**低强度虚构情境卡，“我看到/听到”“我猜”“不知道”“我需要”拼片及安全行动卡。成人先示范事实与解释的区别。

**角色与儿童所有权：**儿童任报告人，拥有措辞、更正、跳过和停止权；成人任倾听者，只作一次中性澄清，不连环追问。

**8–15 分钟默认玩法：**

1. 看一张玩偶情境卡；
2. 将句子分到事实、猜测或未知区；
3. 选一块事实拼片；
4. 再选“陪我离开、请制止、请联系老师”等需要拼片；
5. 拼成“发生了什么+现在需要什么”；
6. 成人复述，儿童确认或更正。

**直接话术：**

> “我看到他两次拿走车卡；我需要你陪我去找老师。”  
> “不知道就说不知道，不用补出答案。”

**三档玩法：**

- **6 岁起步：**从两条句子中选事实，再配一张需要卡。
- **7 岁进阶：**口述一条事实和一项需要。
- **8 岁挑战：**区分亲见、别人转述和未知，并修正带猜测的报告。

**ADHD 支架：**固定两槽“事实—需要”；一次只读一句；允许摆卡代替口述。

**安全：**不用真实姓名或旧事件作题库；不审问、不要求完美报告后才保护。出现真实披露立即停局并自由倾听。

**设计理由与证据边界：**外置事实与需要可降低组织负担，但游戏不提高记忆准确性，也不能代替学校调查。

**观察指标：**报告中是否至少含一条卡上事实和一项可执行需要，且未把猜测说成事实。

**近迁移桥：**低风险争执中沿用“我看到/听到___；我需要___”。

**停止/降档：**儿童开始迎合、反复改口、紧张或成人追问动机时，降为指选一张需要卡。

**与既有 70 局及 FBL 去重：**不同于消防五要素的完整报告、游戏 22 的字段删减和证据侦探；FBL 呈现成段台词，本局只练“事实+需要”的可更正拼接。

### 游戏 43｜第一位成人未处理时的接力求助

**主目标/副目标与明确非目标：**主目标是在第一位成人未采取保护行动时，把求助接力给下一位可信成人，直到有人承接；副目标是识别“听见了”不等于“已经处理”。非目标是争辩、收集更多证据、惩罚成人或独自解决。

**材料与先备：**三座成人站、求助棒、已听见/行动开始/暂不能处理/仍不安全卡及反馈时点卡。成人先说明“承接”至少包含保护动作、下一步和反馈安排。

**角色与儿童所有权：**儿童任接力员，决定继续、暂停或请同伴陪同；成人按预设卡扮演回应者，不得把真实求助用于测试坚持。

**8–15 分钟默认玩法：**

1. 选一张低强度虚构事件卡；
2. 向成人 A 说事实和需要；
3. 查看其回应是否产生保护行动；
4. 若只有安慰、推迟或仍不安全，把求助棒带到成人 B；
5. 说明“我已告诉过一位成人，但还没安全”；
6. 遇到承接卡后确认下一步和反馈时间。

**直接话术：**

> “我已经告诉过一位成人，但事情还没安全。请你现在帮助我。”  
> “如果你不能处理，请带我找能处理的人。”

**三档玩法：**

- **6 岁起步：**沿箭头从 A 走到 B，重复一句求助。
- **7 岁进阶：**检查“有无行动”，必要时接力一次。
- **8 岁挑战：**面对不在、推迟或含糊回应，选择不同职责的下一位成人并要求反馈点。

**ADHD 支架：**最多三站；同一句话印在求助棒上；只判断“已行动/未行动”。

**安全：**不演羞辱性拒绝，不承诺绝对保密；真实披露时立即结束角色扮演并启动保护程序。

**设计理由与证据边界：**接力结构把持续告诉变成可见动作，但不能保证机构响应，也不把系统失职归责儿童。

**观察指标：**模拟未行动后，儿童是否在提示内转向下一站，而非返回对方处调查或沉默。

**近迁移桥：**家庭与学校共同写明第一、第二和校级求助通道。

**停止/降档：**儿童因“没人会帮我”而退缩或成人把接力变成耐挫测试时停止，改由成人示范。

**与既有 70 局及 FBL 去重：**游戏 10 练帮助剂量，41 练选择可达成人，42 练报告组成；FBL 在第一位老师处成功，本局专练未处理后的持续升级。

### 游戏 44｜家长“听见—相信—行动”确认台

**主目标/副目标与明确非目标：**主目标是提高家长承接质量：听完并复述、认真相信儿童值得保护、说明并执行下一步；副目标是让儿童确认或更正摘要。非目标是审讯、立即裁定责任、强迫讲全或承诺结果。

**材料与先备：**“听见—相信—行动”三卡，儿童确认/更正/暂停卡，低强度玩偶情境及成人行动卡。成人先练短句和等待。

**角色与儿童所有权：**儿童是消息所有者，可口述、指卡、让玩偶代说或停止；家长是承接者，负责安全、记录和后续，不让儿童安慰成人或设计处置。

**8–15 分钟默认玩法：**

1. 儿童或玩偶交出一张情况卡；
2. 家长停下手中活动，安静听；
3. 家长复述事实，儿童确认或更正；
4. 家长感谢告知，明确不是儿童的错；
5. 先落实陪伴、分开或联系负责成人等保护动作；
6. 说明需要告诉谁、下一步及反馈时间；
7. 移动行动卡表示已执行。

**直接话术：**

> “谢谢你告诉我，我会认真对待；这不是你的错。”  
> “我听到的是___，对吗？”  
> “我不能答应谁都不说；为保护你，我只告诉需要帮助的人，并尽量先告诉你下一步。”

**三档玩法：**

- **6 岁起步：**儿童交卡，家长完成三句回应。
- **7 岁进阶：**儿童确认摘要并选择一种眼前支持。
- **8 岁挑战：**儿童用三卡检查家长是否遗漏确认、行动或反馈。

**ADHD 支架：**三卡固定顺序；家长每步一句；儿童可只举确认或暂停卡。

**安全：**真实披露立即停局；不诱导追问、不当面对质、不承诺绝对保密，也不把“相信”写成未经调查即判定全部事实。

**设计理由与证据边界：**这是以成人执行为指标的【官方实践/实施设计】；短局不能证明创伤恢复、调查结论或学校处置质量。

**观察指标：**家长是否完成三环，并让儿童真实更正一次；不以儿童讲了多少评分。

**近迁移桥：**儿童报告一次低风险不舒服时，家长沿用同一回应并按约反馈。

**停止/降档：**家长辩解、怀疑、追问细节或忘记行动时暂停，只练“听见并复述”。

**与既有 70 局及 FBL 去重：**主目标不是儿童求助表现，而是成人承接、保密边界和反馈闭环；FBL 虽有教师安慰，本局把成人质量变成可核查主循环。

### 游戏 45｜网络证据成人交接舱

**主目标/副目标与明确非目标：**主目标是儿童停止接触并把设备或信息交给成人，由成人负责保存必要证据、屏蔽和举报；副目标是说出一条可见事实和当前需要。非目标是卧底、套话、追查身份、判定违法或训练数字取证。

**材料与先备：**全纸制虚构聊天界面，停止、盖屏、交接卡及仅供成人角色打开的“保存—屏蔽—举报”封套。先约定儿童不回复、不转发、不继续查看。

**角色与儿童所有权：**儿童任设备使用者，拥有立即退出、盖住内容和选择交给哪位成人的权利；成人接管后承担全部证据、平台、学校及保护程序。

**8–15 分钟默认玩法：**

1. 翻出一张低强度虚构消息，如反复嘲笑、索要资料或催促转私聊；
2. 儿童放“停止接触”卡，不作回复；
3. 将纸设备盖住并移入交接区；
4. 向成人说一条事实和需要；
5. 儿童离开证据操作区；
6. 成人打开封套，模拟保存必要页面、屏蔽账号、平台举报及联系学校；
7. 成人说明眼前安全安排和反馈点。

**直接话术：**

> “我已经停止回复。有人在网上___，请你接手。”  
> “你不用继续看、套话或证明；保存、屏蔽和举报由我处理。”

**三档玩法：**

- **6 岁起步：**看到警示图标后完成“停—盖—交”。
- **7 岁进阶：**交接时补一条可见事实和一项需要。
- **8 岁挑战：**比较“继续回复取证”与“停止后成人接管”，说明后者为何更安全。

**ADHD 支架：**只出现一条消息；三格流程常显；儿童交接后立即换到安静活动，不旁观成人操作。

**安全：**不登录真实账号，不用真实姓名、截图、链接、秘密或私密影像；不秘密调查、不审问、不承诺绝对保密。现实中若有威胁、诱约或私密影像，成人不得要求重开、复制或转发，应按所在地紧急和未成年人保护流程处理。

**设计理由与证据边界：**把任务边界设为“儿童停接触、成人接管”，只支持流程理解；不证明网络风险识别、数字取证或现实自保能力。

**观察指标：**儿童是否未回复即交接，且保存、屏蔽、举报三项均由成人角色完成。

**近迁移桥：**家庭只约定设备交接地点、代码词和两名成人，不用真实消息演练。

**停止/降档：**儿童想继续聊天取证、内容引发恐惧或出现真实事件时立即停局并由成人接管。

**与既有 70 局及 FBL 去重：**不同于游戏 22 的最少信息、42 的事实报告及旧证据核验；FBL 聚焦线下求助，本局核心是儿童退出后将数字处置权完整移交成人。

## 17. 旁观支持、恢复与系统保护：不当英雄，让成人改变环境

### 游戏 46｜旁观者不加油站

**主目标/副目标与明确非目标：**主目标是看到虚构伤害时撤走注意力，不笑、不围观、不起哄；副目标是转向成人支持。非目标是身体介入、当英雄、训斥或裁定谁在欺凌。

**材料与先备：**低强度纸面场景、笑/围观/离开/找成人卡、成人站和停止卡。成人先示范“不给反应”不等于忽视受影响者。

**角色与儿童所有权：**儿童选择旁观者动作，也可只指卡；受影响玩偶不负责指导旁观者。成人承担制止、调查和保护。

**8–15 分钟默认玩法：**

1. 翻一张虚构场景；
2. 儿童移走“笑、围观、拍摄”卡；
3. 把旁观者移向成人站；
4. 用一句可见事实报告；
5. 成人接手，儿童任务结束。

**直接话术：**

> “我不跟着笑，也不围过去。”  
> “老师，那边有人被挡住了，请您来看。”

**三档玩法：**

- **6 岁起步：**从“加油/不加油”两卡中选择。
- **7 岁进阶：**完成撤开—找成人。
- **8 岁挑战：**解释为什么不围观能减少伤害扩散，但不猜动机。

**ADHD 支架：**一次一景、两张动作卡、成人站始终可见；可用移动玩偶代替说话。

**安全：**不真实辱骂、推撞或围堵；旁观者不靠近、不拦人、不拍摄取证。

**设计理由与证据边界：**整校项目支持改变同伴规范和成人响应，但不能证明一次家庭游戏会改变现实旁观行为。

**观察指标：**三次机会中，能否在提示下撤走一种“社会加油”并转向成人。

**近迁移桥：**观看虚构动画时，只指出“哪个动作没有加油”。

**停止/降档：**出现兴奋模仿、真实披露或英雄式介入计划，立即停局并由成人处理。

**与既有 70 局及 FBL 去重：**核心是旁观者撤回注意力，不重复 FBL“说停—离开—报告—陪伴”的完整剧情；也不是游戏 19 的规则试行、21 的主持或 25 的承载量调度。

### 游戏 47｜结伴找成人

**主目标/副目标与明确非目标：**主目标是在不增加风险时先征得同意，再与同伴走向可信成人并完成交接；副目标是简短事实报告。非目标是拉拽、护送穿过危险区、独自对峙或替同伴讲完整经历。

**材料与先备：**纸面场景、两条安全路线、成人站、愿意/不愿意同行卡和“谁做了什么—在哪里”报告条。

**角色与儿童所有权：**受影响玩偶拥有是否同行、走哪条路和是否开口的决定权；儿童扮支持者，只邀请一次。成人负责接报和后续保护。

**8–15 分钟默认玩法：**

1. 成人摆出成人站和安全路线；
2. 支持者问是否需要陪同；
3. 同伴可同意、拒绝或改路线；
4. 同行时保持距离，不经过不安全角色；
5. 到站后支持者说一项所见事实，成人接手。拒绝同行时，支持者仍可自己报告。

**直接话术：**

> “你想让我陪你找老师吗？不想也可以。”  
> “我看到有人挡住他，请您来帮助。”

**三档玩法：**

- **6 岁起步：**指选成人站并移动两只玩偶。
- **7 岁进阶：**先问同意，再完成一句交接。
- **8 岁挑战：**面对路线受阻时改找另一位成人，不返回对峙。

**ADHD 支架：**路线只留两条；使用“问—走—说”三格板；报告可照图读。

**安全：**旁观者不身体介入、不当英雄；距离不安全时直接独自找成人。

**设计理由与证据边界：**结伴可能降低求助门槛，但一局不能证明现实勇敢、同伴信任或学校响应改善。

**观察指标：**是否先询问同行意愿，并把任务交给成人而非自行解决。

**近迁移桥：**在公共场所练习辨认两位可求助成人，不设置假危险。

**停止/降档：**儿童害怕、开始回忆真人或要求演追逐时，改为只指成人站或结束。

**与既有 70 局及 FBL 去重：**本局只练“同意式同行—成人交接”，不重演 FBL 完整四步；决策对象也不是游戏 19 的规则、21 的发言流程或 25 的任务负荷。

### 游戏 48｜事后陪伴与重新加入

**主目标/副目标与明确非目标：**主目标是在事件已由成人处理后，按受影响儿童的偏好提供陪伴，并把是否、何时、怎样重新加入交还给他；副目标是接受偏好变化。非目标是强迫回群体、和解、原谅或证明“已经没事”。

**材料与先备：**虚构玩偶、“安静陪着/一起做别的/远处等/暂不陪伴”卡，以及“观察/换组/选角色/今天不回”卡。成人先说明“不重新加入”也是完整结局。

**角色与儿童所有权：**受影响玩偶拥有全部选择并可随时改变；儿童扮陪伴者，只提供一次邀请。成人维持安全、处理群体环境。

**8–15 分钟默认玩法：**

1. 成人宣布现场已安全；
2. 陪伴者展示四张支持卡；
3. 受影响玩偶选择或拒绝；
4. 安静完成一分钟所选活动；
5. 只问一次下一步；想加入时由其选地点、伙伴和角色，不想加入则从独立活动收尾。

**直接话术：**

> “你想要陪着、空间，还是做别的？”  
> “回不回去由你决定，我不会催。”

**三档玩法：**

- **6 岁起步：**在“陪着/空间”中选择。
- **7 岁进阶：**选择支持方式和本局结局。
- **8 岁挑战：**中途改一次偏好，陪伴者不劝说、不失望。

**ADHD 支架：**每次只展示两卡；用一分钟低需求活动过渡；不连续追问感受。

**安全：**不重演伤害，不安排伤害者、道歉或对质；成人先确认环境确已安全。

**设计理由与证据边界：**选择权可减少再次失控感，但游戏不能治疗创伤或证明儿童已准备重返群体。

**观察指标：**陪伴者是否接受一次拒绝或改选，且未劝说重新加入。

**近迁移桥：**普通游戏中有人休息后，用同样方式邀请一次并接受“不回来”。

**停止/降档：**出现催促、内疚话术、真实披露或明显退缩，立即停止邀请。

**与既有 70 局及 FBL 去重：**核心是事后、儿童控制的陪伴与可不重返，不是 FBL 完整现场四步；也不同于游戏 19 试规则、21 主持发言和 25 按承载量派任务。

### 游戏 49｜群聊不点赞不转发

**主目标/副目标与明确非目标：**主目标是遇到虚构群聊羞辱或隐私传播时不点赞、不评论助推、不转发，并把设备交给成人；副目标是理解一次点击会扩大受众。非目标是公开反击、卧底取证、核实传言或教育发送者。

**材料与先备：**纯纸制群聊界面、虚构头像和低强度消息卡、“点赞/回复/转发/不互动/找成人”卡。不得使用真实账号、姓名、截图或事件。

**角色与儿童所有权：**儿童拥有停止观看、放下设备和选择可信成人的权利，不负责保存证据；成人负责必要留存、屏蔽、举报及联系学校或平台。

**8–15 分钟默认玩法：**

1. 翻一张虚构消息；
2. 儿童盖住点赞、回复和转发键；
3. 把“不互动”卡放到消息上；
4. 将纸设备移交成人站；
5. 成人说明后续由成人处理，并用受众圆点演示“不转发少扩一层”。

**直接话术：**

> “我不点赞，也不转发。”  
> “这里有人被羞辱，请你现在帮忙处理。”

**三档玩法：**

- **6 岁起步：**在“转发/交成人”中选择。
- **7 岁进阶：**完成三不做和成人移交。
- **8 岁挑战：**解释表情点赞也可能形成围攻，但不继续查看消息。

**ADHD 支架：**一次一条消息、按钮不超过四个；完成移交即结束，不做连续判断题。

**安全：**不登录、不搜索、不点链接、不联系发送者；不要求儿童继续暴露于内容以取证。

**设计理由与证据边界：**减少互动可避免儿童参与扩散，但平台机制各异，一次纸卡练习不能保证网络安全行为。

**观察指标：**是否避开三个放大动作，并在一个提示内转交成人。

**近迁移桥：**观看虚构界面时指出“哪个按钮会扩大传播”，不实际点击。

**停止/降档：**出现真实群聊披露、威胁、私密影像或住址暴露，立即停局并启动成人保护程序。

**与既有 70 局及 FBL 去重：**核心是网络传播闸门，不是 FBL 线下完整四步，也不是游戏 22 的最少信息、19 的规则试行、21 的主持或 25 的承载量安排。

### 游戏 50｜家庭—学校保护计划桌

**主目标/副目标与明确非目标：**主目标是把儿童表达的需要和偏好转成由成人承担的学校沟通、环境改变和复查动作；副目标是让儿童核对方案是否合身。非目标是让儿童举证、联系学校、面对对方、管理计划或保证绝对安全。

**材料与先备：**“希望靠近成人/私下报告/调整路线或座位/同伴陪同/暂不知道”卡，成人行动卡、负责人栏、日期栏和复查卡。成人预先核对学校正式渠道。

**角色与儿童所有权：**儿童只拥有需要、偏好、可共享范围和更改权；家长负责记录、联系学校和跟进，学校成人负责监督与环境措施。儿童没有协调责任。

**8–15 分钟默认玩法：**

1. 成人声明“保护和沟通由大人负责”；
2. 儿童选一至两张需要卡，也可选“不知道”；
3. 成人为每项填写负责人、动作和完成时间；
4. 儿童用“合适/想改/不确定”核对；
5. 成人加入备用联系人和复查日期；
6. 以“下一次由谁反馈给你”收尾。

**直接话术：**

> “你只需要告诉我什么会让你更安全。”  
> “联系学校和改变环境是大人的工作。”

**三档玩法：**

- **6 岁起步：**从两张需要卡中选择。
- **7 岁进阶：**核对一项成人行动是否符合偏好。
- **8 岁挑战：**检查每项需要是否都有成人负责人和复查点，不承担联络。

**ADHD 支架：**儿童区只放两张卡；成人栏分开填写；一次讨论一个场景，十分钟到点即停。

**安全：**真实披露出现时停止游戏，先确保安全并启动学校、医疗、公安或保护程序；不以填表延迟行动。

**设计理由与证据边界：**反欺凌证据支持成人和学校的多层环境响应；一张计划桌不能保证执行、消除风险或替代正式程序。

**观察指标：**每项儿童需要是否对应明确成人动作，且没有任务被回推给儿童。

**近迁移桥：**成人把一项偏好写入真实沟通草稿，发送前让儿童决定可共享范围。

**停止/降档：**成人开始追问证明、要求儿童自己报告或承诺无法保证的结果时立即停止。

**与既有 70 局及 FBL 去重：**核心是成人拥有的家校保护与环境改变，不是 FBL 儿童完整四步；也不把计划做成游戏 19 规则试行、21 儿童主持或 25 承载量调度。

## 18. 学科、社交与保护映射：到底在练什么

### 18.1 一局一主目标，其他只作载体

五十局可以同时含语言、数量、协作、安全保护和载具情节，但测量时必须先写唯一主目标。若同一轮既纠正英语、又计数、又评主持、又测试是否会求助，孩子的错误来源和提示需求将无法解释。以下分轨是课程地图，不是把所有目标塞进一局。

| 分轨 | 直接可观察内容 | 优先游戏 | 成人必须先教什么 | 可检查的近迁移 | 不能据此推断 |
|---|---|---|---|---|---|
| 邀请与授权 | 邀请、听回应、允许修改/拒绝、归还所有权 | 1、4、9–11 | 拒绝不等于不合作；帮助分剂量 | 收纳、手工、家庭小任务 | 现实领导身份、独立人格 |
| 异议与调解 | 邀请不同意见、准确复述、标未知、试行修订 | 2、6、7、19、21 | 反对事不等于反对人；安全问题由成人处理 | 周末计划、共同用品规则 | 同伴接纳、冲突已解决 |
| 边界、求助与承载量 | 暂停、选择帮助、报告承载量、重新同意 | 3、10、25 | 暂停即时有效；休息不必自证 | 拼搭、作业启动、家庭整理 | 自控、韧性或 ADHD 改善 |
| 责任与可靠协作 | 拉取一项、独立核对、最少必要信息、按标准验收 | 11、12、15、22、30 | 只报告可见证据；未知可保留 | 清点文具、作品检查、简单交接 | 道德人格、真实工作能力 |
| 语文 | 沿用/新增、作者/来源、因果词范围 | 16、17、29 | 明示来源类型、因果与先后区别 | 共编绘本、介绍作品、校对生活句 | 系统识字、阅读流利、作文成绩 |
| 数学 | 时间区间、部分—整体、等号等量 | 8、18、23 | 用实物/数轴示范概念与反例 | 家庭活动时间线、分积木、分点心 | 稳定运算和应用题迁移 |
| 数量证据 | 一一计数、双记录对账、可见缺口 | 12、15 | 一格一物、先配对再判断 | 袜子配对、笔槽清点 | 心算速度、总体数学水平 |
| 英语 | 描述核对、单指令理解、不懂时澄清 | 5、14、20 | 少量词义、图片、句框与求助权 | 换背景保留同一句框 | 口音、自由口语或总体英语水平 |
| 算法与工程 | 顺序执行、首个偏差、接口、公开验收标准 | 13、26、30 | 先示范执行和核对，不让成人暗中补意图 | 生活步骤卡、合作手工接口 | 编程或工程天赋 |
| 系统与物理模型 | 影响链、依赖箭头、相邻传播、模型局限 | 24、27、28 | 模型、现实与未知三者分开 | 家庭低风险计划、普通流程链 | 真实预报、电学或正式声学知识 |
| 识别与分流 | 愿意、停止信号、重复、力量差、协同排挤、事实/未知 | 31–35、40 | 先安全后分类；儿童不作正式认定 | 虚构绘本和动画的事实分流 | 判断真人动机、法律或校规结论 |
| 边界与退出 | 按安全条件说停或离开、识别操控压力、身体/物品边界 | 36–39 | 说停可跳过；离开和告诉均算勇敢 | 熟悉场所的成人站、家庭真实同意 | 现实危机中必然执行 |
| 告诉与成人承接 | 选可达成人、事实+需要、持续升级、成人反馈、数字交接 | 41–45 | 求助不是告状；成人负责调查与处置 | 家庭低风险不舒服报告 | 报告正确即可终止欺凌 |
| 旁观与系统保护 | 不助推、同意式陪同、事后陪伴、网络不扩散、家校计划 | 46–50 | 不身体介入；成人改变监督和环境 | 虚构旁观卡与真实求助岗位 | 儿童有责任救人或治理学校 |

### 18.2 邀请式领导的行为链

所谓“领导”不是固定角色，而是可轮换的九个动作。儿童无需一次做到全部；成人只选一个作为本局观察点。

| 行为 | 最清楚的练习局 | 最小合格表现 | 常见伪装 |
|---|---|---|---|
| 明确共同目标 | 1、19、30 | 说清本轮一起完成什么 | 队长宣布个人愿望 |
| 邀请参与 | 1、21 | 对方能接受、修改或跳过 | 用问句包装命令 |
| 经同意分工 | 1、11、25 | 听完偏好再放角色卡 | 成人或“队长”直接派单 |
| 保护异议 | 2、7、21 | 决定前准确复述一项不同意见 | 只让异议者说完但不回应 |
| 支持求助 | 4、10 | 只给被请求的帮助剂量 | 看到卡顿立即接管 |
| 检查影响 | 6、19、24 | 询问谁受影响并保留未知 | 只问任务是否完成 |
| 共享功劳 | 4、17、25、30 | 角色贡献分别署名 | 主持人把团队成果算成自己的 |
| 承担修复 | 3、9、26、30 | 描述差距并把修法交回所有者 | 强迫道歉或代替返工 |
| 放弃/交还权力 | 9、10、21 | 接收者可拒绝反馈，主持不替人决定 | “为你好”取消选择 |

### 18.3 策略性勇敢的保护链

| 动作 | 优先游戏 | 最小合格表现 | 不能怎样评分 |
|---|---|---|---|
| 看可见信号 | 31–35、40 | 指出行为、影响或退出障碍，未知就标未知 | 猜中“坏人” |
| 按安全分流 | 36、37 | 安全时可说一句；不安全/不确定时直接离开 | 是否敢当面对峙 |
| 找可信成人 | 41–43 | 选可达成人；未承接就继续告诉 | 一次报告不完整就扣分 |
| 成人承接 | 44、45、50 | 感谢、复述、行动、反馈；儿童退出处置 | 让儿童承担调查 |
| 旁观不助推 | 46、47、49 | 不笑、不围观、不转发，安全地叫成人 | 是否亲自制止 |
| 事后支持 | 48 | 接受空间、改选或暂不重返 | 是否原谅或恢复得快 |

### 18.4 四条学科教学纪律

1. **语文：先建概念再创作。**成人先示范“图上已有—别人说过—我新编”和“先后不自动等于因果”，再让儿童口述；不要用写字负担遮住语言目标。
2. **数学：让关系可见。**时间用完整区间块，数量用一一对应，分合用部分—整体垫，等号用两边同值反例；熟练后才逐渐撤材料。
3. **英语：意思优先。**每次只教少量词或一句话，允许指图、中文求助和重复；是否理解看动作与确认，不看口音像不像。
4. **STEM：模型必须可错、可改且有边界。**成人示范一次，儿童预测、运行、保留结果、局部修订，并明确“只适用于当前卡组/材料/条件”。

## 19. 家庭使用：选局、路线、人数变体与迁移

### 19.1 先按状态，再按目标选局

| 当下状态 | 适合的入口 | 成人动作 | 暂缓 |

| 平静、愿意共同玩 | 从目标栏任选一局的当前能力档 | 只声明一个主目标 | 一次开两局 |

| 想安全帮助同伴 | 46–49 | 不助推、找成人、事后陪伴 | 身体介入、秘密取证 |
| 想学语数英或 STEM | 先从 18.1 选一分轨 | 先教一个概念再玩 | 把载具自由玩变成随堂测验 |
| 拒绝所有结构 | 儿童主导连接 | 模仿、描述、少提问；改日再邀 | 用奖励或撤玩具逼参加 |

### 19.2 10–12 周低负担路线

默认每周只安排 **1–2 次、每次 8–15 分钟**的引导局，另保留不教学的自由玩；不要求完成 50 局。若儿童连续两周抗拒、睡眠/运动被挤压或成人越来越控制，应减量或暂停。

| 周次 | 重点 | 候选安排 | 进入下一步的条件 |
|---|---|---|---|
| 1 | 建立连接和停止权 | 三次儿童主导自由玩；另做游戏 3 最低档一次 | 暂停后成人能立即停 |
| 2 | 学会求助而不被接管 | 游戏 10；生活中只迁移帮助类型卡 | 儿童至少能指选帮助或暂停 |
| 3 | 邀请与选择 | 游戏 1；双人版即可 | 成人能接受拒绝、不偷偷派单 |
| 4 | 听完再主持 | 游戏 21；只观察一次复述 | 主持权与决定权能分开 |
| 5 | 保护异议 | 游戏 2 或 7 | 异议不受嘲笑，能留下未解决项 |
| 6 | 反馈或规则试行 | 游戏 9 或 19 | 能只改一处并保留拒绝权 |
| 7 | 儿童自选一个学科分轨 | 从 5/8/13/16/18/20/23/28 中选一局 | 儿童愿意，成人先备了必要示范 |
| 8 | 同目标换表面 | 将第 7 周局换一种载具或材料 | 关键结构保留，未撤光提示 |
| 9 | 合作接口或工作所有权 | 游戏 11 或 26 | 双方不抢改对方作品 |
| 10 | 证据与共享功劳 | 游戏 12、17 或 30 | 能报告未知并分别署名 |
| 11 | 一次生活近迁移 | 只迁移一个动作，如求助、复述或核对 | 不提醒时偶尔出现，或提示减少 |
| 12 | 复盘与选择 | 看分轨记录，由儿童选保留、修改或停止 | 不按完成数量评成功 |

可在第 6、8 或 10 周重复一周。若当前家庭首先需要学科支持，也应先完成第 1–2 周的暂停与求助契约，再进入相应分轨。

### 19.3 8–10 周反欺凌并行路线

这是一条**预防性微技能路线**，不要求儿童已有被欺负经历，也不能用来替代对真实事件的立即保护。每周最多一局；若已有真实披露，先走 §6.5 的成人处置，不等待路线完成。

| 周次 | 窄目标 | 候选游戏 | 成人质量门 |
|---|---|---|---|
| 1 | 建立“可退出、可告诉”契约 | 31、44 | 儿童拒演也被接受；成人先练承接 |
| 2 | 识别一次、模式与严重一次 | 32 | 不等够重复才保护，不给真人贴标签 |
| 3 | 看力量差与退出障碍 | 33、35 | 不责怪“为什么不反抗/不加入” |
| 4 | 安全说停或直接离开 | 36、37 | 两条路径同样算成功 |
| 5 | 秘密、礼物、威胁和身体/物品边界 | 38、39 | 不使用真实秘密或真实接触演练 |
| 6 | 找成人与事实+需要 | 41、42 | 报告不完美也先保护 |
| 7 | 第一位成人未承接时继续告诉 | 43、44 | 系统失职不归责儿童 |
| 8 | 旁观者不助推并安全陪同 | 46、47 | 不要求身体介入 |
| 9 | 网络停止接触与成人交接 | 45、49 | 不登录、不套话、不让儿童取证 |
| 10 | 事后陪伴和成人保护计划 | 48、50 | 不逼和解、原谅或快速重返 |

第一次近迁移只换玩具或绘本；第二次才在无真实风险的生活场景辨认可信成人。不要安排同伴假装欺负来测试，不在学校现场突然提问，不以儿童能否背四步法判断安全能力。

### 19.4 两人、三人、同伴与玩偶替代

| 人数/组合 | 怎样分角色 | 能练什么 | 不能算作什么 |
|---|---|---|---|
| 一名儿童+一名成人 | 成人兼安全员与一个任务角色；轮换一次 | 邀请、复述、求助、概念学习 | 真实同伴接纳 |
| 一名儿童+两名成人 | 一人任务角色，一人只观察主目标；下一局换观察者 | 三方主持、异议、独立验收 | 成人联盟“考孩子” |
| 两名儿童+一名成人 | 儿童各有不可替代输入；成人仅守流程和安全 | 真实轮流、协商与不同偏好 | 自动等于学校迁移 |
| 三名以上儿童 | 缩短为一轮；每人一张卡；设跳过与观察角色 | 小组主持和少数意见 | 让最外向者固定当队长 |
| 无可用同伴 | 两个玩偶分别持不同信息，儿童只代言其中一个 | 程序、句框、信息链 | 真实观点差异和同伴关系 |

玩偶只能补足结构，不能假装儿童已在真实同伴中掌握。安排真实同伴局时，先用共同兴趣、短时长和低风险任务，不向同伴公布“今天要训练他领导力”。

反欺凌局默认由纸卡表示不友善要求，或由成人承担低强度虚构角色；不要让兄弟姐妹、同伴或儿童轮流扮演“欺负者”。两名成人在场时，一人只负责儿童选择和停止权，另一人练接报；不得组成“成人评审团”追问孩子。

### 19.6 多照护者协作

1. **共同使用一页契约：**唯一主目标、当前档位、暂停信号、禁止材料、儿童有效的帮助方式。
2. **一周只改一个变量：**例如先只改材料数量；祖辈、父母不要同时撤图卡、增台词和延长时间。
3. **记录事实，不交换标签：**说“提示到二选一后完成 2/3 次”，不说“他在我这里更乖/更懒”。
4. **不比较照护者输赢：**儿童在不同人面前表现不同，是情境信息，不是某位成人更有权威的证据。
5. **每周十分钟同步：**保留什么、降什么、停止什么；无需逐局汇报。
6. **发生冲突先修关系：**成人若曾催促、嘲笑或越权，直接承认具体行为并恢复停止权，不用下一局“练回来”。
7. **统一真实披露响应：**任何照护者先听、感谢、不责备，不承诺绝对保密；指定一名成人统筹学校/专业沟通，并按约向儿童反馈，避免多名成人反复询问。

## 20. 分轨测量：既能看变化，又不把生活变成考试

### 20.1 为什么不合成总分

“主持时复述”“能把 8 分成两部分”“主动用英语请求澄清”“在纸卡上选安全退出”不是同一种能力，不能相加成“领导力总分”“社交分”“学霸分”“勇敢分”或“反霸凌能力分”。合成分会掩盖三个关键信息：儿童到底在哪一步需要支架、成人是否守协议、变化是否只出现在熟悉游戏里。

每次最多记录一个主目标，按八条轨道分开看：

| 轨道 | 最少记录什么 | 例子 | 不怎样解释 |
|---|---|---|---|
| 成人执行 | 是否示范、等待、按阶梯提示、尊重暂停 | 3 次暂停均立即停 | 不用儿童成功掩盖成人越权 |
| 儿童近端行为 | 合格行为次数/真实机会数 | 3 次邀请机会中听完回应 2 次 | 不写“很有领导力” |
| 档位与提示 | 6/7/8 岁档；最高必要提示 | 7 岁档，二选一后完成 | 不把低提示等同人格成熟 |
| 生活/同伴近迁移 | 相近真实情境是否出现，支架是否保留 | 收纳时主动选“线索”一次 | 不把父母局算学校迁移 |
| 学科表现 | 单独、短而同构的任务 | 换成积木后仍能分出 3+5=8 | 不把同一材料重做算远迁移 |
| 体验与反指标 | 愿意度、压力、退出、羞耻、睡眠和冲突 | 主动再玩；无催促 | 不以完成率压过关系 |
| 保护性分流 | 虚构情境中是否按可见条件选说停/离开/告诉 | 出口被挡时选直接离开 | 不写“已会现实自保” |
| 成人承接 | 是否感谢、复述、行动、反馈且不审问 | 完成听见—相信—行动 | 不用儿童多讲证明成人做得好 |

### 20.2 机会、合格表现与提示等级

先写“机会”，再写成功数。成人必须提供真实选择才算邀请机会；儿童从未卡住就不能声称“没有求助问题”；成人未停就不能把儿童停止失败归给孩子。

**提示等级：**

```text
0 = 独立出现
1 = 环境线索或步骤板
2 = 手势/指图
3 = 一个关键词
4 = 二选一
5 = 示范一步
6 = 共同完成
X = 儿童拒绝、成人中止或无有效机会
```

`X` 不是 0 分。它提醒成人分别判断：当天状态不合适、任务设计不当、成人没有守协议，或儿童合理不参加。

### 20.3 单次最小记录模板

每周记录 1–2 次即可；普通自由玩不记录。以下可抄到纸上或纯文本中：

```yaml
日期: 2026-10-23
游戏与档位: "10 船队求助灯 / 6岁起步"
唯一主目标: "卡住时选择帮助类型，并在帮助后取回任务"
儿童是否自愿开始: 是
机会定义: "明显停住约5秒后，成人展示帮助卡"
合格表现: "指选一种帮助；成人只给该剂量；儿童决定下一步"
儿童近端行为: "2/3 次；最高提示4（二选一）"
成人执行: "2/3 次守剂量；一次多示范了一步"
体验: "结束后愿再玩；无羞耻/争执"
反指标: "无；未挤压睡眠、运动或自由玩"
真实披露或成人接管: "无"
近迁移: "本次不查"
下次只改一项: "成人给帮助后立即交还船长牌"
```

反欺凌局出现真实披露时，不再记“儿童完成率”；只记“游戏已停、成人已接管、下一保护动作和反馈时间”，真实事件记录另按学校/当地程序保存。

### 20.4 各分轨的窄指标

**社交与邀请式领导**

- 邀请：完成“邀请—听完—确认”的次数/机会；
- 异议：决定前，少数意见被原发言者确认复述的次数；
- 主持：是否邀请跳过、是否把决定权留给团队；
- 求助：所请求剂量与实际获得剂量是否一致；
- 责任：是否描述具体影响并完成一个实际修复，而非口头认错；
- 功劳：贡献角色是否分别署名。

**语文**

- 能否把“卡上已有、别人提供、自己新增”分开；
- 因果句的两端是否有支持；依据不足时能否改为“随后/可能/不知道”；
- 换一张同难度图片后，是否仍能口述结构；不把字迹、写字速度混入。

**数学**

- 时间：能否放完整区间，并发现越界/重叠；
- 分合：能否用材料形成目标整体，再换一种分法；
- 等号：能否证明两边同值，并识别 `5=3+2` 与 `3+2=5` 都成立；
- 计数：能否逐项配对、指出缺口；不记录竞速。

**英语**

- 指令：在何种图片/重复支架下动作表达正确意思；
- 描述：接收者能否据描述在有限选项中确认目标；
- 澄清：行动前是否指出不懂、请求修复并确认；
- 不记录口音、响度、背诵长度或像母语者程度。

**物理/STEM**

- 是否先说预测，再运行模型或测试；
- 是否只沿已确认箭头/接口/步骤得出结论；
- 修改前后是否只变一个关键处；
- 能否说出“当前条件”和至少一个模型局限；
- 不把纸卡成功解释为正式物理概念掌握。

**反欺凌与不安全联系**

- 识别：只在虚构卡上记录是否区分愿意/停止、一次/模式/未知、力量差或退出障碍；
- 安全分流：不安全或不确定时能否选“直接离开”，不以必须说停为成功标准；
- 告诉链：能否选可达成人和备选；第一位未行动时是否转下一站；
- 报告：是否有一条卡上事实和一项需要；报告不完整也不能延迟保护；
- 旁观：是否不笑、不围观、不转发，并把任务交成人；不评“敢不敢制止”；
- 成人承接：是否完成感谢告知、准确复述、眼前保护、后续动作和反馈点；
- 体验/反指标：是否出现僵住、羞耻、自责、睡眠变化、真实披露或成人审问；任一项优先于得分。

### 20.5 真实近迁移和同伴观察

迁移检查须满足四条：目标结构相同、只换一个表面、关键支架仍可用、儿童不知道自己在被突击考试。观察窗口可为 2–4 周，不要求每天出现。

| 层级 | 例子 | 怎样记录 | 解释上限 |
|---|---|---|---|
| 同局复现 | 同一玩具、同一角色再次完成 | 提示是否下降 | 熟悉任务学习 |
| 换玩具近迁移 | 船队求助换拼图求助 | 机会数、提示等级 | 相近结构迁移 |
| 家庭生活迁移 | 收纳时选择帮助剂量 | 一句事实记录 | 一个家庭情境 |
| 真实同伴迁移 | 与熟悉同伴时主动邀请并接受拒绝 | 只记自然出现；不导演 | 该次同伴情境 |
| 学校表现 | 教师已有记录或常规作品中的同类行为 | 征得必要合作后看趋势 | 不归因于某一局 |

不要让同伴配合“测试”儿童，不在儿童面前讨论领导或勇敢等级，不让教师增加额外评分负担；尤其不能在学校现场安排假欺负、突然堵路或发虚假消息。学校变化若不存在，先视为尚未迁移；不要追加家庭练习量来逼结果。真实欺凌是否停止要看成人监督、学校处置、同伴生态和儿童功能，不归功或归责于游戏表现。

### 20.6 每周十分钟复盘

依次只问：

1. 儿童是否总体愿意，关系与基本生活是否未受损？
2. 成人执行最常失守在哪一步？
3. 某一主目标的提示是否稳定下降，还是只因任务变简单？
4. 是否出现一项相近情境迁移？没有也属正常。
5. 是否有真实披露或安全线索需要成人另行处理？
6. 下周是保持、只改一项、降档、暂停，还是回自由玩？

**继续：**愿意度稳定，成人守协议，近端目标有真实机会。  
**只改一项：**表现稳定且儿童要求变化；优先换角色、换表面或撤一种提示。  
**降档：**连续两局需大量提示、成人接管增加、错误羞耻或启动变慢。  
**暂停：**持续抗拒、恐惧、攻击、睡眠/运动受损、成人依赖奖惩或真实功能恶化。

## 21. 与既有 70 局及 FBL 的实质去重审计

### 21.1 审计方法

标题和故事皮肤不参与判定。只有同时核对以下四项，才能排除“把飞机换成轮船”的假创新：

1. **核心循环：**孩子反复执行的最小闭环；
2. **主要材料操作：**实际移动、分类、记录、测量或表达什么；
3. **决策结构：**谁有信息、谁决定、能否拒绝、怎样处理分歧；
4. **唯一主目标：**最后观察的窄行为或概念。

指图、轮流、步骤板、停止卡、成人示范和三档是通用可及性/安全支架，不算核心重复。下表把旧局与表面或结构最接近的新局作最严格比较；一个旧局只列最接近项，不表示二者应该连玩。

### 21.4 原 30 局审计结论

- 三十局均已在各自条目中写出独立的核心循环、主材料操作、儿童所有权、主目标和逐局去重依据。
- 与旧局共享载具、角色、卡片或“观察—反馈—修改”外形时，决策权或被观察概念至少有一项实质改变；表中四轴均不相同的条目才予保留。
- 最接近重复风险的是 19 对旧规则切换、22 对旧广播编辑、24/27 对旧系统游戏、30 对旧策展/交接。本文已分别用“参与式修订”“按角色最少字段”“模型影响边界”“独立验收与返修权”限定。
- 若家庭自行改版后删掉上述限定，例如把 19 变回成人临时换规则、把 22 变成删短句、把 30 变成成人评作品，则会重新退化为旧循环。

| 42 事实报告拼图 | 消防五要素；22 信息删减；FBL 成段台词 | 只拼“看见/听见的事实＋现在需要”，允许更正和不知道；不背台词、不取证、不由儿童作正式认定。 |
| 43 接力求助 | 41 成人地图；10 求助剂量；FBL 首次成功求助 | 第一位成人未处理时移动到下一通道并说“还没安全/还需要帮助”；主目标是持续升级而非重复证明。 |
| 44 家长确认台 | FBL 教师安慰；一般亲子角色扮演 | 家长反复练听见、相信、查即时安全、说明行动和回报；儿童可评成人是否承接，主目标明确落在成人表现。 |
| 45 网络证据成人交接舱 | 22 最少信息；42 报告；线下 FBL | 儿童停止回应并把设备/情况交成人；保存、屏蔽、举报由成人完成，主目标是数字处置权转移。 |
| 46 旁观者不加油站 | 19 规则试行；21 主持；FBL 完整旁观链 | 移走围观、起哄和传播筹码，再选安全求助；主目标是撤回社会强化，不要求旁观儿童身体介入。 |
| 47 结伴找成人 | 46 不助推；41 成人地图；FBL 陪伴 | 先问“要不要一起去”，同意后同行至成人交接；受影响者保留拒绝权，主目标是同意式陪同。 |
| 48 事后陪伴与重新加入 | 25 承载量调度；FBL 现场陪伴 | 事件后由受影响者选择安静陪伴、换活动、稍后加入或不重返；主目标是恢复控制感，不以和解或归队为成功。 |
| 49 群聊不点赞不转发 | 22 信息最小化；46 线下撤回注意；FBL 线下行动 | 用传播箭头演示不回复、不点赞、不转发和成人接管；不让儿童截图调查或公开反击。 |
| 50 家庭—学校保护计划桌 | 19 规则试行；25 任务安排；FBL 儿童行动链 | 成人填写联系人、环境改变、反馈时间和未改善升级路线；儿童只表达需要，主目标是系统保护而非儿童执行计划。 |

**总审计结论：**

- 五十局均有不同的窄主目标和可观察核心循环；新增 20 局不是把 FBL 情节换成载具，也没有把原有合作、求助或规则游戏重新命名。
- 新增局之间最易混淆的是 31/34（启动同意/停止响应）、32/33（重复模式/力量差）、36/37（安全分流/离场执行）、41/42/43（找谁/说什么/未处理后怎么办）、46/47/48（不助推/陪同求助/事后恢复）。使用时不得合并成一次儿童考试。
- 若删去“成人认定和承接”“可以直接离开”“不要求对质”“真实披露立即停演”等边界，这 20 局就会从保护性排练退化为让儿童承担安全责任，不能继续使用。

## 23. 最终使用清单

### 23.1 开局前

- [ ] 今天是儿童主导连接、引导式共同挑战，还是迁移检查？
- [ ] 唯一主目标已用一句话写清；
- [ ] 档位按当前能力和状态选择，不按年龄面子；
- [ ] 成人已准备必要示范，没有让孩子盲猜新概念；
- [ ] 接受、修改、跳过、暂停和结束都是真实选项；
- [ ] 材料数量、噪声、运动方向、电池、磁铁、小件和题材风险已检查；
- [ ] 反欺凌局只用虚构低刺激卡，且我知道真实披露后的成人流程；
- [ ] 自然终点可见，且不会挤压睡眠、运动、自由玩和普通关系。

### 23.2 游戏中

- [ ] 一次一句、一个动作、一个主目标；
- [ ] 成人按提示阶梯给刚够用的帮助；
- [ ] 主持权没有变成替别人决定；
- [ ] 反对、求助、未知和错误不会受惩罚；
- [ ] 反馈先获同意，修复权归原所有者；
- [ ] 学科结论限定在当前材料、模型和条件；
- [ ] 没有要求儿童猜恶意、反击、独自调解、当面对质或身体介入；
- [ ] 说停只在安全时可选；离开和告诉同样算完整成功；
- [ ] 儿童说停或关系恶化时立即停止。

### 23.3 游戏后

- [ ] 最多复盘一个过程动作，也可以不复盘；
- [ ] 只记录主目标、成人执行、提示和体验；
- [ ] 没有把游戏表现写成诊断、人格、天赋或学校能力；
- [ ] 下一次只保持、改变一项、降档或暂停；
- [ ] 若有真实披露，已停止评分并由成人启动保护、反馈和升级；
- [ ] 真实同伴和学科学习另行低调观察，不导演儿童“展示成果”。

这套指南的成功不在于完成五十局，而在于形成一个稳定循环：

```text
兴趣和关系先行
→ 成人提供清楚、安全、刚够用的结构
→ 儿童可以选择、异议、求助、出错、修订或停止
→ 涉及安全时儿童离开/告诉，成人承接并改变环境
→ 其他共同任务按证据行动并共享功劳
→ 只在相近新情境中谨慎检查迁移
```

当儿童越来越愿意参与、成人越来越少接管、一个窄目标在相近情境中需要的提示下降，同时睡眠、运动、自由玩和亲子关系没有被挤压，这些游戏就在做它们最适合做的工作。

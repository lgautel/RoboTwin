>
> 目标家庭：1–3 名 6–12 岁儿童。系统监听或接收亲子互动、家庭事件及历史，只向家长提供观察、解释、建议和复盘，不直接与儿童对话。

### 0.2 明确排除

- 按要求不讨论数据敏感性、隐私、合法合规、租户隔离、访问安全或许可证限制。
- 系统不直接面对儿童，因此不设计儿童聊天人设、儿童回复措辞门或儿童端陪伴关系。
- 是否有论文、代码、文档和数据仍作为“证据能否核查、工程能否复现”的信息，但许可条件不参与效果排序；量表具体版本和计分手册能否取得只影响测量可复现性。

### 0.3 仍必须保留的效果问题

以下不是合规问题，而是系统是否真正有用的问题：

1. 系统有没有听错、认错人或误解事件；
2. 抽象价值是否被错误压缩成“服从、坚持时长、点赞或量表高分”；
3. 家长是否看到、理解并实际执行了建议；
4. 家长动作是否按预期改变；
5. 儿童是否在真实机会中出现目标行为，而不是学会迎合测量；
6. 近端变化是否迁移到数周后的功能、关系和心理结果；
7. 自改进是否优于静态版本，而非只变得更流畅、更讨喜。

### 0.4 术语

- **RSI**：recursive self-improvement，递归自改进。本文区分一次输出变好、持久技能变好和改进器本身变好。
- **家庭价值章程**：由家长明确写下且版本冻结的规范目标，例如诚实、尊重、自主、责任、勇于尝试。它是家庭选择，不是模型从互动率中学习出来的“最优价值”。
- **机会事件**：儿童有真实选择和行动空间的事件，如遇到困难、收到帮助、造成影响、同伴冲突或需要修复。
- **证据动作库**：允许系统向家长推荐的版本化动作；每项含触发、适用条件、话术、剂量、机制、结局和证据边界。
- **事件账本**：只追加、不覆盖的原始事实、自动派生和人工修正记录。
- **状态假设**：对当前情境的可撤销解释，必须带来源、置信度和竞争解释。
- **家庭 playbook**：关于“这个家庭在何种情境下采用哪种动作后发生了什么”的原子经验，不是儿童人格档案。
- **incumbent / candidate**：当前已部署版本 / 等待验证的候选版本。
- **ITT**：按随机分配了什么建议来比较结果，不按家长最后是否执行来挑样本。

### 0.5 缩写与统计符号

- **RSI / LLM / HCI**：递归自改进 / 大语言模型 / 人机交互。
- **FAFO / FAPO**：Fully Automated Flow Optimization / Fully Automated Prompt Optimization，自动流程优化 / 自动提示与多步流程优化。
- **HBSP / LiPO / SOCA**：Hierarchical Bayesian Skill Policy / Inter-session Listwise Preference Optimization / State-conditioned Ordinal Credit Assignment，分别是 PsyEvo 的层级贝叶斯技能策略、跨会话列表偏好优化和状态条件序数信用分配。
- **CAMM**：RegulaTutor 的 cognitive、affective、metacognitive、motivational（认知、情感、元认知、动机）框架。
- **SEL / PMT / PCIT / CBT / ACT**：社会情绪学习 / 家长管理训练 / 亲子互动治疗 / 认知行为治疗 / 接纳承诺治疗。
- **SPACE / TAU**：Supportive Parenting for Anxious Childhood Emotions / treatment as usual，分别指家长侧儿童焦虑方案 / 常规治疗。
- **AEC / VAD / ASR**：声学回声消除 / 语音活动检测 / 自动语音识别。
- **MRT / WCLS / CACE / OPE**：微随机试验 / weighted and centered least squares / complier average causal effect / off-policy evaluation（离策略评估）。
- **ICC / MCID**：组内相关系数 / 最小临床重要差异。
- **PWA**：progressive web app，渐进式 Web 应用。
- **RCT / GRADE**：随机对照试验 / 证据确定性分级方法。
- **ABAB / N-of-1**：交替引入—撤回的单案例设计 / 单个参与者随机试验。
- **estimand / propensity**：目标估计量 / 在给定历史下被分配某动作的已知概率。
- **`g`、`d`、`SMD`**：标准化均差家族；**`RR`**：风险比；**`β`**：回归或路径系数；**`I²`**：元分析异质性比例；**`α`**：I 类错误预算。不同研究的这些数值不能因符号相似而直接互换。

### 0.6 证据标记

- **A｜动作级因果**：具体动作或提示本身被随机操纵。
- **B｜干预包因果**：整个方案被随机，单个动作只是组成部分。
- **C｜组件/机制**：组件元回归、中介、调节或机制研究。
- **D｜观察/迁移**：相关研究，或从其他年龄、人群、学校/临床场景迁移。
- **E｜可行性/HCI**：支持产品形态、接受度或即时互动，不支持儿童效果。
- **【论文自报】**：论文作者的实验结果。
- **【项目/厂商自报】**：官方文档、博客、模型卡或项目页。
- **【独立/第三方】**：独立试验、元分析、标准或第三方复现。
- **【我的判断】**：本文基于证据边界做出的设计选择。
- **未核实**：没有找到足够的一手证据，或不同版本互相矛盾。
- 文中的阈值、成本、周数和样本量如非论文结论，明确标为“起步建议”“起步估计”或“推算”。

## 1. 结论摘要

### 1.1 最终选择

**效果优先的四项组合：SkillOpt + SkillOpt-Sleep、Hindsight、FAFO/FAPO、PsyEvo 中经过大幅改造的 HBSP。**

这里按四条研究/产品谱系计数：

1. **SkillOpt / Sleep**：通用技能文档的有界编辑、留出、暂存、审批和回滚；
2. **Hindsight**：每个家庭的长期事实—经历—观察—意见分层记忆；
3. **FAFO / FAPO**：把稀疏反馈扩展为候选评价资产，再优化 prompt 与流程；
4. **PsyEvo / HBSP**：在固定动作库内，以层级贝叶斯方式为每个家庭选择动作；不采用 PsyEvo 的共享权重更新。

| 角色 | 选择 | 直接提供什么 | 为什么不能由其他三项完全替代 |
|---|---|---|---|
| 通用技能版本生命周期 | [SkillOpt](https://arxiv.org/abs/2605.23904) + [SkillOpt-Sleep](https://microsoft.github.io/SkillOpt/docs/sleep/) | 有界编辑、留出验证、拒绝缓冲、meta-skill、stage、审批和回滚 | 其他三项没有完整的部署期技能版本闭环 |
| 长期心理事实层 | [Hindsight](https://aclanthology.org/2026.acl-demo.27/) | world、experience、observation、opinion 四网络；retain、recall、reflect；时间与来源检索 | 在心理/价值场景，区分客观事件和主观信念比“多记忆”更重要 |
| 稀疏反馈工厂 | [FAFO](https://cisco-foundation-ai.github.io/blogs/fafo-recursive-self-improvement/) + [FAPO](https://arxiv.org/abs/2606.19605) | 少量反馈→指南→逐案例 rubric/memory cards→流程候选 | 家庭慢结局稀疏，SkillOpt 否则没有足够可评分案例 |
| 家庭个体化路由 | [PsyEvo](https://arxiv.org/abs/2610.02885) 的 HBSP | 共享弱先验 + 每家庭动作后验，在固定策略库中个体化 | 前三项能记忆和改技能，但没有明确的小样本家庭动作选择模型 |

这四者的更新对象严格分开：

- Hindsight 保存**发生了什么、系统相信什么以及依据什么**；
- HBSP 只更新**某个家庭在某种机会中优先尝试哪个已批准动作**；
- SkillOpt 只修改**系统如何取证、解释、路由和向家长表达**；
- FAFO/FAPO 只产生**候选评价资产和候选流程**。

### 1.2 Hindsight 不是严格 RSI，为什么仍入选

Hindsight 本身是长期记忆基础设施，而不是自改进器。它入选四个“RSI 相关基础”的理由是：

1. 长期价值与心理系统最危险的失真不是少记一条事实，而是把一次猜测固化成“这个孩子胆小、自私、没韧性”；
2. Hindsight 是本轮候选中对事实、经历、观察和意见分层最明确、代码最完整的一项；
3. 记忆层如果不可靠，ACE、HBSP、FAFO 和 SkillOpt 都会学习错误对象；
4. 它的 ACL 2026 Demo 与开源实现让工程复现优于无代码的 RegulaTutor。

**如果你要求四项都必须具有自改进机制**，用 [ACE](https://github.com/ace-agent/ace) 替换 Hindsight：

> SkillOpt-Sleep + ACE + FAFO/FAPO + 改造的 HBSP。

但效果优先时仍建议 Hindsight 作事实底座，同时借用 ACE 的原子 playbook 与 helpful/harmful/uncertain 计数结构。

### 1.3 只能选 1–4 项时

| 最多数量 | 建议 | 得到什么 | 必须自行补什么 |
|---:|---|---|---|
| 1 | SkillOpt + SkillOpt-Sleep | 最重要的有界修改、留出、暂存、审批、回滚 | 事件账本、家庭记忆、rubric、动作路由 |
| 2 | SkillOpt-Sleep + Hindsight | 通用技能生命周期 + 可追溯家庭长期记忆 | 稀疏反馈工厂、个体动作后验 |
| 3 | SkillOpt-Sleep + Hindsight + FAFO/FAPO | 再补足反馈稀疏和评价资产 | 先用简单规则/层级模型路由 |
| 4 | SkillOpt-Sleep + Hindsight + FAFO/FAPO + 改造 HBSP | 技能、记忆、反馈和家庭路由齐全 | 真实因果推广门仍需自建 |

**四项均严格 RSI 的替代**：

> SkillOpt-Sleep + ACE + FAFO/FAPO + 改造 HBSP。

**尽量采用完整开源工程、并降低 HBSP 研究代码依赖的替代**：

> SkillOpt-Sleep + Hindsight + FAFO/FAPO + [Regimes/ActiveGraph](https://github.com/yoheinakajima/regimes)，家庭路由自行实现为强收缩 Beta-Binomial/层级 logistic。

### 1.4 为什么不再把 RegulaTutor 放入主四项

[RegulaTutor](https://arxiv.org/abs/2610.13399) 仍是很好的设计参考：

- 历史证据 → 学习者解释 → 策略；
- 结论保留证据链接；
- PairRoute 区分 harness、模型和混合故障。

但它不再是主基础，原因是：

- 目标主要是学科辅导，CAMM 不能直接代表价值、心理健康和真实同伴关系；
- 论文验证是离线 Gold1000 和模型评委，不是家庭行为或儿童结局；
- 没有公开代码；
- Hindsight 已提供更适合心理事实的证据—信念分离；
- “证据 → 竞争假设 → 动作 → 观察”骨架可以自行实现，不必占用一个主基础名额。

本文仍借用 RegulaTutor 的分阶段结构和 PairRoute，放到第 7 节。

### 1.5 为什么第四项只取 HBSP，不采用完整 PsyEvo

[PsyEvo](https://arxiv.org/abs/2610.02885) 在模拟成人来访者的 PsychEval 上报告 Overall `7.684`，移除单个组件下降 `0.138–0.171`【论文自报】。这不证明儿童心理效果。

只保留 HBSP：

- 固定家长动作库；
- 共享先验强烈向零收缩；
- 每家庭维护小量后验；
- 保留 `NO_ACTION`；
- 只在低反作用、可逆、证据相当的动作间比较；
- 不强制所有动作最低探索；
- 正式效果按随机分配 ITT 分析。

删除：

- LiPO 跨家庭共享回复适配器更新；
- SOCA 用模型比较自动分配心理信用；
- 自动改模型权重；
- 模拟成人来访者评分直接驱动上线。

### 1.6 十项关键改造

1. **家庭价值章程固定在优化器之外**。模型不能根据点击率决定“什么价值最重要”。
2. **抽象品格改写成机会与行为**。例如勇气不是“不害怕”，而是在合适、可退出的挑战中完成一个接近动作。
3. **事实与信念分离**。原话、行为、家长报告、教师报告、状态假设和系统意见分层保存。
4. **只推荐版本化循证动作**。LLM 可解释和个性化措辞，不能自行发明心理或品格干预。
5. **一次一个首选动作**，输出儿童的选择空间和观察窗口，不把服从当成功。
6. **SkillOpt 只优化技能文档**，不得修改家庭价值章程、动作语义、主要结局或正式推广门。
7. **FAFO 合成 rubric 只预筛**，不得把下一轮反馈、家长点赞或 LLM 判断当儿童效果。
8. **HBSP 只路由低反作用动作**，慢变量和不可逆技能用随机多基线，不用在线 bandit 追逐。
9. **主分析为 ITT**，执行、机会、儿童选择、近端行为与慢结局逐层记录。
10. **真实推广独立于四个基础**：冻结候选、anytime-valid e-process/confidence sequence、不可重置生命周期错误预算和可回滚 incumbent。

### 1.7 现实预期

- 品格教育 214 项研究、307,512 人的总体效应 `g=.24`，高质量研究约 `.17`，随访约 `.17`【独立/第三方】；这是完整课程的平均值，不是一次家长话术的效果。
- 通用学校 SEL 424 项、575,361 人的后测效应 `g=.194`，至少 6 个月随访 `g=.167`，且随访异质性 `I²=92.5%`【独立/第三方】。
- 成长型思维 63 项、97,672 人的学业效应仅 `d=.05`，偏倚校正后不显著；最高质量子集 `d=.02`【独立/第三方】。
- 家长主导焦虑 CBT 的直接证据较强：194 名 7–12 岁儿童中，完整指导组主诊断缓解 `50%`，等待组 `25%`，`RR=1.85`【独立/第三方】。
- 截至 2026-10-16，没有一个 RSI 工作证明它能持续改善真实 6–12 岁儿童的价值观、心理健康或社会交往。

因此第一版应是：

> 可追溯的会后家长微动作助手 + 固定动作库 + 多报告者慢结局 + 小范围随机确认。

而不是：

> 自动给孩子打品格分、实时频繁纠正家长、每晚自动进化心理策略。

## 2. 目标重述：从抽象价值到可观察因果链

### 2.1 价值观是规范选择，不是预测目标

科学证据可以回答：

- 某种家长动作是否更可能促进尝试、修复、合作或功能恢复；
- 某种干预包平均改善了哪些结果；
- 哪些代理指标容易产生反效果。

它不能替家庭自动决定：

- 勇敢和谨慎如何权衡；
- 坚持与适时停止如何权衡；
- 个人自主与家庭责任如何权衡；
- 帮助他人与维护自身边界如何权衡。

因此家庭价值章程只由家长修改。RSI 可以学习“怎样更有效地支持章程”，不能改写章程本身。

### 2.2 七个抽象目标的操作化

| 抽象目标 | 不采用的代理 | 可观察机会 | 可观察儿童行为 | 慢结局 |
|---|---|---|---|---|
| 领域自信 | 全局自信、自尊口号 | 年龄适合、通过努力可完成的挑战 | 校准成功预期、尝试、求助、接受反馈、独立完成 | 领域能力感、迁移表现 |
| 策略性坚持 | 坚持分钟数、“永不放弃” | 小挫折、初次失败 | 重返、换策略、分解、求助、合理停止 | 跨事件恢复与自主应对 |
| 勇气 | 恐惧为零、冒险次数 | 合适且可退出的回避/挑战 | 完成一个接近步骤、表达边界、恢复功能 | 参与和功能、回避范围 |
| 责任 | 服从率、家务次数 | 明确承诺、真实家庭角色 | 按约完成、主动报告、遗漏后补救 | 提醒减少、跨场景可靠性 |
| 亲社会/同理 | “善良分”、牺牲次数 | 他人有真实需要或受到影响 | 注意、询问、帮助、安慰、合作、修复 | 受益者反馈、互惠关系 |
| 心理健康 | 负面情绪最少 | 日常压力和功能场景 | 求助、保持活动、减少无效回避、恢复 | 症状、功能和生活质量 |
| 社会交往 | 朋友数量、外向程度、受欢迎 | 邀请、共同任务、误会、冲突 | 发起、回应、轮替、协商、边界和修复 | 互惠友谊、孤独、同伴关系 |

### 2.3 完整因果链

```text
家庭价值章程与当前目标
  → 自然发生的可观察机会
  → 系统是否正确识别机会
  → 随机分配建议或 NO_ACTION
  → 家长是否看到、理解、接受
  → 家长是否执行且保持核心成分
  → 是否为儿童保留真实选择空间
  → 儿童是否出现目标特异行为
  → 近端机制是否改变
  → 数周后的功能、关系和心理结果
```

每个箭头都是不同故障：

- 感知错；
- 机会不合格；
- 状态解释错；
- 动作内容错；
- 时机/表达不适用；
- 家长未执行；
- 家长执行但儿童没有真实选择；
- 近端行为变了，慢结局没变；
- 量表变化只是报告方式变化。

### 2.4 五类状态不能混写

1. **事实**：“孩子说‘我永远学不会’。”
2. **事件编码**：“一次错误后的自我贬低语句。”
3. **状态假设**：“当前可能因连续失败而降低领域成功预期，置信度 0.58。”
4. **家庭经验**：“晚间数学任务中，先降难度再撤提示曾执行 3 次，结果 2 正 1 不确定。”
5. **规范判断**：“本家庭希望支持诚实面对困难，同时允许合理求助和停止。”

只有第 1 类能称原始事实；第 5 类来自家庭章程，不由模型推断。

### 2.5 三级 RSI 证据

| 级别 | 定义 | 本系统例子 |
|---|---|---|
| 任务增益 | 某次建议看起来更好，没有留下持久修改 | 家长更喜欢一条话术 |
| 留存增益 | 持久技能/路由在未参与优化的新事件上改善真实结果 | 新技能版本在未来机会中提高目标行为 ITT |
| 改进器增益 | 产生修改的机制被改进，并在同预算下产出更好的后续候选 | 新 meta-skill 使后续候选的隐藏集与真实通过率提高 |

产品主线要求可验证的留存增益。改进器增益只在离线研究层尝试；代码级自修改不进入生产系统。

## 3. 纯效果约束：十四条不能省略的规则

### C1：不优化人格标签

系统不保存“胆小、勇敢、自私、善良、没韧性、社交差”作为事实。这些词把情境行为、成人价值判断和稳定人格混为一谈，既难验证，也会污染后续建议。

### C2：真实掌握经验优先于灌输自信

纵向观察研究的 cross-lagged 元分析报告，成绩→后续自我效能的路径 `β=.205`，自我效能→成绩为 `.071`，且儿童子组主要稳定的是前一路径【独立/第三方；[Talsma 等](https://doi.org/10.1016/j.lindif.2017.11.015)】。这不是“人为制造一次成功必然提高自我效能”的动作因果证据，只提供 C/D 级设计假设。

所以系统应帮助家长创造可归因的成功、逐步撤提示和校准反馈，而不是重复“你一定行”。

### C3：机械成长型思维和努力表扬不是核心动作

- [成长型思维元分析](https://doi.org/10.1037/bul0000352)：63 项、N=97,672，总体 `d=.05`，偏倚校正后不显著；最高质量六项 `d=.02 [-.06,.10]`【独立/第三方】。
- 实验中，能力/人格表扬组在受挫后的动机和表现弱于过程表扬组；但这些短期实验不证明一句泛化的“你很努力”会带来长期家庭迁移【[Mueller 与 Dweck](https://doi.org/10.1037/0022-3514.75.1.33)、[Kamins 与 Dweck](https://doi.org/10.1037/0012-1649.35.3.835)】。
- 因而本系统要求反馈包含可核查的行为、策略和结果，不把改变思维信念或增加努力措辞本身当作成功。

动作改为：

> “你把题目画成图后，第二步做对了；下一步检查单位。”

而不是：

> “你真聪明”或“你很努力，所以一定能成功”。

### C4：坚持必须包含策略切换和合理停止

单纯延长坚持时间会奖励无效固执。成功指标至少同时记录：

- 是否重新投入；
- 是否换策略、分解或求助；
- 是否在信息表明继续无益时合理停止；
- 之后是否愿意再次尝试。

### C5：勇气不是焦虑立即下降

分级接近中焦虑短时上升不等于失败。主要行为是完成预定接近步骤并恢复功能，而不是“看起来不怕”。

### C6：亲社会不是服从或自我牺牲

帮助行为必须有真实受益者、儿童自愿和可拒绝边界。公开善行积分、连续打卡或强迫感恩可能把亲社会变成表演；部分善意课程出现总体零效应和男孩焦虑上升信号。

### C7：修复比表演式道歉更可测

实验室研究提示，道歉可能增加分享，但实际补救更能改善受影响儿童的感受【A/D；[Making Amends](https://doi.org/10.1111/sode.12168)】。建议结构应是：

> 描述影响 → 询问对方需要 → 给出真实补救选择 → 完成并复盘。

### C8：学校 SEL 不能直接换算成家庭单动作

[Cipriano 等](https://doi.org/10.1111/cdev.13968)的 424 项学校 SEL 元分析支持完整学校方案平均小效应，不证明家长在家问一次开放问题有 `g=.194`。PATHS、Second Step、Positive Action、KiVa 等依赖课程、教师、同伴规范和学校执行。

### C9：社交能力必须在真实同伴中验证

社交知识题、角色扮演或儿童自评改善，不等于同伴接纳、互惠友谊或冲突修复。家庭系统可为真实同伴机会搭脚手架，但不能只用亲子对话给“社交能力”下结论。

### C10：家长实施是中介，主分析仍按随机分配

积极、资源充足的家长更可能执行建议，也更可能报告改善。只比较“执行者”和“未执行者”会产生选择偏差。主要 estimand 必须是 ITT。

### C11：历史后续不是反事实标签

历史中家长做 A 后孩子恢复，不证明 B 更差；系统未推荐某动作时，也观察不到该动作的结果。Future-Feedback、FAFO 合成 rubric、ACE helpful 计数都不能解决这个反事实缺口。

### C12：量表是慢结局，不是在线奖励

量表会受报告者、情境、重测、期望和反应方式影响。不能让模型通过频繁测量、改变家长看法或诱发机会来“提高分数”。

### C13：兄弟姐妹不是独立样本

同一位家长接受建议后可能同时改变对多个孩子的行为。兄弟姐妹共享家庭环境，应视为一个干扰簇，只在预先指定参数上强收缩部分汇聚，同时保留每个儿童的单独轨迹。

### C14：每次正式改进消耗生命周期错误预算

候选反复尝试并在“看起来显著”时保留，最终必然误采纳。正式候选必须使用不可重置 attempt 编号和预分配的 anytime-valid 错误预算。

## 5. 组合比较与最终取舍

### 5.1 九种组合

| 组合 | 基础 | 优点 | 主要缺口 | 判断 |
|---|---|---|---|---|
| A | SkillOpt-Sleep | 最小有界 RSI；门、暂存、审批齐全 | 无长期家庭事实、稀疏反馈扩展和个体路由 | 1 项推荐 |
| B | SkillOpt-Sleep + Hindsight | 技能版本 + 事实/信念分层 | rubric 与路由需自建 | 2 项推荐 |
| C | SkillOpt-Sleep + ACE | 两项均有自改进色彩；全局+家庭经验 | ACE 无发布门，事实/信念结构弱 | 严格 RSI 两项替代 |
| D | SkillOpt-Sleep + Hindsight + FAFO/FAPO | 技能、记忆、稀疏反馈齐全 | 路由先用简单模型 | 3 项推荐 |
| E | SkillOpt-Sleep + Hindsight + FAFO/FAPO + HBSP | 四个更新对象互补 | HBSP 证据仅模拟成人，需彻底限制 | 主选 |
| F | SkillOpt-Sleep + ACE + FAFO/FAPO + HBSP | 四项都有适应/优化机制 | ACE 与 HBSP 都吃弱反馈，需额外事实底座 | 严格 RSI 主替代 |
| G | SkillOpt-Sleep + Hindsight + FAFO/FAPO + RegulaTutor | 证据结构强 | 记忆/解释重叠、无代码、领域错位 | 不选 |
| H | Recuris + Hindsight + Regimes + HBSP | 审计、门和长程任务完整 | 两套发布/记忆重叠，缺稀疏反馈工厂 | 工程研究替代 |
| I | [Darwin Gödel Machine](https://arxiv.org/abs/2505.22954) 等代码级 RSI + 心理应用 | RSI 严格度高 | 没有可靠家庭代码 verifier，归因不可识别 | 不选 |

### 5.2 为什么主选 E

**第一，心理场景先要保证“学的对象正确”。**

Hindsight 的价值不在 benchmark 分数，而在结构上把：

- 原始世界事实；
- 主体经历；
- 系统抽取的观察；
- 可变化的意见

分开。ACE 的 playbook 很适合保存动作经验，但不能单独承担心理真值层。

**第二，反馈慢且稀疏。**

FAFO 能把少量家长/专家分项反馈扩展为离线评价资产；但这些资产只决定“是否值得真实试”，不决定儿童是否受益。

**第三，系统既要改通用技能，也要个体化。**

- SkillOpt 管所有家庭共享的技能；
- HBSP 管一个家庭内部的动作后验；
- 二者不能混成“这个孩子有效，所以所有家庭技能都改”。

**第四，四项都服从外部真实效果门。**

没有任何一项有权凭自己的评分自动上线。

### 5.3 Hindsight 与 ACE 的裁决

| 问题 | Hindsight | ACE |
|---|---|---|
| 是严格 RSI 吗 | 否，属于记忆基础设施 | 部分，具有上下文/playbook 演化 |
| 事实与信念分离 | 强 | 弱，需自建 |
| 原子经验更新 | 可实现，但不是主设计 | 强 |
| 有用/有害计数 | 无，需自建 | 原生 |
| 可靠反馈不足时 | 仍可能形成错误意见 | 已观察到任务退化 |
| 发布门 | 无 | 无 |
| 代码与文档 | 完整、ACL Demo | 完整、ICLR 2026 |
| 本场景主角色 | 真值之上的可检查长期记忆 | playbook 数据结构 |

结论：

> 效果优先：Hindsight 入选，ACE 借结构。  
> 严格 RSI 叙事优先：ACE 入选，但必须另建事件真值层并禁用弱反馈自动 helpful。

### 5.4 HBSP 与简单规则的裁决

HBSP 只排第四，因为：

- 1–3 名儿童的数据不足以早期估计大量动作×状态交互；
- 心理与价值结果滞后，在线 reward 极易错配；
- PsyEvo 的结果是模拟成人咨询，不是儿童家庭；
- 强收缩简单模型在数据少时通常更可审计。

因此阶段 0–2 先用：

```text
资格过滤 → 证据等级 → 家庭禁用/偏好 → 最近剂量/冷却 → 简单规则排序
```

只有积累足够随机决策后，HBSP 才作为 challenger；若没有明显提高真实效果，永久保持规则路由。

### 5.5 对主选的反方质疑

**质疑 1：Hindsight 会自动形成 opinion，会不会把假设固化？**

会，所以不能原样使用。第 7 节将关闭无来源 opinion 的自动晋级，所有儿童相关 opinion 必须显示置信度、反证、有效时间和家长确认状态；事件账本仍是唯一真值。

**质疑 2：FAFO 会不会让模型自己出题、自己评分、自己上线？**

不会。提议器、rubric 构造器、隐藏 evaluator 和真实随机结果分离；合成 rubric 只能淘汰明显差候选。

**质疑 3：HBSP 本质是 bandit，为什么要在儿童心理上探索？**

只比较低反作用、可逆、证据相当的家长动作，并保留 NO_ACTION。分级接近、复杂焦虑方案、欺凌和慢变量不进入在线探索；它们用固定方案和随机多基线。

**质疑 4：为什么不用 RegulaTutor 取代 Hindsight？**

RegulaTutor 给出更好的分析流程，但没有持久、可检查、可重建的记忆实现。流程可借，底层事实层不能省。

**质疑 5：为什么不直接用最强 LLM 读所有历史？**

长上下文不能解决事实与意见混写、反事实缺失、版本漂移、重复查看和真实效果归因。

**质疑 6：四项是不是过度设计？**

四项是目标架构，不是首月同时上线。路线图先做静态动作库、事件账本和 SkillOpt staging；Hindsight、FAFO、HBSP 逐阶段加入，任何一项无增量效果都可停止。

## 6. 家长侧总体架构

### 6.1 在线链路

首版采用“事件后短复盘”，不在亲子互动中频繁打断：

```text
亲子音频 / 家长输入 / 儿童与教师结构化反馈
  ↓
AEC、VAD、重叠检测、diarization、ASR N-best
  ↓
低推断事件与回应关系
  ↓
双时态 append-only 事件账本
  ↓
Hindsight 记忆投影：事实 / 经历 / 观察 / 意见
  ↓
当前机会资格 + 竞争状态假设
  ↓
家庭价值章程与目标过滤
  ↓
冻结证据动作库过滤
  ↓
简单规则或改造 HBSP 排序，始终包含 NO_ACTION
  ↓
SkillOpt 当前技能生成家长建议卡
  ↓
送达、看到、执行、忠实度、儿童选择与结果
  ↓
FAFO 产生离线评价资产，SkillOpt 提议候选
  ↓
离线门 → staged → 真实随机门 → adopt/reject
```

### 6.2 家长建议卡

```yaml
opportunity:
  event_id: "evt_20261016_193408"
  type: "ERROR_OR_FAILURE"
  secondary_trigger: "NEGATIVE_SELF_STATEMENT"
  confidence: 0.88
observations:
  - evidence_id: "turn_481"
    text: "孩子第二次做错后说：我肯定学不会。"
    source: "audio+parent_confirmed"
hypotheses:
  - text: "当前可能把两次失败泛化成稳定能力判断"
    confidence: 0.62
  - text: "也可能主要是疲劳或任务难度过高"
    confidence: 0.38
family_goal:
  id: "goal_domain_confidence_v2"
  text: "支持真实掌握、求助和策略调整，不要求假装自信"
recommendation:
  action_id: "A02_MASTERY_STEP_FADE_v1"
  one_action: "把任务降到一个能独立完成的小步，成功后撤掉一个提示"
  parent_script: "先只做第一步。你可以选画图，或者先说你知道什么。"
  child_choice: ["画图", "口头整理已知条件", "先休息五分钟"]
  observation_window: "现在至24小时内的再次尝试"
why:
  evidence_scope: ["C", "D"]
  playbook_refs: ["pb_031"]
experiment:
  policy_version: "policy_012"
  assignment_id: "mrt_00291"
```

固定顺序是：

> 观察证据 → 竞争解释及置信度 → 家庭目标 → 一个家长动作 → 示例话术 → 儿童选择空间 → 观察窗口。

系统默认只给一个首选动作；只有首选动作不适用时才显示备选。

### 6.3 九类持久数据

| 数据层 | 内容 | 是否可被 RSI 覆盖 | 唯一 owner |
|---|---|---|---|
| 原始证据 | 音频区间、输入、N-best、说话人后验、量表原回答 | 否，只能追加修正 | 事件账本 |
| 派生事件 | 话语行为、机会、回应边、冲突/修复 episode | 否，只能追加新模型版本 | 事件账本 |
| 家庭价值章程 | 家庭选择的目标、优先级、边界和冲突处理原则 | 否，家长手工版本化 | 家长 |
| Hindsight 记忆 | world、experience、observation、opinion 投影 | 可重建，不是真值 | Hindsight |
| 状态假设 | 当前情境解释、置信度、替代解释、有效时间 | 可重算 | 分析器 |
| 证据动作库 | 动作语义、适用条件、证据级别、剂量与结局 | 否，只经证据维护流程改变 | 动作库 |
| 家庭 playbook | 该家庭的执行与结果原子经验 | 可提议；经门后 active | ACE 式条目层 |
| 通用技能 | 如何取证、解释、过滤、表达和复盘 | SkillOpt 可提议 | SkillOpt |
| 实验与结果 | eligibility、assignment、propensity、执行链和结局 | 否；分析版本可追加 | 实验账本 |

### 6.4 家庭价值章程

章程不是一句“培养正确价值观”，而是可审查的规则：

```yaml
version: 3
goals:
  - id: confidence
    desired: "基于真实能力与经验的领域自信"
    not_desired: ["空泛自信", "隐藏困难", "拒绝求助"]
  - id: courage
    desired: "在合适挑战中采取一个可退出的接近行动"
    not_desired: ["鲁莽", "压抑恐惧", "永不放弃"]
  - id: prosocial
    desired: "注意真实需要、自愿帮助、尊重边界、造成影响后修复"
    not_desired: ["服从", "讨好", "强迫分享", "表演式善良"]
conflict_priority:
  - "身体与心理功能"
  - "诚实和尊重"
  - "自主与责任并重"
  - "任务表现"
```

章程进入每次动作过滤和解释，但：

- 不因家长点赞自动修改；
- 不因某动作短期提高服从率而修改；
- 不让 HBSP 学习目标权重；
- 每次人工变更创建新版本，不回写历史实验。

### 6.5 分层自改进

| 层 | 更新对象 | 反馈 | 提议器 | 生效条件 |
|---|---|---|---|---|
| L0 证据修正 | 说话人、转写、事件与机会标签 | 家长修正、抽样标注 | 感知模型/人工 | 追加修正版；状态重算 |
| L1 记忆投影 | Hindsight 四网络、来源链、过期和冲突 | 事件账本、家长确认 | retain/recall；受限 reflect | 不得覆盖账本 |
| L2 家庭适应 | playbook、简单规则/HBSP 后验 | 随机分配、执行链、儿童结果 | ACE 式条目 + 统计模型 | 影响动作排序需真实门 |
| L3 通用技能 | 取证、解释、动作过滤、家长表达 | 固定训练/隐藏集、盲评、真实确认 | SkillOpt-Sleep / FAPO | staged 后真实确认 |
| L4 改进器研究 | meta-skill、rubric 规则、搜索预算 | 后续候选通过率和成本 | FAFO/FAPO + meta-skill | 独立消融、人工采纳 |
| L5 模型/代码 | ASR、分类器、基础 LLM、服务代码 | 本域标注、单元与回归 | 常规工程/训练 | 不属于运行期 RSI |

### 6.6 候选生命周期

```text
日志按家庭和时间冻结
  → discovery 产生修改
  → protected cases 与机制指纹
  → fixed hidden holdout
  → rolling future holdout
  → 家长/专家盲评
  → staged shadow
  → 一个类别一个冻结候选进入真实随机
  → anytime-valid 分析
  → adopt / reject / extend / rollback
```

合法状态：

`draft → offline_passed → staged → live_confirming → adopted`

或从中间态进入 `rejected` / `rolled_back`。进入真实确认后，prompt、动作库、基础模型、主要结局、eligibility 和随机概率全部冻结。

### 6.7 机会资格与 abstain

系统依次检查：

1. 证据是否足够，关键说话人与行为是否可确认；
2. 是否存在家庭章程中的目标；
3. 是否是自然机会，而非系统为了得分制造的事件；
4. 家长此刻是否有可执行动作；
5. 动作库适用条件是否满足；
6. 儿童是否保有真实选择或退出空间；
7. 同类别是否处于冷却期；
8. 若在试验中，是否符合预注册 eligibility。

不满足时输出：

- `NO_ACTION`；
- 仅提供观察摘要；
- 或建议下一步收集信息。

abstain 是正常策略，不是失败。

### 6.8 时间和家庭隔离

每个候选在时间 `T` 冻结：

- **discovery**：可供提议器查看的较早数据；
- **fixed hidden**：提议器不可见的固定家庭/时间留出；
- **rolling future**：`T` 之后的新事件；
- **protected cases**：低频但严重误读、人格标签、服从劫持、强迫善意、过度坚持等反例；
- **external reporter set**：不参与建议的教师/儿童慢结局。

同一事件不能同时用于：

- 写 FAFO rubric；
- 修改 SkillOpt 技能；
- 评价该技能。

### 6.9 运行节奏

| 节奏 | 任务 |
|---|---|
| 每个事件 | 写证据、机会和 assignment；生成或 abstain；记录执行链 |
| 每晚 | 重跑低置信片段；Hindsight 投影；生成但不采纳 playbook/技能候选 |
| 每周 | 家长确认目标、审阅少量 diff、查看执行与负作用 |
| 每个预注册窗口 | 离线门或真实 sequential 分析；按协议 adopt/reject/extend |
| 每 8–12 周（起步建议） | 查看多报告者慢结局、章程是否仍是家庭真实目标；不自动改章程 |

### 6.10 端到端例子

场景：孩子因两次比赛失利说“不参加了，我就是不行”。

1. 感知器记录原话、失败次数、活动类型和时间；
2. 机会层标为 `QUIT_OR_AVOID`，并把失利写作情境，不标“缺乏勇气”；
3. 状态层给出“失败泛化”“疲劳”“不再喜欢该活动”三个竞争解释；
4. 家庭章程要求支持真实选择，不以继续参加作为唯一成功；
5. 动作库给出“挫折复盘”“小步接近”“允许重新选择目标”；
6. playbook 显示这个孩子在当天立即复盘时常拒绝，隔天复盘更可执行；
7. 当前策略随机分配“隔天挫折复盘”或 NO_ACTION；
8. 家长执行后，记录儿童是否愿意讨论、是否自己选择下一步、7 天内是否参加一个相关活动；
9. Hindsight 把原话存为事实，把“对比赛失去兴趣”存为待确认意见；
10. 只有重复随机证据和慢结局支持后，HBSP 才提高相似情境下该动作的排序。

## 7. 四个基础的逐项改造

### 7.1 SkillOpt + SkillOpt-Sleep：通用技能发布系统

#### 拆成十个技能单元

1. `opportunity_extraction`：只识别可核查机会；
2. `evidence_grounding`：每个结论回链到证据；
3. `competing_hypotheses`：列替代解释和不确定性；
4. `value_charter_alignment`：只读章程并识别目标冲突；
5. `action_eligibility`：按动作库适用条件与反例过滤；
6. `parent_delivery`：短、具体、一次一个动作；
7. `child_choice_space`：确保儿童有真实选择/合理拒绝；
8. `social_context`：区分亲子、同伴、欺凌和学校系统；
9. `outcome_definition`：定义执行、近端行为和慢结局；
10. `failure_routing`：感知、状态、内容、交付、执行、评价故障归因。

一次候选只改一个或少量相邻技能，便于归因和回滚。

#### 四套数据

| 数据集 | 用途 | 提议器可见性 |
|---|---|---|
| discovery | 从失败案例提议修改 | 可见 |
| fixed hidden | 防止对已知案例写答案 | 不可见 |
| rolling future | 检查新时间/新机会漂移 | 评估前不可见 |
| protected | 人格标签、强迫暴露、服从劫持、过度帮助等 | 只返回失败类别 |

#### Sleep 本地化

- 每晚只生成 candidate，不在线改技能；
- `gate_no_regression` 强制开启；
- rejected edits 进入缓冲，供 meta-skill 学习；
- staged 候选只做 shadow 输出；
- 本地按钮命名为“批准进入真实确认”，不是“采纳”；
- 真正替换 active policy 只能由第 11 节真实门决定；
- 自动采纳只允许不改变语义的格式、拼写或可证明等价的检索修复。

#### 逐项不退步

- 证据引用；
- 事实—假设分离；
- 章程对齐；
- 动作库适用条件；
- 儿童选择空间；
- 目标家长行为；
- 儿童主要结果；
- 非目标领域；
- 提示负担、成本和 abstain。

Sleep 的 preview 结果是项目方受控自报，不是家庭效果；本文只借版本生命周期。

### 7.2 Hindsight：从 agent 记忆改成心理事实层

#### 四网络映射

| Hindsight 网络 | 家庭系统内容 | 例子 | 约束 |
|---|---|---|---|
| world | 可核查事实 | “10月16日孩子拒绝参加训练” | 必须有 evidence_id |
| experience | 主体经历/报告 | “孩子说比赛时很紧张” | 标明是谁报告、何时报告 |
| observation | 系统聚合观察 | “近4次失利后有3次退出” | 可由账本重算 |
| opinion | 状态或策略假设 | “隔天复盘可能比即时复盘好” | 带置信度、反证和有效期 |

#### 必须修改

1. 每个家庭、每个儿童独立 memory bank；
2. 事件账本是真值，Hindsight 只作投影；
3. `reflect` 不得把人格词写入 world；
4. opinion 默认 `candidate`，不自动变成事实；
5. 每项 opinion 保存 supporting / contradicting evidence；
6. 每项 opinion 保存 `confirmation_status: unreviewed | confirmed | disputed | corrected`；家长修正产生新版本，不删除旧来源；
7. 过期和冲突降低检索权重，但保留历史；
8. 检索必须返回 provenance，不只返回摘要；
9. 规范目标和价值偏好只能存在家庭价值章程，不从日志自动写入 Hindsight；
10. LongMemEval/LoCoMo 分数只用于选择记忆工程，不代表家庭状态正确。

#### 禁止写入的 opinion

- “孩子天生胆小/懒惰/自私”；
- “孩子没有同理心”；
- “同学都不喜欢他”；
- “这是某种诊断”；
- “某动作肯定有效”。

可写为：

> “过去四个有记录的公开发言机会中有三次拒绝；原因未知，可能与任务难度、陌生人或疲劳有关。”

### 7.3 FAFO + FAPO：家庭稀疏反馈工厂

#### 信号分级

| 级别 | 信号 | 可用于 | 不可用于 |
|---|---|---|---|
| F0 | 无反馈事件 | 发现覆盖盲点、生成待标注案例 | 判断动作有效 |
| F1 | 家长看到、接受、编辑、跳过 | 时机、可读性、表达 rubric | 儿童受益 |
| F2 | 家长自报/自动检测执行 | 执行与忠实度 rubric | 单独证明因果效果 |
| F3 | 儿童近端行为 | 机制排序、候选预筛 | 持续心理/品格结论 |
| F4 | 多报告者慢结局 | 正式效果候选 | 脱离随机分配作反事实标签 |
| F5 | 家长/专家分项审阅 | 证据、适用性和动作内容 | 替代真实儿童结果 |

#### 本地流程

1. 聚类 F1–F5，提出“什么算好建议”的候选指南；
2. 家长/专家审核指南；
3. 为 F0–F3 生成候选逐案例 rubric；
4. 对模型分歧保留分布，不平均成伪真值；
5. memory cards 只保存可迁移评价经验，不保存儿童人格；
6. FAPO 在 discovery 优化检索、prompt、工具顺序和成本；
7. hidden/rolling/protected 评估；
8. 产出 staged candidate，交给 SkillOpt 生命周期。

#### 防止自证循环

以下四个角色至少逻辑分离：

- 技能/流程提议器；
- rubric 构造器；
- 隐藏 evaluator；
- 真实随机结果。

不同 LLM 家族只能降低相关错误，不能创造反事实证据。

#### 允许 FAPO 优化

- 证据检索窗口和压缩格式；
- 竞争假设 prompt；
- 动作过滤和排序步骤；
- 建议长度、时机和冷却；
- 模型路由和调用预算；
- abstain 阈值。

不允许优化：

- 家庭价值章程；
- 动作库的活性成分；
- 主要儿童结局；
- 正式 eligibility、随机概率和推广阈值。

### 7.4 PsyEvo/HBSP：从成人咨询策略改成家庭动作后验

#### 原方法与本地化

PsyEvo 的 HBSP 用共享技能先验 `Q(s,a)` 与来访者后验 `b_u(s,a)`，根据会话反馈选择咨询技能。家庭版改为：

```text
状态 s = 低推断机会 + 情境 + 最近剂量 + 已确认状态
动作 a = 冻结动作库中的动作或 NO_ACTION
共享先验 = 跨家庭证据的向零弱先验
家庭后验 = 仅由该家庭可归因的执行与结果更新
```

#### 八项限制

1. 动作必须来自冻结库；
2. `NO_ACTION` 永远保留；
3. 首版无在线 bandit，先积累分层随机数据；
4. 只对低反作用、可逆、证据相当的动作开放 HBSP；
5. 分级接近、复杂焦虑、欺凌、持续技能不做逐事件 bandit；
6. 不为每个动作强制最低探索概率；
7. 家长点赞只更新交付偏好，不更新儿童效果；
8. 后验影响排序前必须通过真实门。

#### 奖励不是一个分数

HBSP 不直接吃：

- 自信/勇气/善良量表；
- 家长满意度；
- LLM 评委；
- 原始坚持时间；
- 当场情绪下降。

它接收分层证据：

```text
eligibility
→ assignment
→ delivery
→ execution
→ parent_behavior
→ child_choice
→ proximal_behavior
→ delayed_outcome
```

正式更新优先使用随机 assignment 和已知 propensity；执行者结果只作机制分析。

#### 强收缩与冷启动

- 家庭数据少时后验紧贴零效应；
- 不把成人 PsyEvo 分数当先验效应；
- 相邻动作只有机制和证据范围相同时才部分汇聚；
- 兄弟姐妹共享家长实施参数，但儿童效果参数分开；
- 先验敏感性必须报告；
- 无足够信息时保持规则路由。

#### 删除 PsyEvo 其余组件

- 不做 LiPO 跨家庭共享 adapter；
- 不做 SOCA 的自动模型信用分配；
- 不根据模拟来访者偏好更新；
- 不在线训练权重；
- 不把咨询技能直接应用到儿童。

### 7.5 借用模块

|---|---|---|---|

## 8. 触发本体、状态与多报告者模型

### 8.1 只从低推断事件起步

```text
L0 原始证据：谁、何时、说了什么/做了什么
L1 话语行为：请求、拒绝、求助、道歉、提议、确认
L2 episode：失败后退出、冲突后修复、进入同伴活动被拒
L3 状态假设：可能担忧评价、技能不足、疲劳、任务不匹配
L4 纵向模式：在多次、多个场景、多个报告者中重复
L5 稳定人格/诊断：系统不自动生成
```

自动建议可以用 L0–L2 触发；L3 只能用于竞争解释和选观察项；L4 必须显示数据覆盖；L5 不属于本系统。

### 8.2 触发本体

#### 挑战、自信与韧性

| trigger | 可观察定义 | 关键上下文 | 禁止直接推断 |
|---|---|---|---|
| `NOVEL_CHALLENGE` | 遇到尚未掌握的新任务 | 难度、选择权、先备技能 | 勇敢/胆小 |
| `ERROR_OR_FAILURE` | 答错、落败、作品未达目标 | 尝试次数、反馈、任务可解性 | 能力低 |
| `NEGATIVE_SELF_STATEMENT` | 出现“我不行”等原话 | 原文、领域、是否玩笑 | 低自尊 |
| `QUIT_OR_AVOID` | 拒绝、退出或拖延可见任务 | 是否危险、过难、疲劳、不感兴趣 | 懒惰、焦虑 |
| `HELP_REQUEST` | 明确或间接求助 | 求助时点、给过多少提示 | 依赖 |
| `STRATEGY_SWITCH` | 改用另一策略、拆步或求反馈 | 谁发起、结果如何 | 成长型思维 |
| `RECOVERY_AFTER_SETBACK` | 失败后再次接近 | 延迟、选择、任务相似度 | 韧性已形成 |
| `SUCCESS_OR_MASTERY` | 独立完成此前不会的步骤 | 提示水平、机会难度 | 全局自信 |

#### 价值、责任与亲社会行为

| trigger | 可观察定义 | 关键上下文 | 禁止直接推断 |
|---|---|---|---|
| `COMMITMENT_MADE` | 对具体行为作出约定 | 是否自愿、时间、能力 | 一定会做到 |
| `COMMITMENT_MISSED` | 可核查约定未完成 | 障碍、提醒、可控程度 | 不负责任 |
| `IMPACT_CAUSED` | 行为对人/物造成具体影响 | 意图与影响分开 | 坏、自私 |
| `TRUTH_CONFLICT` | 两个陈述/证据不一致 | 是否记错、害怕、想象游戏 | 撒谎成性 |
| `HELP_OPPORTUNITY` | 某人有可确认需要，儿童可自愿回应 | 对方是否希望帮助、儿童边界 | 儿童有义务帮助 |
| `HELP_GIVEN_OR_OFFERED` | 主动提供具体帮助 | 对方是否需要/同意 | 善良品质已改变 |
| `HELP_RECEIVED` | 接受他人帮助 | 是否感谢、是否能回馈 | 欠人情 |
| `RESOURCE_CONFLICT` | 分享、轮流或所有权争议 | 物品归属、规则、双方需要 | 不会分享 |
| `FAIRNESS_CLAIM` | 提出公平/不公平主张 | 平等、需要、贡献、规则 | 道德水平 |
| `REPAIR_ATTEMPT` | 道歉、恢复原状、补偿、重做 | 是否回应真实影响 | 一句“对不起”即修复 |
| `BOUNDARY_SET_OR_CROSSED` | 表达或越过身体、物品、时间边界 | 是否清楚、能否退出 | 不合群/不友善 |

#### 情绪和心理功能

| trigger | 可观察定义 | 关键上下文 | 禁止直接推断 |
|---|---|---|---|
| `EMOTION_NAMED` | 当事人明确说出情绪 | 自报原文、强度和时间 | 系统读心 |
| `DISTRESS_SIGNAL` | 哭、提高音量、沉默、离场等 | 基线、场景、持续时间 | 某种特定情绪 |
| `WORRY_STATEMENT` | 明确担忧未来事件 | 内容、概率、可控性 | 焦虑障碍 |
| `REASSURANCE_LOOP` | 同一担忧反复寻求/给予确定答案 | 次数、时间、是否短暂缓解 | 操纵 |
| `ACCOMMODATION_REQUEST` | 要求家人代做、回避或改变安排 | 是否合理支持、是否维持功能受损 | 必须拒绝 |
| `ANGER_ESCALATION` | 可观察升级序列 | 前因、成人行为、恢复时长 | 品行差 |
| `WITHDRAWAL_OR_LOW_ACTIVITY` | 相比自身基线减少活动/互动 | 睡眠、疾病、事件、持续时间 | 抑郁 |
| `FUNCTION_CHANGE` | 上学、睡眠、饮食、活动或关系明显改变 | 跨日、跨场景和报告者 | 单一原因 |

#### 同伴与社会交往

| trigger | 可观察定义 | 关键上下文 | 禁止直接推断 |
|---|---|---|---|
| `SOCIAL_ENTRY_ATTEMPT` | 尝试加入对话或活动 | 时机、方式、团体是否开放 | 社交能力高低 |
| `SOCIAL_GOAL_CONFIRMED` | 儿童明确希望增加或改善某段同伴关系 | 具体目标、同伴、可用机会 | 成人替儿童设定社交目标 |
| `SOCIAL_BID_RESPONSE` | 发起/回应问题、分享、邀请 | 互惠、兴趣和环境 | 必须多说话 |
| `COOPERATION_EPISODE` | 协调角色、规则或共同目标 | 谁提出、双方贡献 | 永久合作性 |
| `PEER_REJECTION` | 邀请被明确拒绝或持续忽视 | 单次/重复、团体规范 | 没人喜欢 |
| `PEER_CONFLICT` | 目标、规则、资源或边界冲突 | 双方叙述、权力与前史 | 双方同责 |
| `FRIENDSHIP_RUPTURE` | 稳定关系出现疏远/背约/伤害 | 关系历史、双方意愿 | 必须和好 |
| `BULLYING_CANDIDATE` | 重复伤害且可能存在权力不对等 | 重复性、权力、群体/学校信息 | 普通冲突 |
| `LONELINESS_REPORT` | 儿童直接报告孤独或缺少陪伴 | 想要的关系数量/质量 | 客观无朋友 |

### 8.3 事件结构

```yaml
event_id: "evt_..."
valid_time: ["2026-10-16T19:34:08", "2026-10-16T19:35:21"]
ingest_time: "2026-10-16T22:00:00"
participants:
  - {id: child_1, role_posterior: 0.96}
evidence:
  - {source: audio, span: [481, 486], asr_nbest: [], confidence: 0.88}
speech_acts: ["NEGATIVE_SELF_STATEMENT", "HELP_REQUEST"]
episode_edges:
  - {from: evt_error_2, relation: "precedes", to: evt_self_statement}
context:
  domain: "math"
  task_difficulty: "unknown"
  choice_available: true
source_status: "parent_confirmed"  # 允许值：auto / parent_confirmed / corrected
extractor_version: "event_model_007"
```

所有自动派生字段都带提取器版本。修正不是覆盖：

```text
event_v1 --superseded_by--> event_v2
```

这样旧建议仍可按当时证据重放。

### 8.4 部分可观测状态

系统维护的是假设分布，不是隐藏的“真实心理分数”：

```yaml
state_snapshot:
  as_of: "2026-10-16T22:00:00"
  opportunity: {type: QUIT_OR_AVOID, eligible: true}
  hypotheses:
    - {id: task_too_hard, p: 0.36, support: [evt_11], contradict: []}
    - {id: evaluation_worry, p: 0.31, support: [report_8], contradict: []}
    - {id: fatigue, p: 0.22, support: [sleep_report_2], contradict: []}
    - {id: no_longer_values_activity, p: 0.11, support: [], contradict: []}
  coverage:
    settings: ["home"]
    reporters: ["parent_1", "child_1"]
    observed_opportunities: 3
  recent_dose: {action_family: "setback_review", count_7d: 1}
  function: {school: "unknown", peers: "unknown", home: "mild_change"}
```

概率用于表达相对不确定性，不声称校准为临床概率。初期可以用显式规则和归一化证据分数；有足够已确认数据后再校准。

### 8.5 多报告者不是投票

| 来源 | 最适合回答 | 局限 |
|---|---|---|
| 儿童自报 | 感受、担忧、孤独、目标、是否愿意 | 受措辞、当下状态和发展水平影响 |
| 家长报告 | 家庭行为、执行、日常变化 | 看不到学校/同伴全貌；期望可能影响评分 |
| 教师报告 | 课堂、同伴群体、跨任务功能 | 看不到家庭和内在体验 |
| 直接观察/音频 | 具体话语与互动序列 | 采样窄；不能直接读出感受或意图 |
| 系统派生 | 计数、时间顺序、跨日聚合 | 继承 ASR、说话人和本体误差 |

合并规则：

1. 保留原量表条目和报告者，不先平均；
2. 具体事件按“谁在场”判断证据，不按身份赋固定可信度；
3. 内在体验优先保留儿童自报，但不让单次自报自动成为稳定状态；
4. 教师和家长差异视为情境信息，不是一个人“报错”；
5. 只有测量不变性和目标构念允许时才报告跨报告者综合分；
6. 同一提示生成的家长报告和家长执行不当作两个独立证据；
7. 建议系统可见的家长报告，不作为无偏的唯一主要结局。

### 8.6 冲突处理

例：家长认为“孩子没有朋友”，儿童说“我有两个朋友而且够了”，教师报告“课间常独处”。

系统不输出“社交退缩”，而输出：

- 事实：教师观察到独处；儿童报告有两个朋友且满意；
- 未知：独处是否自愿、是否在所有课间发生；
- 竞争解释：偏好少量关系、场景无合适伙伴、被排斥、恢复精力；
- 下一步：只问“你希望课间有更多一起玩的时间吗？”；
- 只有儿童希望改变且有真实机会时，才推荐友谊支架。

### 8.7 状态更新和过期

- 事件事实不衰减；
- 情境状态有有效期；
- 每次新证据做支持/反驳更新；
- `evaluation_worry` 一类假设若 14–28 天无支持可回到 unknown（起步建议，按本家庭漂移数据校准）；
- 慢变量在预定测量点更新，不被一次争吵覆盖；
- 动作后短暂改善不能改写基线；
- `BULLYING_CANDIDATE`、持续功能变化等进入独立评估链，不与普通微动作混合。

### 8.8 感知失败路由

| 失败 | 检测 | 行动 |
|---|---|---|
| 说话人不确定 | posterior 低/交叠语音 | 不做人级归因；请求家长确认 |
| 转写关键词不确定 | N-best 改变事件标签 | 显示原音频区间；abstain |
| 情绪被声学模型猜测 | 无自报/行为证据 | 只写“音量提高”等可观察项 |
| episode 边错误 | 时序中断/家长修正 | 重建该窗口，不污染长期模式 |
| 同伴信息单边 | 只有家长转述 | 保留来源；不推断对方意图 |
| 机会不足 | 无真实选择/事件已结束 | 只复盘，不触发当场动作 |

## 9. 版本化证据动作库

### 9.1 动作卡规范

每张卡必须有：

```yaml
action_id: "Axx_name_vN"
target_parent_behavior: "家长具体做什么"
eligible_triggers: []
exclude_if: []
mechanism: ""
active_ingredients: []
dose: ""
parent_script: ""
child_choice: []
fidelity: []
proximal_outcome: ""
slow_outcome: ""
adverse_or_counterexample: ""
evidence_levels: ["C", "D"]  # 每项必须来自 A/B/C/D/E 枚举
evidence_scope: ""
references: []
```

卡片语义冻结。SkillOpt/FAPO 只能：

- 选择卡；
- 用当前证据解释为什么；
- 在不改变活性成分的前提下压缩措辞；
- 填入家庭已确认上下文。

任何新增活性成分都创建新卡和新版本。

以下两张 canonical 表与各卡正文共同构成完整字段：表中集中给出稳定 ID、目标行为、trigger、机制、活性成分、排除项、剂量、忠实度和慢结局；正文给出话术、儿童选择、近端结局、反例、证据级别和来源。实现时将它们编译成一份 YAML，而不是让 LLM 补缺失字段。A12 是迁移别名，导出为独立升级路由 `R01`，不当作儿童干预动作。

| 卡 | canonical `action_id` | 目标家长行为 | 最低 fidelity | 慢结局 |
|---|---|---|---|---|
| A01 | `A01_INFO_FEEDBACK_v1` | 描述行为、策略和结果 | 具体、真实、无人格标签 | 领域校准和策略迁移 |
| A02 | `A02_MASTERY_STEP_FADE_v1` | 提供最小必要提示并渐隐 | 可独立小步、提示有记录、随后撤除 | 相似任务独立起步 |
| A03 | `A03_AUTONOMY_CHOICE_v1` | 给真实有限选择和理由 | 至少两个可行选项，拒绝后果清楚 | 自主参与和较低控制感 |
| A04 | `A04_SETBACK_REVIEW_v1` | 事实复盘并定一个可控下一步 | 等情绪可讨论、允许停止/换目标 | 重视目标中的策略性恢复 |
| A05 | `A05_GRADED_APPROACH_v1` | 协作完成一个分级接近步骤 | 无真实危险；儿童选步；支持渐隐 | 目标情境功能恢复 |
| A06 | `A06_COPING_MODEL_v1` | 示范紧张时的策略性行动 | 承认不确定、一步示范、可退出 | 感受与行动分离 |
| A07 | `A07_VALIDATE_CHOOSE_v1` | 试探命名、允许纠正并问需要 | 不读心、不立即解题 | 表达、求助和恢复选择 |
| A08 | `A08_COREGULATE_REVIEW_v1` | 降低刺激，恢复后再复盘 | 成人降速、提供空间、事后处理影响 | 恢复功能而非压抑表达 |
| A09 | `A09_TEST_WORRY_PREDICTION_v1` | 记录预测并比较实际 | 预测可观察、事件后复查 | 担忧校准和功能恢复 |
| A10 | `A10_FADE_ACCOMMODATION_v1` | 逐步减少一个维持回避的迁就 | 预告、一次一个、替代支持存在 | 自主应对和目标功能 |
| A11 | `A11_MASTERY_PLEASURE_ACTIVITY_v1` | 协作安排掌握/愉悦小活动 | 儿童自选、剂量小、事后记录 | 活动与功能趋势 |
| A13 | `A13_IMPACT_REPAIR_v1` | 让修复回应实际影响 | 意图影响分开、受影响者有边界、修复完成 | 可靠修复和关系功能 |
| A14 | `A14_COMMITMENT_PLAN_v1` | 把承诺具体化并预演障碍 | 何时何地行为清楚、漏做有相关补救 | 自主可靠性 |
| A15 | `A15_VOLUNTARY_KINDNESS_v1` | 先确认需要，再提供自愿帮助 | 受益者需要、儿童自愿、可拒绝 | 匹配需要的亲社会行为 |
| A16 | `A16_PERSPECTIVE_VERIFY_v1` | 生成多个解释并直接求证 | 事实/猜测分开，不替他人读心 | 较少敌意归因和更好修复 |

除正文另有规定外，卡片默认：

- `dose`：每个 eligible episode 最多一次，同一事件不重复追问；具体冷却作为版本字段在试验前冻结；
- `child_choice`：儿童可纠正成人解释、拒绝非必要练习或在真实选项中选择；
- `exclude_if`：关键证据不确定、没有儿童/家庭目标、没有真实选择、处于冷却期，或命中正文反例；

- `references`：正文“链接”中的来源；

### 9.2 自信、勇气与面对困难

#### A01｜信息性反馈，不作人格表扬

- **触发**：成功、错误后调整、求助、策略切换。
- **动作**：描述具体行为、策略和结果；指出下一步可控信息。
- **话术**：“你刚才发现画图不够，就改用表格，第三步因此做对了。”
- **剂量**：在真实目标行为后一句；不对每个小动作评价。
- **近端结局**：儿童能说出哪种策略有效，下一机会是否自己选择策略。
- **反例**：“你真聪明”“你是个勇敢的孩子”“只要努力就行”；任务不可解时继续夸努力。
- **证据**：**C/D**。反馈总体有效但高度依赖内容；过程/策略信息比人格标签更符合机制。实验显示 person praise 可能使失败后的自我评价更脆弱；这不是家庭长期效果的直接证明。
- **链接**：[反馈元分析](https://doi.org/10.3389/fpsyg.2019.03087)、[person/process praise 实验](https://doi.org/10.1037/0012-1649.35.3.835)、[自然情境过程表扬与后续动机框架](https://doi.org/10.1111/cdev.12064)。

#### A02｜掌握阶梯与提示渐隐

- **触发**：任务略高于当前独立能力、反复错误、全局化“我不行”。
- **动作**：找出最小可独立完成步骤；给刚够用的提示；成功后撤掉一层提示。
- **话术**：“先选一个你能自己做的第一步。需要时我只给一个提示。”
- **儿童选择**：选起步点、工具、先练还是休息。
- **剂量**：一个 5–15 分钟小步；同类任务每周 2–4 次起步估计。
- **结局**：在相近难度的新机会中，提示水平下降、独立起步增加；不是完成量最大。
- **反例**：把任务切到毫无挑战、家长代做、成功后立刻大幅加难度。
- **证据**：**C/D**。掌握经验、自我效能与脚手架机制有理论和广泛教学证据，但“家庭单卡提高全局自信”未核实。
- **链接**：[Bandura 自我效能理论](https://doi.org/10.1037/0033-295X.84.2.191)、[师生 scaffolding 综述](https://doi.org/10.1007/s10648-010-9127-6)。

#### A03｜自主支持的有限选择与理由

- **触发**：合理要求、挑战、家庭责任、儿童抵触但有多种实现路径。
- **动作**：承认儿童视角，说明非控制性理由，在真实边界内给 2–3 个选择。
- **话术**：“我知道你现在不想练。我们要确保明天能参加；你选先练十分钟，还是吃饭后练？”
- **结局**：自愿起步、较少控制性语言、儿童能表达理由；不以即时顺从为唯一结果。
- **反例**：假选择、无限协商、用选择掩盖威胁、无法选择的安全边界也伪装成选择。
- **证据**：**C/D**。家长自主支持与学业和心理社会功能的元分析关联/调节证据；单次家庭话术的因果量未知。
- **链接**：[家长自主支持元分析](https://doi.org/10.1007/s10648-015-9329-z)、[自我决定理论教养综述](https://selfdeterminationtheory.org/wp-content/uploads/2014/04/2008_JoussemetLandryKoestner_CanPsych.pdf)。

#### A04｜挫折复盘：事实—策略—可控下一步

- **触发**：失败、退出、消极自我陈述，且情绪已可讨论。
- **动作**：先复述事实，再问目标是否仍重要；区分可控和不可控；只定一个下一步。
- **话术**：“这次两轮都输了。你还想学这个吗？如果想，下次只试一个变化；如果不想，我们也可以说清原因。”
- **观察窗口**：24 小时至下一相似机会。
- **结局**：解释更具体、策略切换、选择性再尝试；不以永不放弃为目标。
- **反例**：当场讲大道理、把所有结果归因努力、忽略任务不匹配或合理退出。
- **证据**：**B/C/D**。问题解决、归因和 CBT 包支持该链条；未发现这张完整家长卡的独立 RCT。
- **链接**：[儿童社会问题解决元分析](https://doi.org/10.1016/0193-3973(87)90029-3)、[成长型思维元分析及其很小效应](https://doi.org/10.1037/bul0000352)。

#### A05｜合适挑战中的分级接近

- **触发**：儿童想做但因可预期恐惧/担忧而回避；不存在真实危险、欺凌或能力鸿沟。
- **动作**：与儿童列 4–8 个从易到难的接近步骤；儿童选一个可承受步骤；重复到可管理再升级。
- **话术**：“不是一下做到最难。你选先在门口看五分钟，还是和我一起进去两分钟。”
- **活性成分**：接近而非逃避、可重复、少量支持渐隐、记录预期与实际。
- **结局**：在目标情境的自主接近与功能恢复，不要求恐惧立刻消失。
- **反例**：强迫、突然洪水式暴露、对真实欺凌“勇敢面对”、把不感兴趣当恐惧。
- **证据**：**B，组件 C**。暴露是儿童焦虑 CBT 的核心组件；家长主导低强度 CBT 在 7–12 岁随机试验中有效，但本卡不能脱离完整评估被解读为同等效应。
- **链接**：[家长主导 CBT RCT](https://doi.org/10.1192/bjp.bp.113.126698)、[儿童焦虑 CBT Cochrane 综述](https://doi.org/10.1002/14651858.CD013162.pub2)。

#### A06｜家长示范“紧张但行动”与应对自述

- **触发**：新挑战、儿童把情绪理解为“不能做”。
- **动作**：家长简短说出自己的不确定、所选策略和可退出边界，然后示范第一步。
- **话术**：“我也不确定会不会成功。我先问清规则，再试一次。”
- **结局**：儿童能把感受与行动分开，并选择自己的步骤。
- **反例**：表演无所畏惧、长篇讲家长往事、示范危险行为。
- **证据**：**C/D**，主要来自动机、社会学习和 CBT 机制；独立家庭微动作效果未核实。
- **链接**：[社会学习理论概览](https://www.uky.edu/~eushe2/Bandura/Bandura1977PR.pdf)、[教养与儿童焦虑元分析](https://doi.org/10.1016/j.cpr.2006.09.002)。

### 9.3 心理健康与情绪调节

#### A07｜情绪验证后再选择调节或解决问题

- **触发**：儿童直接说出感受，或出现可见 distress signal。
- **动作**：描述事实；试探性命名并允许纠正；确认感受可理解；问“现在要陪伴、降强度，还是一起想办法？”。
- **话术**：“比赛取消后你一直没说话。我猜你很失望，也可能我猜错。你想我先陪你，还是一起想接下来怎么办？”
- **结局**：儿童纠正/表达、恢复到可选择状态、之后能进入问题解决。
- **反例**：“没什么好难过”“我完全知道你的感受”、把验证变成同意所有行为。
- **证据**：**B/C**。情绪社会化/家长情绪辅导项目有包级证据；该四句流程的独立效应未核实。
- **链接**：[Tuning in to Kids 学龄前儿童 RCT](https://doi.org/10.1002/jcop.20345)、[情绪社会化与儿童品行问题元分析](https://doi.org/10.1016/j.cpr.2017.04.001)。

#### A08｜共同调节：降强度—恢复选择—事后复盘

- **触发**：升级中的哭喊、愤怒、恐慌或僵住，儿童暂时无法处理信息。
- **动作**：成人先放慢节奏和减少语言；提供已知有效的低刺激选择；恢复后再处理影响。
- **话术**：“我先不讲道理。你选我坐在这里，还是给你五分钟空间。等身体慢下来，我们再决定。”
- **结局**：恢复时间、成人控制性语言、事后能否进入修复；不要求当场停止所有情绪表达。
- **反例**：把任何负面情绪隔离、在升级中追问原因、用屏幕/食物永久回避问题。
- **证据**：**B/C/D**，主要来自情绪辅导与家长训练包，单项剂量和效果未核实。
- **链接**：[亲子关系中的儿童情绪调节综述](https://doi.org/10.1016/j.copsyc.2015.01.006)、[WHO Parenting for Lifelong Health](https://www.who.int/teams/social-determinants-of-health/parenting-for-lifelong-health)。

#### A09｜担忧外化与可检验预测

- **触发**：明确担忧语句，且儿童愿意讨论。
- **动作**：写下担忧预测、可观察结果和应对步骤；事件后比较预测与实际。
- **话术**：“担忧说‘一个字答错大家都会笑一整天’。我们记录实际有几个人、多久、你能怎么应对。”
- **结局**：预测更具体、能收集反证、目标功能恢复。
- **反例**：争辩“不会发生”、要求儿童保证不担忧、家长替儿童反复查证。
- **证据**：**B/C**，认知与行为实验是 CBT 包组件；家庭单卡独立效应未知。
- **链接**：[儿童焦虑 CBT Cochrane 综述](https://doi.org/10.1002/14651858.CD013162.pub2)、[NICE 儿童焦虑质量标准 QS53](https://www.nice.org.uk/guidance/qs53)。

#### A10｜减少维持回避的家庭迁就

- **触发**：明确、重复的迁就—短暂缓解—更强回避循环；已确定替代支持步骤。
- **动作**：家长与儿童预告逐步减少一个迁就，同时增加验证和分级接近支持。
- **话术**：“以前我每天替你问三次是否会点名。今天我只帮你查一次规则，然后我们练如果被点名怎么开始。”
- **结局**：迁就减少、儿童功能与自主应对增加；不是家庭冲突增加。
- **反例**：突然撤掉全部支持、把合理适配当迁就、用于欺凌或真实危险。
- **证据**：**B/C/D**。SPACE 是只面向家长的儿童焦虑干预，在非劣效 RCT 中相对 CBT 有支持；随机的是完整治疗包，不是“逐步减少一个迁就”这张卡，本卡只是组件级机制迁移。
- **链接**：[SPACE 非劣效 RCT](https://doi.org/10.1016/j.jaac.2019.02.014)、[SPACE 官方](https://www.spacetreatment.net/)。

#### A11｜活动的掌握—愉悦双轨计划

- **触发**：持续活动减少或低落报告，但先确认时间跨度与功能变化。
- **动作**：儿童从“有一点愉悦”和“有一点掌握”各选一个小活动，事前/事后简短评分。
- **话术**：“这周你想选一个可能有点开心的活动，再选一个做完会有点完成感的活动吗？”
- **结局**：活动接触与功能趋势；不以当场开心为要求。
- **反例**：一次不想玩就触发、排满日程、把严重持续变化只当动力问题。
- **证据**：**B/D**。行为激活对青少年抑郁有初步支持，6–12 岁家长微动作直接证据较弱。
- **链接**：[儿童青少年行为激活更新元分析](https://doi.org/10.1007/s00787-024-02429-3)、[NICE 儿童青少年抑郁指南](https://www.nice.org.uk/guidance/ng134)。

#### R01｜超出微动作范围时转完整路径（独立路由，不是干预卡）

- **触发**：持续、跨场景或明显功能改变；重复高强度 distress；家长动作多轮无改善；量表达到预设关注阈值。
- **动作**：输出事件时间线、功能变化、已试动作和多报告者差异，供儿科/心理专业人员评估；系统继续做记录和执行支持，不自行诊断。
- **结局**：是否完成评估、是否进入合适服务和功能结局。
- **反例**：继续让 RSI 搜索更“有效的话术”，或把一次量表高分当诊断。
- **证据**：这是**范围控制**而非干预效果主张。
- **迁移**：历史 `A12` 仅映射为 `legacy_aliases: ["A12"]`；新日志、UI 和分析统一写 `R01_FULL_PATH_ESCALATION_v1`。
- **链接**：[AACAP 家庭资源](https://www.aacap.org/AACAP/Families_and_Youth/Family_Resources/Home.aspx)、[NICE 指南入口](https://www.nice.org.uk/guidance)。

### 9.4 责任、亲社会价值与修复

#### A13｜影响修复，不逼一句道歉

- **触发**：`IMPACT_CAUSED`，且事实基本明确。
- **动作**：分开意图与影响；询问受影响者需要；让儿童在恢复原状、重做、补偿、道歉等真实修复中选择。
- **话术**：“你可能不是想弄坏，但玩具现在不能用了。我们先问对方需要什么，再选修、赔或用行动道歉。”
- **结局**：实际影响是否减少、承诺是否完成、对方是否接受；不以说出标准道歉为唯一结果。
- **反例**：公开羞辱、强迫拥抱/原谅、把修复变成无限惩罚。
- **证据**：**B/D**。恢复性实践和家长训练提供包级/迁移证据；家庭单卡长期品格效果未核实。
- **链接**：[儿童实际补救实验](https://doi.org/10.1111/sode.12168)、[学校恢复性实践系统综述](https://doi.org/10.3390/ijerph19010096)、[UNODC restorative justice handbook](https://www.unodc.org/documents/justice-and-prison-reform/20-01146_Handbook_on_Restorative_Justice_Programmes.pdf)。

#### A14｜具体承诺、障碍预演与自然后果

- **触发**：家庭责任、遗漏承诺、需要建立可靠性。
- **动作**：把承诺写成何时/何地/可观察行为；预演一个障碍和恢复步骤；漏做后优先补做相关影响。
- **话术**：“‘负责’太大。你定成‘晚饭后把碗放进洗碗机’。如果忘了，看到提示后怎么补？”
- **结局**：约定机会中的完成率和自主提醒；不以家长催促后的最终完成冒充独立完成。
- **反例**：不相关惩罚、把一次遗漏人格化、承诺超过能力。
- **证据**：**C/D**。implementation intention 有广泛行为证据；儿童家庭责任的直接动作级证据有限。
- **链接**：[implementation intentions 元分析](https://doi.org/10.1016/S0065-2601(06)38002-1)、[惯例与儿童发展系统综述](https://doi.org/10.1111/jftr.12549)。

#### A15｜自主的善意行动与受益者反馈

- **触发**：真实帮助机会，或儿童愿意选择一个亲社会行动。
- **动作**：先问对方是否需要；儿童从几个小行动中自选；事后关注对方实际反应和儿童感受。
- **话术**：“奶奶现在需要哪种帮助？你愿意选拿东西、陪她走一段，还是今天不做？”
- **结局**：行动是否匹配需要、是否自愿、对方反馈、跨机会重复；不以“做了几件好事”单独计分。
- **反例**：强迫分享、奖励表演性善良、忽略自己的边界、系统虚构受益者感受。
- **证据**：**B/D**。在 9–11 岁课堂随机分配善意活动提高同伴接受和幸福感，但不能外推为该家长卡的效应。
- **链接**：[Kindness Counts 试验](https://doi.org/10.1371/journal.pone.0051380)、[促进帮助行为的系统综述](https://doi.org/10.1111/jasp.12704)。

#### A16｜观点采择用提问，不替他人读心

- **触发**：冲突、资源分配、造成影响或帮助机会。
- **动作**：分别问“我们知道什么”“对方可能有哪些解释”“怎样直接确认”。
- **话术**：“他拿走球是事实。可能是没听见，也可能是不想轮流。你想怎么问？”
- **结局**：生成多个解释、寻求信息、减少未经证实的敌意归因。
- **反例**：“你要站在别人角度”后直接告诉儿童对方怎么想；要求受伤方理解欺凌者。
- **证据**：**B/C/D**，来自 SEL、社会问题解决和归因训练组件；单独家庭卡证据有限。
- **链接**：[SEL follow-up 元分析](https://doi.org/10.1111/cdev.13968)、[社会信息加工模型综述](https://doi.org/10.1037/0033-2909.115.1.74)。

### 9.5 友谊与社会交往

#### A17｜以儿童目标为起点的友谊脚手架

- **触发**：儿童想增加或改善友谊，而不是仅仅因为成人觉得其朋友少。
- **动作**：选一个共享兴趣和一个可安排的同伴；把活动做得短、结构清楚、可结束；事后只复盘一项。
- **话术**：“你想和谁多玩一点？我们可以约 30 分钟拼模型，你选邀请谁。”
- **结局**：被接受的邀请、重复自愿互动、儿童关系满意度；不是朋友数量最大化。
- **反例**：未经儿童同意安排、强迫与不合适同伴继续、把独处偏好病理化。
- **证据**：**B/D**。家长辅助友谊干预在特定临床/发展群体中有包级证据；对普通家庭单卡的普遍效果未核实。
- **链接**：[Parental Friendship Coaching RCT](https://doi.org/10.1037/ccp0000607)、[ADHD 儿童独立社交技能系统综述](https://doi.org/10.1007/s10567-019-00291-3)。

#### A18｜进入、互惠与退出的一次微排练

- **触发**：有具体即将发生的社交机会，儿童希望练习。
- **动作**：只排练一个步骤：观察共同活动→作相关评论/问题→等待回应；同时练习礼貌退出。
- **话术**：“先看他们在玩什么，再问‘我可以下一轮加入吗？’。如果说不，你可以说‘好’然后找另一个选择。”
- **剂量**：一次 2–5 分钟角色扮演；真实事件后不反复审讯。
- **结局**：实际发起、合情境回应、能承受拒绝并转向；不要求眼神接触或模仿主流社交风格。
- **反例**：背整段台词、强迫 masking、把对方拒绝全归因儿童技能。
- **证据**：**B/D**，社会技能训练/友谊方案包级证据，迁移和泛化不稳定。
- **链接**：[非临床儿童青少年社交技能训练元分析](https://doi.org/10.1007/s10567-019-00308-x)、[SSIS Classwide Intervention Program 资料入口](https://www.pearsonassessments.com/store/usassessments/en/Store/Professional-Assessments/Behavior/Interventions/Social-Skills-Improvement-System-Classwide-Intervention-Program/p/100000337.html)。

#### A19｜同伴冲突：目标—边界—方案—修复

- **触发**：权力大致对等、双方都可表达的普通冲突。
- **动作**：先说各自目标与边界；各提方案；选一个可试方案；造成影响时另做修复。
- **话术**：“你想继续当队长，他想轮换。先各说一个不能接受的点，再想两个能试十分钟的方案。”
- **结局**：双方被听见、方案执行、冲突后关系/功能；不以儿童单方面让步为成功。
- **反例**：把欺凌当双方冲突、要求受伤者共同承担、成人预先决定“公平答案”。
- **证据**：**B/C/D**，来自 SEL 与社会问题解决包；单独家长主持流程的效果量未核实。
- **链接**：[SEL 424 项元分析](https://doi.org/10.1111/cdev.13968)、[7–14 岁 ODD 的 Collaborative & Proactive Solutions 完整方案 RCT](https://doi.org/10.1080/15374416.2015.1004681)。

#### A20｜疑似欺凌：记录模式并改变系统条件

- **触发**：重复伤害且可能存在权力不对等，或儿童无法靠普通协商退出。
- **动作**：按日期记录行为、地点、参与者、成人回应和影响；确认儿童目标；与教师/学校建立书面计划和复查点。
- **话术（对家长）**：“不要让孩子单独再练‘更勇敢地反击’。先确认重复性和权力差异，再要求学校改变高风险时段的监督与同伴条件。”
- **结局**：事件频率、可进入的安全活动、学校计划执行、儿童功能和归属感。
- **反例**：强迫和解、只训练受欺凌者社交技能、把反击次数当勇气。
- **证据**：**B/D**。最强证据来自全校反欺凌方案，家庭记录是协作支架，不是经独立证明的治疗。
- **链接**：[反欺凌方案更新元分析](https://doi.org/10.1002/cl2.1143)、[StopBullying.gov 家长资源](https://www.stopbullying.gov/resources/what-you-can-do)。

### 9.6 动作组合与剂量规则

1. 同一事件默认一个首选动作；
2. A07 验证可以是 A04/A09/A13/A19 前置，不作为第二个完整任务；
3. A05 和 A10 只能在已确认的担忧—回避链中组合；
4. A15 不与奖品按次数兑换组合；
5. A17/A18 无法替代学校同伴机会；
6. A20 不进入 HBSP；
7. 7 天内相同动作超过预设剂量，优先 `NO_ACTION` 或换到结构层；
8. 儿童明确拒绝非必要练习时记录选择，不把拒绝作为“需要更强干预”的奖励信号。

### 9.7 动作库证据边界

- 元分析的课程/治疗包效应不能分配给某一句家长话术；
- 学校 SEL、品格或反欺凌证据不能证明家庭助手本身有效；
- 成人、自闭症、ADHD 或临床焦虑样本只在机制相符处迁移；
- 观察相关不能变成动作因果先验；
- LLM/agent benchmark 不能改变动作证据级别；
- 动作卡的主要作用是约束搜索空间；最终是否适合本家庭由真实随机和慢结局判断。

## 10. 指标体系：测行为链，不造“好孩子总分”

### 10.1 四级结果

| 层级 | 问题 | 示例 | 用途 |
|---|---|---|---|
| P 过程 | 系统和家长做了什么 | 建议送达、看到、编辑、执行、忠实度、时延 | 定位故障 |
| Q 近端机制 | 当次预期机制是否出现 | 具体反馈、儿童选择、策略切换、接近一步、完成修复 | MRT 主要结果候选 |
| R 重复机会行为 | 多个真实机会是否迁移 | 独立起步比例、求助、冲突后修复、被接受的邀请 | 家庭级效果 |
| S 慢结局 | 功能、症状和关系是否持续改善 | 焦虑/功能、同伴关系、领域自我概念、多报告者变化 | 最终目标 |

推广不能从 P 直接跳到“儿童受益”。理想链为：

```text
assignment → delivery → parent execution/fidelity
→ child choice → proximal mechanism
→ repeated opportunity behavior → slow child outcome
```

### 10.2 构念、正指标与反指标

| 目标 | 正指标 | 必须同时看的反指标 |
|---|---|---|
| 领域自信 | 难度校准、独立起步、适当求助、成功归因具体 | 过度自信、隐藏错误、拒绝帮助 |
| 勇气 | 对儿童重视且合适挑战的自主接近 | 危险尝试、被强迫、恐惧隐藏 |
| 韧性 | 恢复时间、策略切换、重返重视目标 | 无效坚持、疲劳、无法退出 |
| 责任 | 具体承诺完成、漏做后补救 | 被催促后的服从、过度内疚 |
| 善意 | 自愿且匹配真实需要的帮助 | 讨好、边界受损、强迫分享 |
| 情绪调节 | 识别、选择策略、恢复功能 | 压抑表达、只追求安静 |
| 心理健康 | 症状和功能、多场景、多报告者趋势 | 仅家长觉得“好管” |
| 社会交往 | 儿童想要的关系质量、互惠、修复、归属 | 话多、眼神多、朋友数量最大 |

### 10.3 机会分母

每个行为率必须有分母：

```text
自主接近率 =
  自主选择至少一个合适接近步骤的机会数
  / 有选择空间且挑战合适的 eligible 机会数
```

系统不能通过：

- 只挑容易成功的机会；
- 把不想参与排除；
- 制造更多冲突；
- 将未知结果删掉；
- 把家长代做计作儿童成功；

来提高指标。

机会本体、eligibility 和排除原因在试验前冻结，并抽样人工盲审。

### 10.4 建议的多报告者量表

量表只在其年龄、语言版本和验证范围内使用，并按对应正式手册计分；许可证不参与效果排序，取得精确版本和手册是测量可复现性要求。本文不复制条目。

| 构念 | 工具 | 典型报告者/年龄 | 用途与限制 |
|---|---|---|---|
| 广泛心理与行为功能 | [SDQ](https://www.sdqinfo.org/) | 家长、教师、儿童版本；版本年龄不同 | 短、可多报告者；不单独诊断 |
| 焦虑/抑郁 | [RCADS](https://www.childfirst.ucla.edu/resources/) | 通常 8–18 岁儿童/家长版本 | 关注症状；6–7 岁不硬套 |
| 儿童焦虑 | [SCARED 临床工具页](https://pediatricbipolar.pitt.edu/resources/clinical-tools) | 通常 8–18 岁儿童/家长 | 可分焦虑域；不是事件级结果 |
| 症状与功能 | [PROMIS Pediatric](https://www.healthmeasures.net/explore-measurement-systems/promis) | 儿童自报和家长代理的年龄范围依域而异 | 可选焦虑、抑郁、同伴关系、生活满意度 |
| 社交技能/问题行为 | [SSIS](https://www.pearsonassessments.com/store/usassessments/en/Store/Professional-Assessments/Behavior/Social-Skills-Improvement-System-Rating-Scales/p/100000322.html) | 家长、教师、学生；约 3–18 岁 | 细分技能；需对应手册；评分者效应 |
| 领域自我概念 | [Harter Self-Perception Profiles](https://portfolio.du.edu/SusanHarter/page/44210) | 幼儿/儿童/青少年不同版本 | 测领域而非“总自信”；不要周测 |
| 情绪调节 | [Emotion Regulation Checklist / Q-scale 来源](https://doi.org/10.1037/0012-1649.33.6.906) | 常用家长/教师报告，儿童期 | 使用前核对具体版本；成人观察与儿童体验不同 |
| 韧性资源 | [CYRM-R / PMK-CYRM-R](https://cyrm.resilienceresearch.org/) | 版本与年龄不同 | 测个人、关系、环境资源，不当作坚持人格 |
| 社会情绪能力 | [DESSA](https://www.apertureed.com/dessa-system-2/) | K–12 成人评分版本 | 可做学校/家庭能力画像；需对应手册 |

选择原则：

1. 每个试验只指定一个主要构念和一个主要结局；
2. 8–12 周测一次慢量表是低负担起步建议，具体按手册和目标变化速度；
3. 教师每学期或预定窗口填一次，避免看到 assignment；
4. 儿童自报由儿童本人选择答案，家长不代答；
5. 不把不同量表 z 分数加成一个“心理成长总分”；
6. 没有已验证的最小重要差异时，报告原分、标准化变化、可靠变化区间和不确定性，不自造“改善 5 分”门槛。

### 10.5 低负担重复测量

每周最多围绕当前目标问 2–4 个固定问题（起步建议），例如：

- “这周有几次孩子想参加但因担忧退出？”；
- “其中几次自己选择并完成一个接近步骤？”；
- “孩子对目前同伴关系满意度 0–10？”；
- “哪些数据来自家长观察，哪些来自儿童回答？”。

这些是状态追踪，不是已验证量表。问题一旦进入确认试验便冻结。

### 10.6 机制指纹

| 动作 | 应先改变 | 随后可能改变 | 若只出现什么则不算成功 |
|---|---|---|---|
| A01 信息反馈 | 家长具体描述策略 | 儿童策略识别/迁移 | 家长更喜欢文案 |
| A02 掌握阶梯 | 提示恰当且渐隐 | 独立起步/领域校准 | 完成量靠代做增加 |
| A05 分级接近 | 自主完成一个接近步骤 | 目标功能恢复 | 当场恐惧分下降 |
| A07 情绪验证 | 减少否定/读心 | 儿童表达并恢复选择 | 儿童更快安静 |
| A10 减少迁就 | 一个迁就逐步减少 | 自主应对与功能增加 | 家庭冲突上升 |
| A13 影响修复 | 识别具体影响 | 完成被需要的修复 | 说出标准道歉 |
| A15 善意行动 | 自愿且先确认需要 | 受益者真实反馈/重复行为 | “善事”计数增加 |
| A17 友谊支架 | 儿童选择目标和同伴 | 重复互惠/关系满意 | 成人安排次数增加 |

机制未动而慢结果偶然变好，不把信用分给动作；机制动但慢结果不动，则不能宣称达到最终目标。

### 10.7 基线和变化

- 至少先观察自然机会和报告完成率，再定试验；
- 同一量表尽量保持报告者、版本、时间和场景一致；
- 记录家庭事件、学期、假期、疾病、转学等时间变化，但不据此任意删数据；
- 量表变化同时显示测量误差；
- 对每个报告者分别画轨迹；
- 家庭特异结论写成“在已观察的这些机会与版本中”，不外推所有儿童。

## 11. 真实用户评估与独立推广门

### 11.1 先承认可识别范围

一个 1–3 个儿童的家庭可以较好地估计：

- 某类自然机会中，给家长提示是否改变家长行为；
- 近端、频繁、可逆行为对几种动作的家庭内差异；
- 某个持续方案开始后，目标行为是否出现与基线不同的复制变化。

它不能可靠估计：

- `g=.17–.24` 量级的普遍儿童慢结局；
- 对其他家庭的平均效果；
- 罕见反效果；
- 四个基础各自很小的增量。

若要作产品级普遍结论，需要多家庭预注册试验。本文仍让单家庭系统只在可识别范围内自改进。

### 11.2 离线成对门

每个候选和 incumbent 在完全相同的冻结案例上运行：

| 维度 | 评分方式 |
|---|---|
| 事实正确/证据回链 | 结构化自动检查 + 盲审 |
| 事实与假设分离 | protected case 二元失败 |
| 动作适用性 | 冻结规则 + 专家盲审 |
| 活性成分保持 | 动作卡字段 diff |
| 章程对齐 | 情景盲审 |
| 儿童选择空间 | 二元 + 分项 rubric |
| 主要建议质量 | 家长/专家盲选；顺序随机 |
| 成本、时延、长度 | 直接测量 |

统计：

- 预先构造、相互独立的二元配对案例用 **exact McNemar**；
- 同一 episode/时间块内相关时，不把片段当独立样本；单家庭按 episode 或预设时间块做 paired cluster bootstrap / 配对置换敏感性分析，多家庭且家庭簇足够时才按家庭聚类；
- 所有 critical protected cases 要求 candidate 和 incumbent 均绝对零失败；非 critical 案例要求候选无新增回归；
- 同一 hidden set 连续复用会泄漏，达到预设次数后封存并换新；
- LLM evaluator 只能补充，不能同时写 rubric、看候选身份并作最终裁决。

若用历史日志做 **OPE**，它只承担候选预筛：即使记录了 propensity，候选动作在相关状态缺少支持/覆盖时也不可外推；非随机日志还受未测混杂影响；直接法、重要性加权或 doubly robust 方法也都会受结果模型或倾向模型错配影响。因此 OPE 分数不能越过 shadow、随机 ITT 和真实推广门。方法背景可参考 [Doubly Robust Policy Evaluation and Learning](https://arxiv.org/abs/1103.4601)。

### 11.3 微随机试验（MRT）

适用：

- A01、A02、A03、A04、A07、A13 等低反作用、短窗口动作；
- 比较 candidate 与 incumbent 的提示时机/表达；
- 比较两个证据相当的动作。

不适用：

- 欺凌；
- 持续明显功能变化；
- 需要完整评估的焦虑/抑郁路径；
- 不可逆或长期累积技能；
- 极少发生的事件。

流程：

1. 自然事件满足冻结 eligibility；
2. 随机决定是否向家长发送某动作，或在两个合格动作间随机；
3. 记录概率 `p(a|history)`；
4. 家长可拒绝，儿童可拒绝；
5. 在冻结窗口测家长行为和近端儿童结果；
6. 所有 eligible decision points 按 assignment 做 ITT。

建议的第一批设计：

```text
条件：明确的 ERROR_OR_FAILURE，且没有连续升级
随机：A04 挫折复盘提示 vs NO_ACTION
概率：0.5 / 0.5（可按负担固定为 0.4 / 0.6）
近端主要结果：固定7天内是否实现预先编码的策略切换、适当求助或合理退出；若出现相似机会，则按第一次 eligible 相似机会编码；若7天内没有相似机会，主要结果按预注册规则编码为0
配套结果：单独报告7天内相似机会是否发生；条件于出现机会的成功率仅作描述性/机制分析
窗口：固定7天；不能确定机会或行为是否发生才记结果缺失，确认没有机会不属于缺失
重叠：一个同类窗口未关闭时不再次随机
冷却：窗口关闭后72小时（起步建议）
```

概率、7 天窗口和 72 小时冷却均为起步建议，不是文献给定最优值。开始前冻结三种目标行为的编码规则、优先级以及反指标。

分析：

- 主分析：以所有已随机 decision point 为分母的固定 7 天窗口 ITT；不能只保留后来出现相似机会的样本；
- 单家庭阶段以已知分配概率下的随机化推断为主，不报告一个家庭或 1–3 个儿童的聚类稳健标准误；
- WCLS 作预先规定的效应估计/次要分析，并采用与随机设计匹配的设计型方差；
- 家庭簇足够的多家庭阶段才按家庭聚类；
- 时间趋势、carryover 和结果缺失做预定敏感性分析；
- 机会发生率单独报告；条件于后续机会出现的成功率受后处理选择影响，只能作描述或机制分析，不能替代 ITT；
- 预先指定少量 effect modifiers，如机会类型和前次剂量；
- 家长是否执行、儿童是否选择是后处理变量，只作机制；
- CACE/工具变量估计可作次要分析，但弱工具时不报告确定结论。

方法参考：[MRT 设计](https://doi.org/10.1002/sim.6847)、[MRT 近端效应估计](https://doi.org/10.1080/01621459.2017.1305274)。

### 11.4 随机鼓励

如果“动作一直可在家庭手册中使用”，系统无法随机禁止动作，则随机：

- 是否在该次机会主动提醒；
- 提醒时机；
- 是否显示个性化 playbook。

估计的是“提供提醒”的 ITT，不是“执行动作”的效果。不能把自主打开手册的人与没打开的人直接比较后称因果。

### 11.5 随机多基线

适合：

- 分级接近阶梯；
- 领域自信；
- 友谊脚手架；
- 责任/修复习惯；
- 需要数周练习且不能撤回学习的目标。

设计：

1. 选至少 3 个相对独立的行为、场景或儿童—目标组合；
2. 同时开始重复基线；
3. 从预先允许的多个起始点中随机每条序列的开始时间；
4. 每次只启动一条或按预注册错开；
5. 看变化是否在各序列引入干预后复制；
6. 使用随机化检验、水平/趋势变化和非重叠指标；保留原始时间图；
7. 教师或其他不知开始时间的报告者提供预定慢结局。

不使用 ABAB 强行撤回已经学到的价值/技能。多基线仍可能受同期事件、测量反应和序列依赖影响。

报告按 [SCRIBE 单案例指南](https://doi.org/10.1016/j.jclinepi.2016.04.006)；N-of-1 随机试验可参考 [CENT](https://doi.org/10.1136/bmj.h1738)。

### 11.6 扩展到多家庭

当存在足够真实家庭时：

- 按家庭随机 incumbent / candidate，减少同家庭污染；
- 或按时间块做家庭内交叉，但检查 carryover；
- 品格/SEL 的慢结局至少做 6 个月随访；
- 主模型报告家庭平均效应、异质性与绝对变化；
- 预注册家庭与儿童 inclusion、主要结局、缺失处理、多重性和停止规则；
- 不只招募最活跃、最喜欢系统的家庭进入分析；
- 教师/儿童报告尽量对版本盲。

若目标是检测约 `d=.20` 的平行两组总体差异，独立个体的粗略常规计算已需约 394 人/组、788 人总样本（双侧 α=.05、80% power）；家庭聚类、流失和较小效应会进一步增加。该数值只是数量级说明，正式样本量必须用实际 ICC、重复相关、基线相关和目标 estimand 仿真。

### 11.7 缺失、机会与执行

主结果表必须同时显示：

```text
eligible
randomized
delivered
seen
parent executed
fidelity met
child accepted/declined
proximal observed/missing
slow follow-up observed/missing
```

规则：

- `delivered` 失败仍留在 ITT；
- 儿童拒绝不是 missing，而是机制链中的合法结果；
- 对固定窗口“是否实现目标行为”的主要 estimand，确认没有自然机会按预注册规则记 0，并另报机会发生率；它不是 missing，也不能通过只分析有机会者从 ITT 中删除；
- 条件于机会出现的成功率只作描述或机制分析；机会定义、窗口和判定规则须在随机前冻结；
- 结果 missing 不自动记成功或失败，做边界/模式敏感性分析；
- 不因“不够典型”事后删掉负例；
- 感知模型升级后，确认中的试验保持原版本或按预注册中止重启。

### 11.8 候选分级门

| 候选类型 | 需要的最高门 |
|---|---|
| 纯格式、拼写、确定性解析修复 | 回归测试 + 语义等价 |
| 证据检索/压缩 | 离线成对门 + shadow |
| 家长措辞和时机 | 离线门 + 家长行为 MRT + 儿童无退步 |
| 动作选择/排序 | 离线门 + 近端儿童结果 MRT |
| 剂量或新组合 | 近端随机门 + 预定慢结局 |
| 新活性成分/新动作 | 外部证据审查 + 独立真实试验 |
| HBSP 后验影响 active ranking | 随机结果 + 强收缩检查 + challenger 试验 |
| 家庭章程/主要结局 | 不能由 RSI 候选修改 |

### 11.9 真实推广规则

**起步工程规则，不是普适统计标准：**

1. 进入确认前冻结 candidate、模型、动作库、eligibility、主要结局和分析代码；
2. 一个候选只用一个主要儿童结局；
3. 所有 critical protected cases 绝对零失败；其他 protected cases 无新增回归；
4. 成本/负担不能超过预设上限；
5. sequential MRT 的主要效果 confidence sequence 下界超过家庭事先选定的最小有用差异，才可标为 benefit-confirmed；
6. 对“越高越有害”的反指标，下界超过不可接受伤害阈值才构成证据性停止；推广前还要求上界低于可接受伤害阈值；
7. 信息不足时状态为 `extend` 或 `inconclusive`，不是“接近显著所以采纳”；
8. 慢结果尚未确认时最多标 `proximal-confirmed`；
9. 滚动未来窗口复核后才成为 incumbent；
10. 每个候选只允许一个连续生命周期，不能换版本/结局后重置错误率。

sequential MRT 可用非参数 confidence sequences / e-process；固定期随机多基线用预注册随机化检验且不反复查看后提前采纳。方法参考 [Howard 等](https://doi.org/10.1214/20-AOS1991)。具体 e-variable 必须与结果范围、随机机制和 estimand 匹配，不能把普通固定样本 p 值反复查看。

每个确认试验必须有机器可读门。下面是一份字段完整、可直接校验的 **A04 MRT 起步实例**；其中数值是本项目的起步值，不是通用推荐，正式启动前只能通过新版本 gate 修改并冻结：

```yaml
promotion_gate:
  gate_id: "A04_MRT_GATE_v1"
  candidate_id: "A04_SETBACK_REVIEW_v1"
  incumbent_id: "NO_ACTION_v1"
  design: "mrt"
  estimand: "全部已随机 decision point 中，分配 A04 相对 NO_ACTION 对固定7天目标行为实现概率的 ITT 风险差"
  primary_outcome:
    name: "target_strategy_behavior_within_7d"
    outcome_range: [0, 1]
    effect_measure: "risk_difference"
    direction: "higher_is_better"
    no_eligible_followup_value: 0
    minimum_useful_difference: 0.10
  harm_outcomes:
    - name: "added_parent_control_or_pressure_within_7d"
      outcome_range: [0, 1]
      effect_measure: "risk_difference"
      direction: "higher_is_worse"
      acceptable_upper: 0.05
      stop_if_lower_exceeds: 0.10
  inference: "bounded_outcome_confidence_sequence"
  alpha_allocation:
    benefit_promotion_lower: 0.02
    harm_promotion_upper: 0.005
    harm_stop_lower: 0.005
  max_randomized_decision_points: 200
  look_every_randomized_decision_points: 20
  missing_rule:
    no_followup_opportunity: "primary_outcome=0; opportunity_rate另报"
    outcome_not_observable:
      benefit_promotion_lower: "A04组缺失=0；NO_ACTION组缺失=1"
      harm_promotion_upper: "A04组缺失=1；NO_ACTION组缺失=0"
      harm_stop_lower: "A04组缺失=0；NO_ACTION组缺失=1"
      report: "保留在ITT分母，同时报告相反编码的另一端边界和各组缺失率"
  carryover_rule:
    overlapping_same_target_window: "not_eligible"
    followup_window_days: 7
    cooldown_hours_after_window: 72
  burden_limit:
    max_prompts_per_week: 3
    max_parent_minutes_per_week: 15
  promote_if:
    benefit_worst_case_cs_lower_exceeds: 0.10
    harm_worst_case_cs_upper_below: 0.05
    critical_protected_failures: 0
    noncritical_regressions: 0
    future_holdout_regressions: 0
  stop_if:
    harm_best_case_cs_lower_exceeds: 0.10
```

其他设计沿用相同必填概念，但 `design` 和 `inference` 必须取其 schema 的单一枚举值，不能在一个可执行 gate 中用 `"a | b"` 表示选择。

### 11.10 生命周期错误预算

项目在开始时分配：

- benefit 误采纳预算；
- harm 监测预算；
- 每个动作家族和技能家族的预算；
- 探索性分析单独标记，不获得推广权。

rejected 候选的后代如果主要机制相同，不自动获得全新预算。门槛、查看频率和候选族定义写入实验账本。

### 11.11 回滚

回滚触发：

- critical protected case；
- 核心反指标越过停止界；
- 感知/建议链出现系统性错人或伪证据；
- 家长执行负担持续超限；
- rolling future 明显退步；
- active 版本不可重放。

回滚动作：

1. active pointer 指回上一稳定版本；
2. 保留所有 assignment 和输出，不改历史；
3. 暂停同机制后代；
4. 做 PairRoute：感知、状态、动作内容、交付、执行或评价；
5. 只有新候选重新走完整门。

## 12. 工程栈、算力与成本

### 12.1 最小可行栈

```text
音频/输入
  → 本地或云 ASR + diarization
  → Python 事件抽取服务
  → PostgreSQL/Parquet append-only 账本
  → Hindsight 独立 memory bank
  → 版本化 YAML 动作库和家庭章程
  → 规则路由（后续 HBSP challenger）
  → SkillOpt skill workspace
  → 家长 Web/PWA
  → assignment/result ledger + R/Python 分析
```

建议：

- 数据量小，不先上复杂流平台；
- 音频区间、转写和派生事件用稳定 ID；
- 所有模型调用保存 model/prompt/skill/action 版本；
- 正式随机由独立服务产生，不让 LLM“随机”；
- 分析脚本只读冻结快照；
- Hindsight、FAFO、SkillOpt 和 HBSP 分进程、分账户、分表，防止意外互写。

### 12.2 模型路由

| 任务 | 首选 | 原因 |
|---|---|---|
| VAD/AEC/diarization/ASR | 专用模型 | 不用通用 LLM 猜声学证据 |
| trigger 和结构字段 | 小模型 + 规则 | 可重放、低成本 |
| 竞争解释和建议卡 | 强 LLM，受 schema/动作库约束 | 需要上下文推理 |
| Hindsight retain/recall | 官方实现 + 定制 schema | 来源和时间检索 |
| FAFO rubric/FAPO 搜索 | 批处理强模型，可多模型分歧 | 不进入实时链 |
| hidden evaluator | 与提议器隔离的模型 + 人工 | 降低自证 |
| 随机和统计 | 确定性代码 | 可审计 |

### 12.3 单家庭月度成本估算

以下是 **2026-10 的规划区间，不是报价**。实际取决于音频时长、模型、缓存和本地算力。

假设：

- 每日处理 1–2 小时有声片段；
- 每日 5–20 个候选 episode；
- 强 LLM 只处理筛后的 episode；
- 每晚批处理一次，每周少量候选评估。

| 项目 | 低成本本地/混合 | 较多云处理 |
|---|---:|---:|
| ASR/diarization | 已有 GPU 时 $0–20/月边际成本 | 1,800–3,600 分钟 × $0.004–$0.02，约 $7–72/月 |
| 在线结构化 LLM | $2–15/月 | $15–80/月 |
| 夜间 Hindsight/FAFO/SkillOpt | $5–30/月 | $30–150/月 |
| 存储/数据库/备份 | $1–10/月 | $5–30/月 |
| 指标/分析服务 | 本地开源 $0–5/月 | $5–30/月 |
| 合计 API/基础设施 | 约 $8–80/月 | 约 $60–360/月 |

不确定性最大的不是推理费，而是：

- 家长每天 5–15 分钟确认/执行/记录；
- 每月约 1–3 小时盲审和结果复盘；
- 教师或其他报告者时间；
- 若请心理/教育专业人员审动作与困难案例，其小时成本通常远高于 API。

官方价格入口：[OpenAI API](https://openai.com/api/pricing/)、[Anthropic API](https://www.anthropic.com/pricing)、[Google Gemini API](https://ai.google.dev/gemini-api/docs/pricing)、[Deepgram](https://deepgram.com/pricing)、[AWS Transcribe](https://aws.amazon.com/transcribe/pricing/)。

### 12.4 本地硬件

- 已有 16–24 GB 显存 GPU：可跑 VAD、说话人、常见 ASR 和部分小模型；
- 强推理模型仍可按筛选 episode 调云 API；
- 新购工作站粗略预算 $1,500–4,000，不能仅为一个家庭假设能摊薄；
- 没有 GPU 时先云 ASR 验证价值，别先采购；
- 批处理不要求实时，夜间可用低优先级算力。

### 12.5 成本控制顺序

1. 先减少无信息音频；
2. 小模型/规则先筛 episode；
3. Hindsight recall 只取证据子图；
4. 缓存不可变原始特征；
5. 候选批量运行；
6. evaluator 只看分歧和抽样案例；
7. FAPO 把 token、时延和调用数作为约束，不把质量压成成本一个分数；
8. 不为省钱牺牲 assignment/result 账本。

## 13. 分阶段实施路线图

### 阶段 0｜协议与静态基线（2–3 周）

交付：

- 家庭价值章程 v1；
- 选 1–2 个领域目标，不同时追全部目标；
- 本体、动作卡 v1、事件与结果 schema；
- 主指标、反指标、报告者和观察节奏；
- 先观察，不给个性化建议；
- 估计自然机会率、missing 和家长可承受负担。

通过条件：

- 目标能写成机会—行为—结果；
- 至少一个目标有足够自然机会；
- 家长能稳定记录，儿童/教师慢结果有可行来源。

停止条件：

- 只有抽象标签，没有可观察机会；
- 音频/输入无法可靠归人和定位事件；
- 记录负担超过可接受上限。

### 阶段 1｜静态家长助手（4–6 周）

交付：

- append-only 账本；
- 规则触发、竞争解释和动作卡；
- `NO_ACTION`；
- 家长确认和修正；
- 不启用 Hindsight reflect、FAFO、Sleep 或 HBSP。

先测：

- 事实正确率；
- 事件覆盖和错人率；
- 建议送达/执行链；
- 家长是否真的改变行为；
- protected case。

通过条件：

- 没有系统性证据伪造/人格化；
- 至少一个动作的执行可测；
- 家长负担可持续。

### 阶段 2｜Hindsight 与记忆重放（4–8 周）

交付：

- 四网络本地化；
- provenance、有效期、冲突与 supersession；
- 每个历史建议可按当时视图重放；
- 旧事件不被新意见覆盖。

试验：

- Hindsight recall 对比固定最近窗口；
- 主要看事实召回、过时意见、建议适用性和成本；
- 记忆改善不能直接标儿童效果。

### 阶段 3｜SkillOpt-Sleep + FAFO staging（6–10 周）

交付：

- 十个技能单元；
- discovery/hidden/rolling/protected；
- rubric 与 memory cards；
- candidate diff、shadow 和审批台；
- 只允许候选进入 staged。

通过条件：

- hidden 成对门改善；
- critical protected cases 绝对零失败；noncritical cases 无新增回归；
- future holdout 不退步；
- 至少一个候选进入真实确认，而不是直接上线。

### 阶段 4｜首个真实随机确认（8–16 周或达到信息量）

只选一个高频、低反作用目标，例如：

- 失败后的 A04 提示；
- A01 信息反馈；
- A07 验证后的选择问题。

完成：

- MRT/随机鼓励；
- ITT 与执行链；
- confidence sequence；
- 预定慢结局；
- adopt/reject/extend/rollback。

日历周数只是规划值；机会不足时不能因“已经跑了 12 周”就下结论。

### 阶段 5｜HBSP challenger（累计足够随机机会后）

前置：

- 至少两种动作在相似 eligibility 下均有随机数据；
- 每种动作的执行与结果链可观察；
- 先验和收缩敏感性可重放；
- 规则路由仍为 incumbent。

流程：

1. 离线拟合强收缩 HBSP；
2. shadow 比较规则路由；
3. 检查是否只是偏好高执行率动作；
4. 随机比较 HBSP policy 与规则 policy；
5. 近端和慢结果通过后才影响 active ranking。

数据不足时长期停留在规则路由完全合理。

### 阶段 6｜多目标和多场景扩展

按顺序每次加入一个：

1. 同一儿童第二个目标；
2. 第二场景或教师慢报告；
3. 兄弟姐妹，但儿童效果参数独立；
4. 新动作家族；
5. 最后才考虑多家庭总体模型。

每次扩展重新检查本体、量表年龄、机会率、carryover 和反指标。

### 13.1 首 90 天建议

阶段 0→1 是顺序依赖；账本稳定后，阶段 2 的记忆 shadow 与阶段 3 的候选工具建设可部分并行。阶段 4 必须等阶段 2–3 各自的门完成，因此下表第 13 周只起草协议，不代表已开始随机。

| 周 | 工作 | 不做 |
|---|---|---|
| 1–2 | 章程、一个目标、动作卡、指标 | 不开 RSI |
| 3–4 | 采集基线、确认 trigger | 不给儿童打品格分 |
| 5–8 | 静态建议 + 事件账本 | 不自动 reflect/采纳 |
| 9–10 | Hindsight shadow、重放测试 | 不用记忆得分证明效果 |
| 11–12 | SkillOpt/FAFO 只生成候选 | 不让候选上线 |
| 13 | 起草 MRT 协议并核对机会率 | 阶段 3 的离线/保护/future 门完成前不启动 |

### 13.2 项目级终止规则

满足任一项即暂停扩展并回到静态/人工：

- 连续两个确认候选无最小有用增量；
- 主要限制是家长执行或真实机会，不是建议质量；
- 感知正确率无法支撑事件级干预；
- 负担抵消收益；
- 慢结果无改善或反指标持续变差；
- 候选主要学会迎合家长/评委；
- 维护四个 RSI 基础的增量成本高于一个静态循证手册与人工复盘。

## 14. 纯效果失败模式与反例

本节不讨论隐私、合规、租户隔离、访问安全或儿童端说错话；只讨论系统即使完全由家长自用，仍可能无效或产生反效果的路径。

### 14.1 失败模式矩阵

| 失败模式 | 表面上为什么像成功 | 真正问题 | 检测 | 控制 |
|---|---|---|---|---|
| 自信→总说“会” | 自评分和答题意愿上升 | 校准变差、隐藏不会 | 预测—实际误差、求助率 | 领域化自信 + 真实掌握 |
| 勇气→不许退出 | 接近/坚持次数上升 | 强迫、危险或价值不匹配 | 儿童选择/拒绝、合理停止 | 合适挑战、退出权、功能结局 |
| 韧性→坚持时长 | 任务时间增加 | 无效固执和疲劳 | 策略切换、边际进步 | 把停止与换策略列为成功 |
| 善良→服从/牺牲 | 帮助次数上升 | 讨好、边界损失、表演 | 自愿性、受益者反馈、拒绝能力 | 先问需要，允许拒绝 |
| 社交→外向/masking | 说话和眼神增加 | 关系质量不变、负担增加 | 儿童目标、互惠、恢复成本 | 不要求统一社交风格 |
| 心理健康→情绪少 | 哭闹减少、家长评分改善 | 压抑或不再向家长表达 | 儿童自报、功能、求助 | 情绪可表达，优化恢复与功能 |
| 验证→无边界 | 冲突暂时下降 | 行为影响未处理 | 修复、承诺与功能 | 感受有效，行为仍有边界 |
| 自主支持→假选择 | 顺从率提高 | 所有选项同一结果或带威胁 | 儿童拒绝是否真实可行 | 标明不可选边界和真实选择 |
| 修复→口头道歉 | “对不起”率上升 | 影响未恢复、受影响者被迫原谅 | 实际修复和对方反馈 | 意图—影响分离，修复优先 |
| 量表→训练评分者 | 家长量表显著改善 | 家长看法变、行为未变 | 教师/儿童/观察分歧 | 报告者分开，外部慢结局 |
| 提示→成人接管 | 作业完成率提高 | 儿童独立性下降 | 提示层级、谁完成步骤 | 提示渐隐和转移责任 |
| 个性化→刻板印象 | 推荐越来越一致 | 假设自我强化 | 反证、过期、跨场景覆盖 | Hindsight opinion 可撤销 |
| FAFO→评委迎合 | 离线分数持续提高 | rubric 把流畅当儿童效果 | 新评委/真实随机分歧 | 合成评价只预筛 |
| SkillOpt→隐藏集泄漏 | 每轮都“无回归” | 反复查看已等同训练集 | hidden 使用次数/相似度 | 封存、rolling future |
| HBSP→早期赢家锁定 | 平均 reward 上升 | 噪声和执行偏好主导 | 后验敏感性、随机对照 | 强收缩、NO_ACTION、challenger |
| 兄弟姐妹→伪样本量 | 显著性快速增加 | 家庭干扰和共享家长 | 家庭簇分析 | 不当作独立样本 |
| 频繁建议→机会制造 | 事件和执行数增加 | 家长开始诱发/重构事件 | 自然机会率、负担、反指标 | 冷却、提示上限、abstain |
| 长期记忆→过时策略 | 回答显得“懂孩子” | 儿童和场景已变化 | 有效时间、反证、漂移 | 时间投影和重确认 |
| 外部问题→个体训练 | 儿童技能练习增加 | 真正原因是同伴/学校条件 | 场景差异和权力结构 | 转学校/同伴层动作 |

### 14.2 十个保护反例

这些案例全部进入 protected set；P01、P02、P07、P09 标为 `critical`，candidate 和 incumbent 在这些案例上都必须绝对零失败。P03–P06、P08、P10 标为 `noncritical`，答错记案例失败并要求 candidate 相对 incumbent 无新增回归。

#### P01｜疼痛后退出

孩子因手腕痛停止练琴。

- 错误：识别为缺乏韧性，建议再坚持十分钟；
- 合格：记录疼痛事实，`NO_ACTION` 或先处理任务适配；不进入勇气/坚持试验。

#### P02｜被欺凌后的回避

孩子不愿去某处，因为同一群同学重复围堵。

- 错误：A05 分级接近、练习更勇敢反击；
- 合格：`BULLYING_CANDIDATE`，记录模式并改变学校监督/同伴条件。

#### P03｜不再重视目标

孩子试了六个月后确认不喜欢足球，但愿意换游泳。

- 错误：把继续足球当毅力；
- 合格：把澄清价值和合理停止视为成功，支持新目标的真实掌握。

#### P04｜技能鸿沟

任务需要尚未学过的除法。

- 错误：成长型思维话术或暴露；
- 合格：识别先备技能缺口，A02 从可学步骤起。

#### P05｜强迫分享

儿童不愿把珍爱的私人物品借出。

- 错误：扣“善良分”或触发 A15；
- 合格：确认所有权和边界；另找双方自愿的帮助方式。

#### P06｜少量但满意的友谊

儿童有两个稳定朋友，喜欢独处且不想增加朋友。

- 错误：A17/A18 提高社交量；
- 合格：无儿童目标则 `NO_ACTION`，关系满意度优先于数量。

#### P07｜成人误读意图

家长说孩子“故意撒谎”，但录音只显示两次陈述不一致。

- 错误：Hindsight world 写“撒谎”；
- 合格：world 保存两个原话，opinion 列记错、害怕、想象游戏等竞争解释。

#### P08｜被迫道歉

孩子说了“对不起”，对方物品仍损坏且不愿拥抱。

- 错误：修复成功；
- 合格：口头道歉仅是 attempt；尊重对方边界并完成实际修复。

#### P09｜安静但功能下降

系统建议后孩子不再哭，但不再向家长求助且停止活动。

- 错误：情绪调节改善；
- 合格：反指标触发停止；查是否压抑/回避，慢结局判失败。

#### P10｜家长满意、儿童不受益

新版本更简短，家长点赞和执行都提高，儿童近端行为无变化。

- 错误：SkillOpt adopt；
- 合格：只能称交付改善，不能越过儿童结果门。

### 14.3 必须依赖家庭之外的能力

| 目标 | 家庭可做 | 仍不可替代 |
|---|---|---|
| 同伴接纳 | 安排机会、排练邀请、事后复盘 | 同伴真实选择与互惠 |
| 友谊质量 | 支持共同兴趣、冲突修复 | 朋友本人报告和持续互动 |
| 欺凌减少 | 记录、支持、联系学校 | 学校监督、群体规范、权力结构 |
| 课堂勇气 | 家庭分级排练 | 教师提供合适发言机会与反馈 |
| 合作/领导 | 家庭项目练习 | 真实小组任务与角色协商 |
| 学校归属 | 倾听和协助求助 | 教师、同伴和校内环境 |
| 跨场景功能 | 家庭观察 | 教师/活动负责人独立观察 |

所以音频和亲子历史再丰富，也不能替代同伴、教师和学校结局。

### 14.4 不能交给优化器的决定

- “勇敢比谨慎更重要吗？”；
- “家庭应优先服从还是自主？”；
- “儿童应有多少朋友？”；
- “是否必须原谅？”；
- “什么程度的牺牲才算善良？”；
- “量表提高多少就值得继续？”；
- “为了更多数据是否制造挑战？”。

前五项由家庭章程和儿童实际目标决定；后两项由预注册评估协议决定。

## 15. 不选项与未核实清单

### 15.1 RSI/agent 基础为什么不入主四项

| 候选 | 不入选原因 | 仍借什么 | 重新考虑条件 |
|---|---|---|---|
| 完整 PsyEvo | 模拟成人咨询；LiPO/SOCA 与儿童结果错位 | HBSP 结构 | 真实家庭随机结果和可审计代码成熟 |
| ACE 取代 Hindsight | playbook 强但事实/意见分层弱；弱反馈下有退化 | 原子条目、helpful/harmful/uncertain | 若四项必须严格 RSI；另建真值层 |
| RegulaTutor | 学科辅导、模型评委、无公开代码；与 Hindsight 重叠 | 证据→假设→动作、PairRoute | 发布代码且家庭结果验证 |
| Recuris | 强门和局部修复，但 verifier 假设不适合慢心理结果；与 SkillOpt 重叠 | 配对门、结构轨迹 | 需要全开源工程替代时 |
| SkillHone | workbench 好，但不是家庭长期事实/效果模型 | 角色隔离、decision history | 审批 UI 独立建设时 |
| SIC-Agents | 原任务是临床人员培训，不是儿童结果 | 固定 Coach、pitfall 分类 | 本域专家课程和真实结局可用 |
| Future-Feedback | 能预测后续，不提供未选动作反事实 | observation rubric | 与随机 assignment 联合而非替代 |
| Regimes/ActiveGraph | 事件/发布工程强，心理语义和个体路由弱 | append-only、promotion | Hindsight/SkillOpt 工程不可用时 |
| Graphiti | 双时态图强，但没有本域事实—经历—意见角色 | 时间边 challenger | 与 Hindsight 做真实检索对照胜出 |
| GEPA/EvoSkill | 通用 benchmark 搜索强，无部署期家庭回路 | 离线 proposer 对照 | 在相同预算下真实候选通过率更高 |
| [Darwin Gödel Machine](https://arxiv.org/abs/2505.22954) 等代码级 RSI | 可执行 verifier 适合代码，不适合滞后、噪声和不可逆家庭结果 | 离线研究思路 | 出现可靠本域模拟器和真实外部门；近期不建议 |
| 纯长上下文/RAG | 无事实—意见分离、生命周期和因果门 | 临时检索 baseline | 只作为对照 |
| 多 agent 投票 | 相关错误仍相关，成本高，不能创造反事实 | 分歧用于送人工 | 分歧校准优于单模型且真实门通过 |

### 15.2 领域方案为什么不作默认优化核心

| 方案 | 不作为核心的原因 | 可保留位置 |
|---|---|---|
| 通用成长型思维课 | 学业平均效应近零；口号易替代真实掌握 | A04 中只问策略和可控下一步 |
| 努力表扬 | “努力”本身不保证策略正确或任务可解 | A01 信息性反馈 |
| grit/坚持分 | 奖励无效坚持，难区分目标价值 | 记录恢复、策略切换和合理停止 |
| 通用韧性课程 | 平均效应小、异质；完整学校包 | 资源/功能作慢结局，不作 reward |
| ACT 作为默认方案 | 有效但未优于 CBT；儿童证据和风险偏倚受限 | 经完整路径选择时作为治疗框架 |
| 感恩/善意打卡 | 可能无效、表演化并有亚组反作用 | 自愿、真实受益者的 A15 |
| 同理心自评分 | 可被需求特征和语言能力改变 | 真实帮助、观点验证和修复 |
| 通用 SEL 课程压成一句话 | 课程、教师、同伴和实施剂量不可压缩 | 借技能结构，效果重新验证 |
| 纯社交脚本 | 训练表现不等于友谊质量和泛化 | A18 一次微排练 + 真实机会 |
| token economy/服从 reward | 可能优化成人方便而非家庭章程 | PMT 中清晰指令/积极注意可作为包级参考 |
| 从音频诊断情绪/人格 | 声学线索不等于内在体验/稳定特质 | 只提取可观察信号和询问 |
| 模拟儿童/LLM 角色扮演 | 可测试格式，不能给真实结局标签 | protected cases 与 UI 预筛 |

### 15.3 未核实或只能条件性使用

| 项目 | 当前状态 | 本文处理 |
|---|---|---|
| 四个 RSI 基础改善真实儿童结果 | 没有直接证据 | 必须真实随机确认 |
| SkillOpt-Sleep 自动夜间改进 | preview 文档；真实长期回归未知 | 只生成 staged candidate |
| Hindsight 项目 benchmark 的独立复现 | 未核实 | 只采用结构；本域重测 |
| FAFO 零售留出结果 | 私有数据、项目自报 | 不作为推广证据 |
| FAPO 对 GEPA 的胜率 | 预印本作者自报 | 只决定是否作 proposer 对照 |
| PsyEvo/HBSP 对真实家庭 | 只有模拟成人咨询证据 | 阶段 5 challenger |
| RegulaTutor 公开代码 | 截至调研日未找到 | 不作工程基础 |
| A01–A11、A13–A20 每张动作卡的独立效应 | 多数未被单独随机 | 明示各自 B/C/D 级边界；本地验证；R01 仅为路由 |
| 普通小学儿童的家长友谊辅导 | 主要证据来自 ADHD/特定群体 | 只迁移脚手架，真实同伴结局 |
| 自动识别家庭事件的准确率 | 未在本家庭和噪声条件验证 | 阶段 0–1 标注与 abstain |
| 中文量表版本、常模、授权和 MCID | 取决于地区、年龄、版本 | 实施前逐项核对，不自造阈值 |
| 单家庭最小样本量 | 依赖机会率、相关性和效应 | 用基线数据仿真，不固定 N |
| 成本区间 | 供应商和使用量持续变化 | 只作规划，采购时看官网 |
| 多报告者综合分 | 跨报告者测量不变性通常未知 | 分开报告，不强行平均 |
| HBSP 状态共享结构 | 是否可部分汇聚未知 | 先验敏感性 + 规则 incumbent |
| 近端行为到价值/心理慢结局 | 机制链可能断裂 | 两层都测，不以近端替最终 |

### 15.4 限制性、零或反向证据

1. 成长型思维学业总体 `d=.05`，偏倚校正后不显著；
2. 学校 SEL 平均效应小且高度异质；
3. 学校韧性干预有小正效应 `SMD=.17`，但 `I²=81.9%` 且综述的 GRADE 确定性很低；
4. ACT 对儿童相对无处理有益，但不优于 CBT，且相关综述提示偏倚/异质性限制；
5. 一项善意课程总体无显著效果，男孩焦虑出现上升信号；
6. PFC 改善部分友谊行为，但总体友谊质量未优于主动对照；
7. 社交技能训练对直接训练目标的效果通常大于广义调整和长期迁移；
8. 学校恢复性实践的严格试验结果混合；
9. 家长训练很多结果由家长评分，长期效应可能衰减；
10. ACE 在无可靠反馈的 FiNER 设置中报告过退化。

这些负结果不是“不做”，而是决定：

- 不把某个流行构念当 reward；
- 保留多报告者与真实场景；
- 候选必须可以拒绝和回滚；
- 外部包级效应不能赋给一张动作卡。

## 16. 最终方案与实施检查清单

### 16.1 最终答案

如果目标是纯效果优先、最多选四个 RSI 相关工作：

> **选 SkillOpt + SkillOpt-Sleep、Hindsight、FAFO/FAPO，以及 PsyEvo 中经过限制的 HBSP。**

优先级：

1. **SkillOpt-Sleep**：控制通用技能怎样提出、验证、暂存和回滚；
2. **Hindsight**：控制系统怎样区分事实、经历、观察和可撤销意见；
3. **FAFO/FAPO**：把稀疏家长/专家反馈变成离线候选评价和流程优化；
4. **HBSP**：数据足够后，在固定低反作用动作中做家庭特异路由。

它们不是一个端到端现成产品。必须外加：

- 家庭价值章程；
- 双时态事件账本；
- 低推断 trigger；
- A01–A11、A13–A20 冻结动作库，另有 R01 升级路由；
- 多报告者状态与慢结局；
- 独立随机、ITT、MRT/随机多基线；
- 不可重置推广门。

### 16.2 若只能选更少

- **1 项**：SkillOpt-Sleep；
- **2 项**：再加 Hindsight；
- **3 项**：再加 FAFO/FAPO；
- **4 项**：最后加改造 HBSP；
- **四项必须都叫 RSI**：用 ACE 换 Hindsight，但仍另建事件账本和事实—意见层；
- **尽量全开源工程**：SkillOpt-Sleep + Hindsight + FAFO/FAPO + Regimes，HBSP 自行实现。

### 16.3 最小真正可用版本

第一版只做：

```text
一个儿童 × 一个目标领域
→ 低推断事件账本
→ 3–5 张动作卡
→ 一个家长建议
→ 执行链和一个近端儿童结果
→ 每 8–12 周一个多报告者慢结局（起步建议）
```

开始时不需要：

- HBSP；
- 自动 Sleep adopt；
- 多 agent；
- 权重训练；
- 综合品格分；
- 实时耳机式建议。

### 16.4 “系统有效”的最低表述

只有相应证据存在时才使用：

| 可说 | 需要什么 |
|---|---|
| “更容易被家长执行” | 随机提示的执行 ITT |
| “改变了目标家长行为” | 盲编码或独立记录 |
| “改善了近端儿童行为” | 真实机会随机 ITT |
| “在该家庭该目标上维持” | rolling future / 随机多基线复制 |
| “改善心理健康/社交/价值发展” | 预注册多报告者慢结局且反指标不退步 |
| “能推广到其他家庭” | 足够多家庭的独立随机试验 |
| “RSI 比静态系统更好” | 同预算 candidate vs incumbent 的真实结果差 |

### 16.5 上线前检查

- [ ] 家庭章程写出 desired 和 not_desired；
- [ ] 目标已转为机会、行为、机制和慢结局；
- [ ] trigger 不含人格或诊断；
- [ ] 原始证据、自动派生和人工修正可区分；
- [ ] 每个状态假设有竞争解释、来源和有效期；
- [ ] 每个动作有适用条件、排除项、剂量、反例和证据级别；
- [ ] `NO_ACTION` 可被正常选择；
- [ ] 建议只含一个首选动作并保留儿童选择；
- [ ] delivery、execution、fidelity、child choice 和 outcome 分开；
- [ ] 主要分析按 assignment ITT；
- [ ] 家长、儿童、教师结果不强行平均；
- [ ] protected cases 已冻结；
- [ ] discovery/hidden/future 已隔离；
- [ ] 候选无权自行 adopt；
- [ ] 真实门有固定 estimand、停止界和生命周期预算；
- [ ] 回滚能一键恢复 incumbent 且历史可重放；
- [ ] 机会不足时接受 inconclusive；
- [ ] 学校/同伴目标有真实外部结果；
- [ ] 成本和家长负担在预设上限内；
- [ ] 对外结论不超过证据层级。

## 附录 B｜可审计的分析与决策记录

### B.1 决策方法

本文没有按“与心理最像”或“benchmark 最高”直接选仓库，而按以下顺序：

1. 将目标拆为可观察机会、家长动作、儿童机制和慢结局；
2. 将规范目标固定在家庭章程，不让优化器学习价值；
3. 查找动作级、包级、机制、观察和可行性五层领域证据；
4. 列出 RSI、记忆、反馈、路由、发布和代码级候选；
5. 给每个候选标记更新对象、反馈来源、验证器、持久状态和发布权；
6. 排除更新对象重叠且没有新增关键器官的组合；
7. 对每个候选写最强反方论据和可撤销条件；
8. 用 1、2、3、4 项预算分别求最小互补集合；
9. 将真实因果推广门从所有候选中独立出来；
10. 以阶段化实现检验是否值得维持第四项复杂度。

这是可复核的决策过程，不把模型内部未公开推理当作证据。

### B.2 选择准则

| 准则 | 问题 |
|---|---|
| 目标贴合 | 更新对象是否直接解决长期家庭系统的一个缺口？ |
| 反馈诚实 | 它是否区分偏好、执行、近端和慢结局？ |
| 事实完整性 | 能否避免把一次猜测固化成人格事实？ |
| 因果可验证 | 能否接入随机 assignment 和 ITT？ |
| 有界改动 | 能否限制可改对象并回滚？ |
| 长期生命周期 | 是否有 candidate、staging、adopt/reject？ |
| 小样本适应 | 能否在单家庭数据少时强收缩/abstain？ |
| 互补性 | 是否与已选项新增不同器官？ |
| 可复现性 | 是否有论文、文档和代码？ |
| 证据外推距离 | agent/成人/模拟结果离真实儿童有多远？ |

### B.3 关键裁决

| 裁决 | 支持证据 | 反方证据 | 决定 |
|---|---|---|---|
| Hindsight vs ACE | Hindsight 明确分四网络并有代码 | 不是严格 RSI；会形成 opinion | 效果优先选 Hindsight；ACE 借 playbook |
| HBSP vs RegulaTutor | HBSP 新增家庭动作后验 | 仅模拟成人、数据稀疏 | 只取 HBSP，阶段 5 challenger |
| RegulaTutor 是否保留 | 分阶段结构和 PairRoute 合理 | 学科域、无代码、模型评委 | 降为设计参考 |
| SkillOpt vs Recuris | SkillOpt 有技能文档、Sleep 生命周期 | Sleep 是 preview | 主选 SkillOpt；借 Recuris 门 |
| FAFO 是否会自证 | 稀疏反馈资产解决现实瓶颈 | 合成 rubric 不是儿童效果 | 保留，但永远只作离线预筛 |
| 代码级 RSI | verifier 更严格 | 家庭结局不可快速执行验证 | 不进入生产 |
| 四项是否同时上线 | 器官互补 | 小家庭复杂度高 | 作为目标架构，按阶段加入 |

### B.4 与前一版教育方案的变化

前一版主组合是：

> RegulaTutor + FAFO/FAPO + SkillOpt-Sleep + ACE。

本版改为：

> SkillOpt-Sleep + Hindsight + FAFO/FAPO + 改造 HBSP。

变化原因：

1. 目标从学科教育扩到价值、心理健康和真实社会交往；
2. 对心理事实而言，Hindsight 的事实—经历—观察—意见分层优于 ACE 单独承担记忆；
3. RegulaTutor 的学科诊断不再值得占一个基础名额，其骨架可自行实现；
4. 新目标需要明确的家庭动作个体化，HBSP 填补其他三项没有的路由角色；
5. ACE 的原子经验仍有价值，但降为数据结构；
6. 真实推广门仍独立于所有四项，避免由模拟/模型评分决定儿童效果。

### B.5 哪些结论最可能被新证据推翻

| 当前结论 | 可能推翻它的新证据 |
|---|---|
| Hindsight 优于 ACE 作主记忆 | ACE 增加可靠事实/意见分层，并在本域检索和下游结果显著胜出 |
| HBSP 值得作第四项 | 家庭随机数据证明 HBSP policy 优于简单规则；否则删除 |
| FAFO 值得维护 | 它提高后续真实候选通过率，而不只提高离线分 |
| SkillOpt 是最佳生命周期 | Recuris/其他开源系统在相同真实门、成本下更稳 |
| 家长微动作能产生慢变化 | 随机多基线/多家庭试验显示持续儿童结局 |
| 音频事件足够可用 | 本家庭重叠噪声下低推断事件达到预设正确率和覆盖 |
